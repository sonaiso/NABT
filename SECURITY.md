# Security and trust boundaries

NABT processes untrusted text and certificates locally. It does not execute
text as code and has no network access in its runtime.

The authoritative law is the packaged, versioned transition table generated
from the Lean definitions. Certificate fields are claims to be recomputed,
not permissions. Replacing the installed package or its trusted law is outside
the certificate verifier's threat model; a digest is an integrity identifier,
not an authentication signature.

Resource limits produce explicit `DEFER` results. They must never be treated
as proof that a word or completion does not exist. Inputs with missing
vocalization are not guessed by the foundation parser.

Before releasing, review the formal assumptions, generated-table conformance,
source binding, malformed integer/Unicode handling, and certificate mutation
tests. Do not report a theorem about Python merely because a related Lean
definition is proved.

Do not include credentials or private text in public issue reports. A private
reporting contact has not yet been designated by the repository owner.
