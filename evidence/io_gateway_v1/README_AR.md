# تحقق بوابة NABT الموحدة

نجح `make check` الكامل عند `2de722c`: شغّل 3405 اختبارات عامة؛ نجح 3225 وتخطى 180، ثم اجتازت فحوص المطابقة والتقييم والتصدير والتدقيق والفهرس وبوابات التكامل المطلوبة. تبقى حدود التقييم اللغوي التاريخية موثقة؛ هذا ليس إعلانًا باكتمال العربية.

أكملت المتابعة إحالات مسار الدروس إلى مصفوفة المنهج الحالية وأصحاب القياس المعرفي والتعلم من المصدر والزمن. اجتازت المتابعة 24 اختبار بوابة أصليًا بلا تخطٍّ، وأربعة اختبارات لحفظ مرجع البرهان والتبعيات المجمدة. لم يُعد تشغيل المجموعة العامة كلها بعد هذه المتابعة المحددة؛ لم تتغير نواة `src/` أو مصادر `formal/` أو أصحاب العقود المنفذين.

الفهرس المجمع مطابق للمرجع المعتمد: 1617 تصريحًا و1614 عبارة معيارية. تدقيق مسلمات Lean نجح. حُلّت الروابط المصرح بها؛ تبقى 382 سجلاً لا تحمل إحالة مبرهنة و55 سجل التزام جسر ظاهرًا. ليست هذه أعداد مبرهنات ثبت بطلانها أو فجوات لغوية متطابقة.

تسجل `results.json` الأوامر والمراجعات والأعداد والتخطيات والبصمات وحدود الدعوى. ملفات `.log.gz` سجلات تشغيل، وملفات المطابقة مخرجات للفواحِص الموجودة. هذه أدلة تحقق؛ الفهرس المرجعي يبقى في المسار الذي يحدده `integrations/current_proof_references.mk`.

توقفت محاولة أولى بسبب تعديل ملف CI المثبت ضمن تبعيات أوراكل التقييم. أُعيد الملف، وأضيف مسار CI مستقل، ثم نجح الفحص الجامع من جديد. السجل السابق معلّم بأنه غير ناجح ولا يُحتسب نجاحًا.

النشر العام والدمج لم يحدثا عند تسجيل هذه النتائج؛ أوقفتهما مراجعة الموافقة الآلية بانتظار إذن صريح للوجهة العامة.

بعد تحديث وثيقة حالة البرهان، نجح أمر التشغيل ثم التحقق المستقل لإيصال الدرس المعرفي: `valid=true` و`VERIFIED_IO_REPLAY`، وبقي حكم المالك `UNKNOWN` وصدق الواقع غير مثبت. يُحفظ الطلب والإيصال المضغوط وبصمتهما لإعادة المراجعة؛ تغير الشيفرة أو الثنائيات يتطلب توليد إيصال جديد.
