# Derivation evidence, version 1

This directory separates source review, authored implementation, independent
material, measurement, and release replay. None of the files grants a caller
authority to replace an installed runtime law or to promote a shape into an
attested lexical reading.

## Source review

- `source_audit_mashru.{json,md}`: pinned Mashru definitions, premises and gaps.
- `source_audit_alghanem.{json,md}`: literal templates, transforms, candidate
  relation, root/pattern collisions, availability and source-scope boundaries.
- `source_audit_other.{json,md}`: seven other repository trees. Current heads
  could not be verified for Qeyas/alasmaa; those findings use their pinned
  local snapshots. Their absence of Lean morphology contracts is not a claim
  about inaccessible later revisions.
- `nominal_pattern_sources.json`: 27 newly authored grammar projections with
  source windows from two books. These are not inherited Lean classifiers.
- `requested_category_coverage.json`: the 21 requested categories and all 71
  pattern IDs, with prerequisites and remaining coverage limits.
- `formal_contracts.md`: all 55 new theorem scopes, source-template fidelity,
  and the distinction between general Lean proofs and Python boundary checks.

## Independent material and transparent run history

`independent_cases_v1.json`, `independent_protocol.md`, and
`independent_material_freeze_v1.json` were frozen before the reviewer opened
the implementation. The 96 cases include positive coverage of 44 core
templates. They do not independently certify positive examples of every
later-added nominal projection.

`pre_first_run_review_v1.json` records the quoted-shape correction prompted
by frozen case DER-B25 before measurement. The candidate reader now retains
quoted occurrences as mentions and never uses them for future attachment.

`independent_first_run_v1.json` and its code archive are immutable. Its raw
6/96 result was invalid as a morphology measurement: the adapter sent source
identifiers outside the existing identifier language. `adapter_erratum_v1.json`
records that defect, both adapter hashes, and the unchanged gold material.
The second run and its separate code archive record 96/96 after this adapter
correction. `independent_review_v1.md` explains the component denominators
and additional 16 review tests.

## Runtime identity and release

`code_freeze_v1.json` and its archive pin 49 authoritative package/config/data
files. Historical freezes under other evidence directories are unchanged.
Evaluators have an explicit new pin for this version and retain their older
pins; no caller-supplied checksum can authorize a replacement.

`release/validation.json` records the actual full gate, installed-wheel
verification and source limitations. Its companion archive contains the
verification records; the manifest names each record's bytes and checksum.
Passing the gate preserves documented earlier coverage boundaries rather
than treating those unresolved cases as successes.
