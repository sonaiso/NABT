# التحقق النهائي للتصحيح `0.13.0a2`

اجتازت لقطة `v4` بوابة `make check` كاملة برمز خروج **0**، مع **812
اختبارًا** و**625 تصريحًا مبرهنًا** ومطابقة تصدير Lean. لا يغيّر التصحيح
قانون Lean السابق؛ يصحح اختيار السؤال من البدائل المرخصة المكتملة.

تحسنت [مراجعة العيب](../review_v1.md) من **2/6 إلى 6/6**. منها حالتان عبر
القارئ الحقيقي وأربع تعزل عقد المستهلك، وجمدت قبل الإصلاح. بقيت
[إعادة المادة السابقة](../../independent_query_selection_review_v1/comparison.json)
**57/86**، ومنها **12/30** حلقات إيجابية و**24/45** سؤالًا فعليًا، مع صفر
قبول خاطئ مرصود. `strict_pass=false` و`coverage_complete=false`؛ لا تضاف
الحالات الست إلى مقام المادة السابقة.

الحزمة النهائية تثبت مطابقة **67/67** ملف مصدر وإعداد و**68/68** ملفًا
مثبتًا، ونجاح **15/15** فحصًا. تحفظ **20 أمرًا** فعليًا بسجلات منفصلة
وجرد موحد، وتفحص بايتات كل ملف في manifest استقلالًا عن ملخص النجاح.

## الملفات

- `validation.json`: الأمر وخروجه، وبصمات القفل والمقارنة والمراجعة والحزمة.
- `verification-source-manifest.json`: بايتات التنفيذ وLean والأدوات
  والاختبارات والتهيئة والأمثلة والتوثيق في التصحيح النهائي.
- `make-check.log`: المخرج الكامل للبوابة.
- `checks/`: نسخ مطابقة بالبايت من `artifacts/local/discourse-release-a2/`؛
  تبقى المسارات الأصلية داخل السجلات دون إعادة كتابة، والآثار الخام وأرشيفات
  التنفيذ موجودة بجوار النتائج المنقولة.
- `package/`: الحزمة المعتمدة ومدخلاتها ومخرجات الأوامر وسجل التثبيت
  المستقل خارج شجرة المصدر. لا تستند مطابقة الحزمة إلى الاستيراد من `src`.
- `packaging_attempt1/` و`packaging_attempt1_review.json`: محاولة a2 الأولى
  محفوظة كما وجدت. أعلن فاحصها نجاح التشغيل، لكن فحص manifest اللاحق
  وجد `commands.json` عند 19 أمرًا بدل 20 وببصمة مختلفة. لم تعدّل النسخة
  الأصلية لإخفاء ذلك، ولم تعتمد كحزمة نهائية. سبب رجوع السجل غير مثبت؛
  يسجل الفاحص المصحح كل أمر مرة واحدة ويكتب الجرد الموحد مرة نهائية.

يحفظ [سجل a1](../../release/validation.json) فحوصه ومحاولاته بوقتها.
هذا السجل محلي؛ نتيجة CI ترتبط بإيداع التصحيح الفعلي على GitHub بعد
نشره. تظل [حدود التغطية](../../../../docs/ROADMAP.md) مستقلة عن نجاح البناء.
