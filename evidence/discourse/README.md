# سجل الشخص والإحالة والخطاب

نسخة التنفيذ `0.13.0a1`، واللقطة النهائية `code_freeze_v3.json`.
يحفظ هذا المجلد البحث، والعقود، والمادة المستقلة، والمحاولات والتصحيحات
والبوابات الفعلية. لا تعد اللقطات الثلاث إصدارات منشورة سابقة؛ هي
مراحل تنفيذ محفوظة داخل هذه الجولة.

## النتائج

| المقياس | v1 | v2 | v3 |
|---|---:|---:|---:|
| الحالات الكاملة المختلطة | 68/86 | 57/86 | 57/86 |
| الحلقات الإيجابية | 19/30 | 12/30 | 12/30 |
| نقل صورة طرفية محجوبة | 4/4 | 2/4 | 2/4 |
| الأسئلة ذات الجواب الفعلي | 36/45 | 24/45 | 24/45 |
| ضوابط غياب السند | 29/29 | 29/29 | 29/29 |
| القبول الخاطئ المرصود | 1 | 2 | 0 |

هذه مادة مؤلفة مستقلًا قبل فتح التنفيذ، مع شواهد QAC وفرضيات سياق
صريحة؛ ليست corpus طبيعيًا محكمًا بشريًا. القياسات اللاحقة للمراجعة
انحدار على مادة مفتوحة. لا يثبت صفر قبول خاطئ مرصود سلامة كل استعمال
مستقبلي، ولا تثبت إعادة الفحص صدق الخبر في العالم.

تبقى `strict_pass=false` و`coverage_complete=false`. تقبل بوابة الانحدار
النهائية فقط إخفاقات تغطية محددة باللقطة والحالة والفحص، ولا تسمح بقبول
خاطئ أو خلل سلامة أو إعادة فحص أو خطأ تنفيذ أو إخفاق جديد غير معلن.

الجنس غير المشهود، ومفرد التكسير، والإعلال العام، والتعلق والحذف الواسعان
والمجال المفتوح للإحالة والدلالة تبقى أعمالًا في [ROADMAP](../../docs/ROADMAP.md).
