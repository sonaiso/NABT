# التحقق النهائي للإصدار `0.13.0a1`

اجتازت اللقطة `v3` بوابة `make check` كاملة برمز خروج **0**، مع **806
اختبارات** و**625 تصريحًا مبرهنًا**، ومطابقة تصدير Lean. سجل الحزمة يثبت
نجاح **15/15** فحصًا من تثبيت مستقل خارج شجرة المصدر.

هذا اجتياز لبوابات الإصدار المحدودة. التغطية الصارمة للخطاب **57/86**،
ومنها **12/30** حلقات إيجابية، ما زالت غير مكتملة. انخفاضها عن اللقطة
الأولى محفوظ، والبوابة لا تسمح بقبول خاطئ مرصود. يعرض
[التقرير الكامل](../../../docs/DISCOURSE_EVALUATION.md) المقامات والحدود.

## الملفات

- `validation.json`: الأمر الفعلي وخروجه، وملخصات القياسات وبصمات المراجع.
- `verification-source-manifest.json`: بايتات التنفيذ وLean والأدوات
  والاختبارات والتهيئة والأمثلة والتوثيق وقت التحقق النهائي.
- `make-check.log`: المخرج الكامل للبوابة النهائية.
- `checks/`: نسخ مطابقة بالبايت لنتائج `artifacts/local/discourse-release-final/`.
  بقيت المسارات الأصلية داخل السجلات دون إعادة كتابة؛ توضع الملفات الخام
  وأرشيفات الشيفرة المنقولة بجوار تقاريرها هنا.
- `package/`: الحزمة النهائية، ومدخلات فحصها وأوامره ومخرجاته وجرد الملفّات.
  يثبت `package/validation.json` مطابقة 67 ملف مصدر وإعداد و68 ملفًا مثبتًا،
  ومطابقة README المضمن داخل METADATA.
- `pre_final_checks/`: سجل البوابة السابقة على v2، وسجل محاولة v3 التي
  توقفت عند قائمة حدود P09 الناقصة، ونتيجتها الخام وأرشيفها دون محو.

لقطة runtime النهائية مجمدة قبل القياس. الأرقام والصور السابقة لم تُعدّل.
نتيجة CI البعيدة ترتبط بإيداع طلب الدمج على GitHub؛ هذا السجل المحلي لا
يسبقها بادعاء نجاحها ولا يحتوي مفاتيح اعتماد.
