# Independent nominal-number-weakness evaluation protocol v1

This authored source-informed material was frozen before the independent reviewer opened the new nominal runtime, generated table, new formal module or implementation tests. It is not an untouched external corpus or an estimate of Arabic-wide accuracy. The reviewer read only existing pinned primary texts/upstream Lean sources, the public API contract, and the explicit pre-freeze five-flag manqus correction.

## Freeze and adapter discipline

The JSON inputs, source descriptions, expected semantic candidates, exclusions and source swaps are immutable once their hashes are written in the material freeze. An adapter may translate output names and representations after implementation becomes available. It may not change the input, evidence prerequisites or expected semantic result to make a run pass. The output schema is deliberately not assumed by these cases. Transport source identifiers supplied by the adapter must obey the established lowercase identifier grammar.

The first actual measurement and its runtime/evaluator/test snapshot are preserved, including failing results. A discovered adapter defect or a legitimate source/oracle correction requires a separate erratum, old/new hashes and a separately saved later run. The original fixture and failed result remain intact. No post-open mutation attack is represented as part of the frozen authored set.

## Separate denominators

- Raw nominal observations and closed-pronoun projection: no expected class/root/answer is passed to the raw reader. Partially marked pronouns use the declared projection; descriptive lexical matching still uses exact UTF-8.
- Explicit source facts: class/gender/number/definiteness extraction is conditional on the supplied source claims. It is not spontaneous fact acquisition or proof that the source is true. Full finite profiles, partial information, contradictions and unsupported clauses are distinct outcomes.
- Plural-base witnesses: a declared plural kind and a licensed same-source singular base are separate claims. A missing base does not erase an explicit plural-kind claim; it prevents borrowed origin/counting authority.
- Manqus: noun, inflected, necessary final ya, preceding kasra and unshaddad final ya are independent premises. The fifth flag was added before freezing because a written geminated final ya must not pass the four-premise shortcut. Missing unshaddad evidence is unknown; observed final shadda provides negative evidence.
- Given-root classification: root operands are supplied, exact and canonical. Their weak positions are classified independently of nominal manqus or lexical root attestation. Initial-adjacent and triple-weak residual masks must not be mislabeled as standard lafif categories.
- Cardinal rules: strict typed values and singular gender select requirements in the stated 1..99/100/1000 domain. These requirements do not establish actual role/case or counted objects.
- Count phrases: cardinal value, observed numeral gender, expected numeral gender, singular-base gender, noun grammatical number and source linkage remain separate. Digit strings do not provide observed grammatical gender.
- Textual counts: count distinct source Arabic written-run occurrences, including quoted mentions, and exclude non-Arabic runs. Two references to the same source span do not create two objects; one dual word remains one written occurrence.
- Replay: raw source, lexical source, scope, and both source identities are bound independently. Omitted lexical text and explicit withdrawal by None are different verifier operations.

Report disjoint authored case groups and these overlapping task denominators separately. Blanket deferral fails the required positive profile, pronoun, root, rule, phrase and count cases. Accepting every candidate fails exclusions and contradictory/missing-evidence cases. Unsupported categories and rejected typed inputs are not positive lexical coverage.

## Source-informed limits

Qatr 414–417 and Alfiyya 966–967 scope the three-to-ten opposition rule; the latter refers to the gender of the singular units. Compound/tens rules have separate requirements. Qatr 122–149 supplies separate causes of definiteness; tanwin and al-like letters are not a single classifier. Qatr 82–95 and existing Mashru ending theorems concern already known nominal categories. The historical use of manqus in some Sibawayhi passages includes final-alif forms and cannot be automatically mapped to the later nominal final-ya category. Alghanem weak-root proofs receive roots/conditions and prove scoped transformations, not their unrestricted lexical truth.

Every retained observation, source assertion, root operand, lexical-base link and count relation must carry the information needed for exact replay. Mathematical finite model checks, bounded conformance, authored examples and unrestricted language coverage are different evidence types.
