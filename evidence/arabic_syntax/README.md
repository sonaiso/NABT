# دليل توسعة الأساليب العربية `0.5.0a1`

تجتاز النسخة بوابة البناء وإعادة الفحص، لكنها **لا تجتاز تغطية العربية
الأوسع**: النتيجة الأولى المستقلة 0/40 حلقة، و0/8 شواهد أصلية، مقابل 8/12
في ملحق الملف المعلن. لا يدخل التعليق الآمن في عدد القراءات المكتملة.

## المدخلات والتثبيت والقياس

- [`code_freeze_first.json`](code_freeze_first.json): جرد الثلاثين ملفًا
  التنفيذيًا وتاريخ التثبيت وهوية الأرشيف؛
  [`code_freeze_first.tar.gz`](code_freeze_first.tar.gz) يحفظ البايتات المقيسة.
- [`independent/README.md`](independent/README.md): المواد المعدة مستقلًا،
  تفسيراتها ومراجعتها، مصادر المقاطع، التسلسل، النتائج الأولى، وخط الأساس.
- [`ARABIC_SYNTAX_EVALUATION.md`](../../docs/ARABIC_SYNTAX_EVALUATION.md):
  تفسير النتائج وحدود العينة والفصل بين التغطية وسلامة الاعتماد.

أعد وكيل تقييم المواد قبل رؤية تنفيذ القارئ الجديد وراجعه وكيل ثانٍ؛
لم يجر تدقيق خبير لغوي بشري في هذه الجولة. الفصل إجرائي بين الوكلاء داخل
مساحة مشتركة، وليس ضمان عزل بصلاحيات الملفات. بعد النشر تصبح المواد
اختبار انحدار عامًا، ولا تعاد تسميتها اختبارًا محجوبًا.

## بوابة الإصدار المحلية

نجح `make check` النهائي على Python 3.12.14، وخروج العملية صفر:

| الفحص | النتيجة |
|---|---:|
| اختبارات بايثون | 271 ناجحًا، صفر تخطٍّ |
| بيان المبرهنات المبني والمدقق | 258، منها 33 مبرهنة جديدة |
| مسلّمات المشروع الخاصة | صفر؛ المرصودة `propext`, `Classical.choice`, `Quot.sound` |
| مطابقة جدول الصيغ بتصدير Lean جديد | 11,252 انتقالًا وكل بيانات الجدول |
| مطابقة دليل الخصائص | 4,096 حالة، صفر اختلاف |
| مواءمة عقد الأساليب | 8 رموز مزاج، مدخلا لغة، 48 غلاف خلايا |
| انحدار اللغة المضبوطة السابق | 60/60 حلقة، 126/126 سؤالًا؛ أصله الأصلي محفوظ |
| تثبيت الحزمة خارج المستودع | القارئ والسؤال والسحب والتعارض وإعادة الفحص نجحت |

السجل النهائي في [`release/validation.json`](release/validation.json)،
والخرج في [`release/gates.log`](release/gates.log)، وتثبيت الحزمة في
[`release/wheel-validation.json`](release/wheel-validation.json).
أصل القياس الأول في `independent/first_results.json` مستقل عن إعادة الفحص
المنشورة في [`release/arabic-regression/receipt.json`](release/arabic-regression/receipt.json).
تظل نتيجة 0/40 و0/8 ظاهرة في إيصال نجاح بوابة الانحدار؛ نجاحها يثبت حفظ
السلوك المحدود، لا اكتمال هدف N4-ب أو بوابة العمومية.

## إعادة التشغيل

```sh
make check LAKE=/path/to/lean-4.34.1-linux/bin/lake
```

يختار Makefile مجلد مخرجات جديدًا لكل تشغيل. يحمي مقيّم العربية كل `evidence/`
من الكتابة المباشرة؛ مخرجاته تكون في `artifacts/local/` أو مسار خارجي جديد.
نسخت مخرجات تشغيل الإصدار إلى مجلد `release/arabic-regression/` للنشر بعد
اكتماله؛ لم تتغير المدخلات أو النتائج الأولى.

البراهين العامة تخص مواصفة Lean وعقود الخفض بعد قراءة معطاة. المواءمة
العددية المحدودة لا تثبت تنقيح قارئ بايثون أو صحة تفسير كل نص. لا يعتمد
الإصدار أي قضية خارجة عن مصادره بوصفها صدقًا واقعيًا.

## إصلاح تشغيل الأداة في CI

في [التشغيل البعيد الأول](https://github.com/sonaiso/NABT/actions/runs/39905101051)
نجحت وظائف Python الثلاث، وبناء Lean وتدقيق مبرهناته ومطابقة الخصائص؛
فشلت أداة مطابقة الأساليب في استيراد `nabt`، لأن وظيفة Lean لا تثبت الحزمة
ولا ترث `PYTHONPATH` من Makefile. أضيف تحديد مسار `src` من موضع الأداة نفسه.
أعيدت المطابقة بنجاح من `/tmp` مع حذف `PYTHONPATH` وتشغيل `python -I`؛
النتيجة في [`arabic-conformance-isolated.json`](release/arabic-conformance-isolated.json).
يعتمد CI الآن التشغيل المعزول نفسه. هذا إصلاح مدخل أداة الفحص؛ ملفات
runtime الثلاثون ومرجع القياس المجمّد لم يتغيرا.
