السبب الذي تعالجه محدد: وجود التحليل الصريح «أعني/أريد/أقصد بـ…» والمرشحين في المحرك لا يكفي لترخيص حركات لم يثبتها سجل الضبط. لذلك يُفصل شاهد الحركات عن تركيب العبارة وعن تعيين معنى جديد. اختيار مفردات هذه المراجعة جاء بعد معرفة بعض الإخفاقات؛ ليست تجربة اكتساب معجمي عمياء.

مصدر «الباصرة» هو [النسخة الرقمية المنشورة لفيض القدير](https://www.islamweb.net/ar/library/content/304/781/-%D8%AD%D8%B1%D9%81-%D8%A7%D9%84%D9%87%D9%85%D8%B2%D8%A9-). لا يطابق شريط بداية المقال ص260 دائمًا؛ أول المقال ص259 ثم تدخل الحاشية ص260. يحفظ السجل موضع المقتطف في استخراج الصفحة الكاملة وبصمتي HTML والاستخراج، ويحفظ `source_materials/fayd_qadir_basira_excerpt.txt` **المقتطف فقط** لإعادة فحصه. لم تُضم الصفحة الكاملة إلى المستودع. لم يقدم الناشر معرف إصدار ثابتًا، ولم تُقابل طبعة مطبوعة أو تُحقق نسبة التشكيل إلى المؤلف. الشاهد دليل استعمال مضبوط في هذه النسخة، لا إثبات صحة الخبر الذي شرحه الكتاب ولا حقيقة البصر الخارجية.

## قواعد التركيب وحدودها

مقطع قطر الندى، الأسطر337–345، يذكر خفض الاسم بالحرف أو الإضافة، ويفصل الإضافة المعنوية عن الوصفية ويذكر الاستثناءات. ينقل السجل المقطع كاملًا بدل اجتزاء حظر «أل» وتعميمه. القاعدة التنفيذية المقترحة أصغر منه:

- في العبارة المعجمية المثبتة `عين الماء` فقط: رأس إضافة اسمي مفرد منصوب بوظيفة المفعول، بلا «أل» ولا تنوين؛ والتابع اسم مفرد معرف مجرور. لا يولد الجرد كل إضافة ممكنة.
- في `العين الباصرة`: تشهد مادة العين في مختار الصحاح بأنها مؤنثة، ويشهد النص الرقمي بضبط الصفة. يُشترط اتفاق الجنس والعدد والتعريف والإعراب وفق قطر الندى، الأسطر377–379. لا تُستنبط دلالة التأنيث من لاحقة وحيدة، ولا يُخلط هذا التركيب بالمذكر المفرد القديم.
- لحركة `بَلِ`: يحفظ النص المصدرّي في الكتاب لسيبويه، باب تحرك أواخر الكلم عند حذف ألف الوصل، القاعدة وأمثلة خلافها. الترخيص الجديد محدود بالقراءة الموصولة أمام الاسم المعرف التالي، داخل بناء التصحيح المنفي الذي كان المحلل يقبله أصلًا. لا يرخص كل «بل» أو كل التقاء ساكنين.

توثيق القمرية إضافي ومحدود بالجذعين المثبتين، لا حكم آلي ناتج من تسمية المستدعي للحرف. تحتفظ مراجعة `lunar_article` بالمجال السابق وتضيف عين «عين» وباء «باصرة» بشواهدها. يصرح الحقل `replaces_rule_from_base` باسم مراجعتي الاتفاق والقمرية اللتين توسعتا؛ لا يستبدل غيرهما من قواعد الأساس.

## جسر التحويل المعلن

يتبع الماء السلسلة المراجعة:

`maA^'i → maA'i → maA' → مَاء`

الخطوة الأولى تسقط **علامة المد المصحفية في هذا الشاهد** لإعداد رسم إملائي معياري. الثانية تفصل كسرة الإعراب المصدرية لتعيد القاعدة اللاحقة توليد الحالة بحسب الوظيفة. هذا ليس حذفًا عامًا للعلامات ولا مساواة بايتية بين الرسمين. لا يجيز مثلًا تغيير فتحة الميم أو كرسي الهمزة أو إسقاط حركة دخلت من المستخدم. وتفصل «الباصرة» أل المصدر وكسرة إعرابه مع حفظ حركات الجذع، ثم تتولد حركة المفعول من قاعدة مستقلة.

إعادة فحص المقتطف والصف لا تثبت تفسير المصدر في النواة. تبقى `native_acquisition_proof=false` و`annotation_acquisition_kernel_proved=false` في هذا السجل. قد يبرهن المسار اللاحق حساب الجدول المشروط بهذه المقدمات؛ وعليه أن يذكر هذا النطاق بدل تحويل السجل نفسه إلى برهان تحصيل أو تواتر.

القرينة لا تزال تصريحًا لغويًا مسندًا إلى متكلمه وموضعه. النفي يستبعد المذكور ولا يوجب اختيار الباقي؛ والقول المحكي والشرط والسؤال والإحالة إلى متكلم آخر تحتاج تحليل نطاق مستقل. لم تُوسع هذه المراجعة معالجة الواو الابتدائية. اختلاف الحركة أو الإعراب أو الاتفاق يوقف **هذا الترخيص**، ولا يُسوّى بحكم بطلان العبارة في العربية كلها. ولا يجوز الحسم بـ«الحيوان المعروف» للأسد حصريًا أو استنتاج الشجاعة من الخطابة.

## إعادة فحص المادة

من جذر المستودع، ومع وجود المصدر QAC المثبت:

```sh
python tools/fetch_qac_source.py --output artifacts/local/external/quranic-corpus-morphology-0.4.txt.gz
python - <<'PY'
import gzip
import hashlib
import json
from pathlib import Path

root = Path.cwd()
review = json.loads((root / 'evidence/qualified_cue_licensing_v1/source_review.json').read_bytes())
digest = lambda data: hashlib.sha256(data).hexdigest()
base = review['base_review']
assert digest((root / base['path']).read_bytes()) == base['sha256']
sources = {}
for source in review['sources']:
    raw = (root / source['path']).read_bytes()
    assert len(raw) == source['bytes'] and digest(raw) == source['sha256']
    data = gzip.decompress(raw) if source.get('encoding') == 'gzip' else raw
    if source.get('encoding') == 'gzip':
        assert len(data) == source['decoded_bytes']
        assert digest(data) == source['decoded_sha256']
    sources[source['id']] = data
for passage in review['passages']:
    data = sources[passage['source_id']]
    selected = data[passage['start_byte']:passage['end_byte']]
    assert digest(selected) == passage['sha256']
    assert selected.decode('utf-8') == passage['quote']
    if 'form_start_byte' in passage:
        assert data[passage['form_start_byte']:passage['form_end_byte']].decode('ascii') == passage['form']
print('source bytes and passage coordinates replayed; interpretation remains a premise')
PY
```

هذا الأمر يعيد مطابقة المادة، ولا يقيس وحده تحسن الاستعمال الطبيعي أو حسم المراد أو التواتر. يجب قراءة نتائج هذه المقامات من قياسها المستقل دون تغيير المرجع القديم أو مقامه.
