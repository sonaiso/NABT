# مراجعة legacy الثالثة: constructions v2 مقابل v4

هذا المجلد هو **المراجعة الثالثة**، ويقيس runtime **constructions v2 وv4**. نتيجة runtime v3 الفاشلة في التغطية محفوظة في [المراجعة السابقة](../legacy_discourse_review_v2/)، ولم تعتمد بوابة لتجاوزها.

## النتيجة النهائية

أعيدت المادة التاريخية نفسها، 86 حالة و74 سؤالًا، بالمحول النهائي نفسه. يثبت [comparison.json](comparison.json) أن الدرجات النهائية تطابق [القياس الصارم السابق للبوابة](comparison_before_gate.json) حالةً بحالة، بعد استبعاد زمن التنفيذ فقط.

| المقياس | constructions v2 | constructions v4 |
|---|---:|---:|
| الحالات الكاملة | 57/86 | 56/86 |
| الإيجابيات | 12/30 | 11/30 |
| الأسئلة المطلوب فيها إسناد | 23/45 | 22/45 |
| أسئلة غياب السند | 29/29 | 29/29 |
| جميع الأسئلة | 52/74 | 51/74 |
| القبول الخاطئ / أخطاء التنفيذ | 0 / 0 | 0 / 0 |
| `strict_pass` | false | false |
| بوابة التغطية الموثقة عند التصريح بها | true | true |

كل عملية نهائية انتهت بخروج 0 عند التصريح بالبوابة، وكل سجل gzip مغلق ومفحوص وفيه 90 record: الحالات، وملخصات المصادر، وتحويرات التحقق المسجلة. النتائج الخام والكود وحالة خروج العملية محفوظة في [final_runs](final_runs/). لا تعني البوابة أن الحالات كلها نجحت.

## التغيران الفعليان

- **P16، `question:0`:** بقيت الوثيقة مرخصة وبقي ادعاءاها. السؤال يحفظ قراءة `N` بمتغير غير مقيّد وقراءة `ADJ` بمتغير مقيّد؛ لذلك يؤجَّل تفسير السؤال وتبقى قائمة الأجوبة فارغة. لم تُحذف قراءة مصدرية لتحسين الدرجة.
- **P26، `reading:0`:** رأس الإضافة اسم مصدري معلوم الجنس مجهول العدد؛ لا يملأ السياق هذا المجهول. بعد تعليق اتفاق الخبر لا يفعّل التحليل دور المضاف إليه. إخفاق الادعاء والسؤال في هذه الحالة موجودان في v2 أصلًا؛ الجديد فقد تفعيل الدور.

الخام المختصر والتشخيص في [observed_limits.json](observed_limits.json)، والقرار المنفصل في [gate_review.json](gate_review.json). سمح القرار فقط بتوقيع `P16/question:0` ذي `DEFER` وقائمة فعلية فارغة ومتوقعة `[h,s]`، وتوقيع `P26/reading:0` على الموضع والدور المسجلين، فوق سياسة v2 السابقة. لا استثناء للقبول الخاطئ أو أخطاء التنفيذ أو سلامة التقرير أو الإعادة أو اكتمال السجل الخام. ظلت سياسة v2 وسياسة discourse v4 التاريخية دون تغيير، وظلت constructions v3 غير معتمدة.

## المحول والشواهد

توسع المحول لقراءة متغير السؤال ذي الجنس والعدد المحفوظين وفحص `predicate_agreement_bindings` مستقلاً عن مساعد التنفيذ. يلزم سياق شخص صريح مطابق وشهادة `ADJ` على الادعاء نفسه والقراءة والمرجع نفسيهما. يُرفض التحليل الذي يضم أكثر من شكل دلالي واحد للادعاء حتى لا تستعير المطابقة شاهدًا من وقت أو نطاق مختلف. لم تتغير دوال scoring أو توقعات الذهب.

بايتات الأداة والاختبارات قبل قرار البوابة في [source_before_gate](source_before_gate/)، وبعد إضافة السياسة المحددة في [source_after_gate](source_after_gate/). مرّ المحول النهائي باختباراته **49/49**؛ سجلها [gate_tests.log](gate_tests.log). هذه اختبارات عقد وتحوير مؤلفة بعد المراجعة، وليست ذهبًا جديدًا. يثبت [integration_v4.json](integration_v4.json) مصادقة اللقطة ذات 74 ملفًا ورفض تعديل manifest، مع سجل اختبارات Arabic السبعة.

النوافذ المصدرية وحدود التسمية والاستفهام موضحة في [CONSTRUCTIONS_CONTEXT_REVIEW_V4](../../../docs/CONSTRUCTIONS_CONTEXT_REVIEW_V4.md). صدق مقدمة السياق في العالم وصحة تحليل العربية العام ليسا من نتائج هذه المقارنة أو قانون Lean المشروط.
