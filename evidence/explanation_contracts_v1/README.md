# Explanation contracts v1 evidence

This is evidence for a versioned extension of the existing explainable pilot,
not a new language law, semantic engine, proof catalogue, or source registry.

- `acceptance_cases.json` is the independent authored nine-case matrix frozen
  in `80fb975` before implementation. It is public engineering material.
- `baseline_answer_v1.json` was produced before the change with the then-current
  checker. Do not rewrite its hash to make it a receipt from another executable.
- `receipt_boundary_before.json` retains the deliberately mocked process
  response that exposed the old wrapper's protocol-consistency gap.
- `budget_boundary_before.json` retains the actual accepted-input serialization
  problem and carefully distinguishes its first observation from later hashes.
- `validation/first_independent_tests.*` preserves the initial 16-method result.
- `validation/exposed_independent_tests_review1.*` records the later 17-method
  result including the large CLI roundtrip regression and revised scope wording.
- `validation/native_gate_first.*` is the retained Lake environment failure;
  `native_gate_environment_retry.*` runs the same pinned command successfully.
- `validation/existing_integration_tests.*`, `existing_pilot_evaluation.json`,
  and `cli_replay.json` retain the existing consumer and entrypoint executions.
- `validation/reuse_signed_inference.json` is a selected report from the existing
  reuse framework. It records proof/source matches and routes, not a new proof
  or a claim that every referenced capability ran.
- `validation/verification_summary.json` binds the successful gates to
  implementation commit `c7ebc6b083431208fdb88c24edf76e6e8bb583dc`, input hashes,
  the actual native executable, and explicit remaining limitations.

The implementation changes no `formal/` or `src/` files. A later documentation
and results commit does not change the tested implementation. Preserve all
historical pilot evidence and all attempts here. Do not aggregate repetitions,
subcase counts, source counts, theorem counts, or separate gates into a single
Arabic-intelligence accuracy measure.
