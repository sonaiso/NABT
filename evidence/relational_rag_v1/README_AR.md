# تحقق وصلة العلاقات

اجتاز فحص البوابة الأصلي 36 اختبارًا دون تخطٍّ، واجتازت فحوص إعادة الاستعمال
والفهرس والتبعيات المجمدة 46 اختبارًا دون تخطٍّ. يحفظ `results.json`
الالتزام المقيس والأوامر والبصمات وحدود الدعوى، وتحتوي ملفات `.log.gz`
السجلات الفعلية. لم يُعد تشغيل `make check` الجامع لهذه الإضافة، ولم
تتغير النواة أو مصادر Lean أو ملف CI التاريخي المثبت.

تستعمل التجارب أمثلة NABT التعليمية المعلنة؛ ليست بيانات قياس واقعي.
تظهر نتيجة الاستدلال `SUPPORTED` مع الجسر و`UNKNOWN` عند سحبه، وتبقى
شهادة الربط الأنطولوجي العام `DEFER` في الحالتين. فهرس المبرهنات الحالي
هو المرجع الوحيد، وإحالات العائلات لا تعني برهان تغطية كل بطاقة.

نجح أيضًا تشغيل مثال العالم عبر البوابة والتحقق المستقل من إيصالها بعد
تحديث وثيقة حالة البرهان. يُحفظ الطلب والإيصال المضغوط وخرج التحقق؛
تغير الشيفرة أو الثنائيات يتطلب توليد إيصال جديد.
