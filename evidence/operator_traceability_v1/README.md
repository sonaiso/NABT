# Explicit conditional operator traceability

`registry.json` supplies current metadata for the 24 entries designated
`new_scoped_conditional_operator` in the frozen
`evidence/arabic_completion_v6/rule_implementation_crosswalk.json`. It fills
18 previously absent explicit theorem references and ten null implementation
scopes without modifying that historical crosswalk or adding grammar semantics.
The six existing hamza references and every existing nonempty scope are retained.

The source catalogue uses schema `nabt.grammar-retrieval-catalog.v2` for this
additive view. Its 125 selected policy entries remain the same: all 24 designated
operators now have explicit scope and theorem metadata. The other 101 entries
are outside this registry's denominator. Neither these counts nor successful
link resolution count all Arabic rules.

| Operator family | Count | Referenced existing declaration | Actual theorem conclusion |
|---|---:|---|---|
| Hamza | 6 | `Nabt.ClassicalHamza.enumeration_exact` | Operation membership iff `Admissible`, for a supplied typed frame |

| Ana boundary | 1 | `Nabt.ClassicalBoundaryAffixes.ana_exact` | Alternative membership iff `AnaLicensed` |

Each row records the implementation path, implemented subset, formal
specialization, exact Lean declaration-header bytes and a separate proof-scope
description. These header bytes include the binders and proposition, stopping
before `:=`; their SHA-256 is **not** the compiled AST statement fingerprint.
The catalogue replays their byte/line coordinates and checks the declaration
against the manifest. The compiled link gate separately resolves the names in
a freshly compiled proof catalogue.

The scopes keep key limits explicit. Weak-letter enumeration does not bind
controls to the actual `Window` or establish the Python adapter. Gemination
enumeration does not prove payload shape checks, and Bakr's unspecified vowel
does not become a completed surface. Nun assimilation does not adjudicate the
retained source discrepancy. Ana's minority pause remains unsupported. The
boundary theorems do not acquire root, person, mood or source profile from text.

The registry's claims of source fidelity, free-text premise acquisition,
Python/Lean refinement, whole-source-rule completion and whole-Arabic
completion are all false. Explicitly linking an existing conditional theorem
does not establish those separate obligations.
