# المرجع المستقل لموجة ترحيل الواجهات الأولى

هذه مجموعة تطوير مستقلة التأليف، لا اختبار أعمى. قرأ المراجع العقد المقترح للغلاف المحدود ومعرفات المعاني المعجمية المثبتة قبل التأليف؛ لم يشغّل التنفيذ الجديد قبل تثبيت `cases.v1.json`. تحفظ `freeze.json` البصمة والتوقيت. لا يجوز تعديل المجموعة لتحسين نتيجة التنفيذ؛ أي تصحيح للمرجع نفسه يحتاج إصدارًا جديدًا وسببًا مستقلًا مع الاحتفاظ بالقديم.

المجموعة 32 حالة: 16 داخل **غلاف الحدود المعلن**، و14 خارجه، وحالتا علامات غير صالحة. وصف «داخل الغلاف» لا يعني صحة العربية أو اكتمال التمثيل أو صدق الحدث. تشمل الحالات الموجبة جسمًا مجهولًا، ورمزًا غير عربي، وجسمًا غير محكوم التركيب؛ فإذا نجح الغلاف يجب أن تبقى هذه الجهات غير مبرهنة. تشمل الحدود النفي، والقول المحكي، واختلاف المتكلم النصي، والشدة، والمسافة غير القابلة للكسر، وصورة همزة Unicode مختلفة. يظل مقام المتكلم المرسل في C01/C02 مدخلًا مقدمًا من المستدعي؛ لا هوية مكتشفة.

تقاس جهتان مستقلتان:

1. **حدود المصدر وسلطة الدعوى:** مطابقة المصدر والمقام والبايتات والقرينة والواو، ربط طلب النواة وإيصالها بالدعوى، ومنع ترقية ذلك إلى مراد أو حقيقة خارجية. في الحالات الخارجة لا يساوي الامتناع تخطئة العربية.
2. **اختيار القارئ التشخيصي اللاحق:** مقارنة المعاني المعادة بالأهداف المؤلفة يدويًا. لا يتحول نجاح هذه المقارنة إلى برهان مراد، ولا يمنح إخفاقها إخفاقًا صوريًا لمبرهنة حدود مستقلة صحيحة. قياس اختيار فارغ مطلوب يميّز عن الاختيار الموجب ولا يعالج بوصفه نجاحًا في حسم المرجع.

تبقى ملفات المرجع الطبيعي القديم ونتيجته 1/6 ومقام 0/5 مستقلين؛ لا تضيف هذه الحالات إلى مقامهما أو بسطهما. ليست المجموعة قياسًا للتواتر أو للعربية كلها.

بعد بناء `discourseBoundaryCue` وتسجيل السطح العام، يعاد التشغيل في ملف محاولة جديد:

```bash
PYTHONPATH=src:. python evidence/legacy_migration_v2/independent_review/run_reference.py \
  --output evidence/legacy_migration_v2/independent_review/attempt1.json.gz
```

يرفض القارئ تبديل المرجع أو الكتابة فوق محاولة سابقة، ويحفظ الأجوبة الخام وهوية المصادر والتنفيذ. إن تغيرت الشفرة بعد محاولة، تعاد في ملف جديد ويُذكر سبب الإعادة. أي تشغيل بعد رؤية النتائج هو إعادة اختبار تطوير لا اختبار أعمى.

## المحاولة الأولى

تحفظ `attempt1.json.gz` الأجوبة الخام للحالات32. نجحت حدود المصدر وربط الطلب وإيصال النواة ومنع ترقية السلطة في32/32. وفي مقام منفصل تطابقت أهداف الاختيار التشخيصي16/16: عشر حالات ذات اختيار موجب، وست حالات يتطلب المرجع إبقاء اختيارها فارغًا. ليست الست الأخيرة ست حالات إضافية لحسم المراد؛ ولا الاختيارات العشر براهين على مراد المتكلم أو صدق الواقع. بقيت الحالات16 الخارجة أو ذات العلامات غير الصالحة خارج مقام قياس الاختيار اللاحق.

اختبارات `tests.test_independent_legacy_migration_attackcases` الستة نجحت أيضًا: الإيصال المصطنع المتسق البصمات لا يحصل على سلطة؛ وتغيير الطلب أو الدعوى أو المسار أو إضافة سلطة يفسد الربط. هذه اختبارات نزاهة نقل، وليست توثيقًا لصدق النقل المستورد.

## مراجعة النقل والخطة

قورنت خريطة الطبقات بملف `framework_foundation.json` المستخرج مباشرة من الالتزام `8b948d8`، لا من سجل حي تغيّر لاحقًا. تطابقت البصمة والطبقات104؛ وحفظ الطابور104 مداخل مراجعة و7 وسائط دون حذف أو ازدواج أو ترقية الحالات، موزعة على18 أسرة هندسية. المصفوفة الحية اللاحقة تحتوي97 صف أمر:69 فيCLI الأساسي، و4 للنحو، و5 للحقيقة اللغوية، و1 للاستدلال، و4 للمنطوق، و7 للبوابة، و7 للمختبر. تطابق مقامCLI الأساسي مع parser الفعلي. اثنا عشر صفًا موسومًا بجسر طفل أصلي تشمل إعادة نقل الطفل نفسه؛ ليست12 مبرهنة لغوية مستقلة. بقي54 صفًا في `LEGACY_AUTHORITY_EXPLICIT_BRIDGE_PENDING` وصفان في `CONDITIONAL_BRIDGE_PENDING` عند المراجعة.

تحفظ `gateway_transport_attempt1.json.gz` خمسة إيصالات تنفيذ محلي فعلية: غلاف قول محكي، وحدّ نفي وقرينة، واستدلال مصدري؛ لكل منها دعوى محددة واحدة. ويضاف إليهما تأجيل عملية مجهولة وإدخال غير صالح، كلاهما بلا دعوى. اجتازت الخمسة المدقق المنفصل في JavaScript مع مطابقة النصوص والبصمات وطلبات الأطفال. لا يمثل ذلك تشغيلًا مستضافًا أو إثباتًا لصدق المنقول.

المدقق الجديد `web/transport-contract.js` أُنشئ بتكليف إضافي من مدير العمل؛ لذلك مراجعة تأليفه ليست مراجعة عمياء مستقلة عن مصممه. تختبر وحدته36 حالة تشمل المفاتيح المكررة، والأعداد غير الآمنة، والكسور التي تفقد أرقامًا عند التحويل، وتسمح بالمقاييس العشرية المعتادة دون إعادة تسلسلها قبل حساب البصمة. يقيد سياسات النقل والمسارات والقوانين المعروفة، ويحفظ إيصال الموارد ذي ملخص البصمة فقط، ويترك فاحص كل مجال سابق ضروريًا. هذه الفحوص لا تصدق إيصالًا مستوردًا ولا تنفذ Lean ولا تضيف سلطة برهان.
