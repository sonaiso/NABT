# Legacy migration wave 1: denominator and review queue

`migration_queue.json` is a reproducible engineering backlog, **not a proof
receipt or a new benchmark result**. It partitions the 104 acquisition/review
surfaces in the immutable v1 inventory into 18 dependency families. All seven
transport surfaces point to command-specific lifecycle review; a successful
command does not migrate its entire CLI or server.

The baseline is `8b948d8538373a9c69100c79253f58d7b5aa358f`, whose tree equals the
published `8203c8ce1c2072c7659191b2a7194ce9f29555ad`. `baseline_layers.json`
retains the reviewed layer assignments extracted from that exact registry.
The builder checks the original inventory and the layer assignment hashes.
It does not import or execute the evolving production code to recalculate the
historical denominator.

Each acquisition row names its public entrypoint, numerical domain, owner
role, existing Lean modules to review, remaining proof obligations, family
dependencies, and a reproduction command. The commands are available checks,
not claimed new runs. The lifecycle stays `NOT_ASSESSED_BY_QUEUE` beyond the
inventory step. Existing theorem files are review references: their presence
does not discharge source acquisition or Python refinement.

```bash
python evidence/legacy_migration_v2/build_queue.py --check
PYTHONPATH=src:. python -m unittest tests.test_legacy_migration_queue -v
```

`src/nabt/data/transport_command_contracts.json` is the separate installed
command matrix. It governs command-specific metadata/transport behavior, not
proof merely by registration. New commands and new surfaces are compared to
this historical queue explicitly; they do not rewrite its 104 + 7 baseline.

No runtime or runner freeze has been generated by this queue builder. Preserve
the previous `interface_migration_v1` v5 identity, raw failures/successes, source
archives, gold cases, and thresholds. After production contracts stabilize,
create a new identity and compare the exact delta. Reuse immutable archives by
content hash rather than copying them into every new attempt.
