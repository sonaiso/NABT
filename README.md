# NABT — نواة جبرية مستقلة للغة المرخّصة

**التطوير الحالي: `0.3.0a1` — ماكينة التكامل التجريبية.** NABT هو موضع التنفيذ النهائي المستفيد من Mashru وAlghanem وQeyas وTaaqol-GPT ومستودعات الدال والمدلول والحامل. يرمّز الخانات العربية، ويحسب انتقالاتها ويعدّ صيغها، ويربط خاصية محددة ببايتات مصدرها، ويتعلم شروطًا ضمن لغة معلنة، ويعيد حساب الجواب عند تغير الشاهد. مصدر قانون الانتقالات هو Lean، والتنفيذ العملي بايثون بلا تبعيات تشغيل خارج المكتبة القياسية.

الترخيص في هذا المشروع **ترخيص حسابي بالنسبة إلى قانون معلن**. قبول صيغة لا يثبت ورودها في السماع، ولا يثبت جذرها أو وظيفتها النحوية أو معناها. راجع [حدود البرهان](docs/PROOF_STATUS.md) قبل بناء نتائج أعلى على هذه النواة.

## ما يعمل الآن

- أبجدية ثابتة: 29 حاملًا × 4 حالات تشكيل = **116 خانة**.
- ترميز عددي قابل للعكس، ووصل وفصل وتبديل، وإطار بتات معياري بسبعة بتات للخانة.
- هوية وقوع تحفظ المصدر ونسخة التحليل والموضع والخانة.
- قانون صيغ من **97 حالة**، وجدول **11,252 انتقالًا** يصدر من Lean.
- حساب أثر قطعة النص من كل حالة، وتركيب الآثار مع حفظ المادة الأصلية.
- عدّ ديناميكي للصيغ عند وزن محدد، وترقيمها وفكّ رتبها، بلا توليد المجموعة كاملة.
- مساران محددان للنهاية: `wasl` و`waqf`؛ وهما لا يشكلان حتى الآن محلل جمل أو قانون وصل كلمتين.
- شهادات مغلقة الحقول يعيد الفاحص بناءها من القانون المثبت، ويكشف اختلاف المصدر أو الرقم أو المسار أو الرتبة.
- أخطاء مسماة تفرق بين الرفض `REJECT` والتعليق `DEFER`.
- قارئ استعلام منفصل يحتفظ بجميع بدائل التشكيل المسموح بها، ويحسبها بالدرجة دون اختيار معنى أو تشكيل نهائي.
- اكتساب مخطط قرارات من البتات بالأمثلة المضادة، وفحص كامل لكل انتقال قبل اعتماده؛ تصدير المخطط المحدد إلى Lean والتحقق من حفظه القانون.
- جسور صريحة بين خمس هويات أبجدية و21 تمثيلًا؛ منها فرق ترتيب Alghanem واتجاه العدد في `SLGE.encL`، مع براهين العكس والتركيب.
- سجل أدلة موجب وسالب، وإعادة قراءة تسعة سجلات محددة من ثلاثة كتب عربية قبل استعمالها؛ ست عبارات قواعد وثلاثة شواهد فعلية في مسارين منفصلين.
- تعلم جميع الشروط المتفقة مع الشواهد داخل لغة محدودة؛ سحب السند يعيد الفروض المستبعدة، والقرينة الناقصة تبقى ناقصة.
- مترجم صيغ موجبة إلى حساب خطط استكمال دنيا بالاحتواء، مع هوية القضية وسياقها، وحفظ التعارض قبل الإسقاط، وإزالة النسخ المتساوية.
- مترجم طلبات إلى برامج عددية محدودة التعليمات؛ سجل تشغيل يفحصه `verify-run` بإعادة الحساب كاملًا.

راجع [أساس نبط المستخلص من Taaqol-GPT](docs/TAAQOL_FOUNDATION.md) للتصميم، والحدود، وتجربة الاكتساب، وخطة توسيع القواعد نفسها.

مرجع هذا الإصدار: [معمارية التكامل والتشغيل](docs/INTEGRATION.md)،
[الجسور العددية](docs/BRIDGES.md)، [سند الخاصية والتعلم](docs/SOURCE_LEARNING.md)،
و[حساب المطلوب](docs/OBLIGATIONS.md). يضم `formal/theorems.json` المبرهنات
المعتمدة في NABT؛ أما فهرس تصريحات المصادر السابقة فليس شهادة بناء لتلك المشاريع.

## التشغيل

يتطلب التنفيذ Python 3.11 أو أحدث. من جذر المستودع:

```bash
python -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/nabt encode 'كَتَبَ'
.venv/bin/nabt analyse 'كَتَبَ'
.venv/bin/nabt count --weight 4 --mode waqf
.venv/bin/nabt generate --weight 4 --rank 0 --mode waqf > generated.json
.venv/bin/nabt verify generated.json
.venv/bin/nabt certify 'كَتَبَ' > certificate.json
.venv/bin/nabt verify certificate.json
```

يمكن التشغيل من المصدر دون تثبيت:

```bash
PYTHONPATH=src python -m nabt encode 'كَتَبَ'
```

### البرنامج المتكامل

```bash
nabt transcode 452621 --from-codec mashru.dal.adad.v1 --to-codec nabt.bijective116.v1
nabt compile examples/word_shape.json
nabt run examples/word_shape.json > shape-receipt.json
nabt verify-run shape-receipt.json
nabt run examples/unvocalized_word.json
nabt run examples/dhu_obligations.json
nabt run examples/source_learning_revision.json > learning-receipt.json
nabt verify-run learning-receipt.json
nabt pilot
```

`nabt execute` يأخذ `program_number_hex` من نتيجة `compile`. ولكل خطوة رقم
تعليمة وعقد ومدخل ومخرج محسوب. `pilot` يعرض التعلم من ثلاثة شواهد فعلية، ثم
سحب شاهد وإعادته وسؤالًا ذا قرينة غير معروفة. اكتمال تشغيل البرنامج قد ينتهي
إلى جواب معلّق؛ حالة النتيجة ومجالها ظاهران داخل السجل.

الأوامر تعيد JSON. الخروج `0` يعني نجاح العملية؛ `2` رفضًا أو مدخلًا غير صالح؛ `3` تعليقًا بسبب نقص مدعوم أو حد موارد. بعد نجاح قراءة الخانات، يعيد `analyse` المسار حتى إذا رفض قانون الصيغ الناتج؛ أما فشل قراءة النص فيعيد سببه دون اختلاق مسار. أوامر الترميز لا تمنح شهادة انطباق لغوي.

### مثال عددي

`كَتَبَ` يقابل `[84, 8, 4]` وعدده **1,144,809**. `كُتِبَ` يقابل `[85, 10, 4]` وعدده **1,158,497**. الحركات محفوظة في الرقم، وليست زينة تُحذف أثناء القراءة.

```bash
nabt decode 1144809
nabt split 1144809 --at 1
nabt append 85 1049
nabt replace 1144809 --at 0 --cell 85
nabt effect 'كَتَبَ'
nabt law
```

`append` وصل عددي خام؛ يفحص `analyse` أو `certify` قبول الناتج بعد الوصل. لا توجد قاعدة تقول إن وصل كلمتين مقبولتين ينتج كلمة مقبولة.

## العقد العددي

ترتيب الحوامل المثبت:

```text
ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي ء
```

وترتيب الحالات: الفتحة، الضمة، الكسرة، السكون. السكون حالة ترميز، وليس حركة صوتية قصيرة. إذا كان رقم الحامل `c` ورقم الحالة `v`:

\[
a=4c+v,\qquad 0\le a<116.
\]

لذلك تحتاج الخانة إلى **7 بتات**. القيم من 116 إلى 127 ممنوعة في إطار الخانات؛ ولا يساوي تمثيل 116 خيارًا امتلاك 116 بتًا.

للوقوع داخل مصدر محدد ونسخة تحليل محددة:

\[
n_{\mathrm{local}}=116p+a.
\]

هوية الوقوع الكاملة هي `(source_id, analysis_version, p, a)`؛ الرقم المحلي وحده لا يمنح هوية عالمية عبر المصادر.

للترميز التسلسلي:

\[
F(\epsilon)=0,\qquad F(u\cdot a)=116F(u)+(a+1).
\]

وتحفظ عملية الوصل:

\[
F(uv)=116^{|v|}F(u)+F(v).
\]

هذه الصيغة تحفظ الطول وتمنع التباس الصفر الابتدائي. لا يُستبدل ترتيب الخانات أو عدد تكرارها بملخص انتقالات يفقد مادتها.

## كيف يقود القانون التنفيذ

1. يبني Lean تعريف القانون وبراهينه.
2. يصدّر `ExportTable.lean` جميع الانتقالات والأوزان والنهايات والجهود.
3. يقرأ Python النسخة المثبتة في `src/nabt/data/law.json` بعد فحص بصمتها.
4. يقارن `tools/check_conformance.py` الجدول كاملًا بتصدير جديد من Lean.
5. يعيد فاحص الشهادة الحساب من هذه السلطة؛ حقول المدخل لا تختار قانونًا بديلًا.

يشغّل CI اختبارات Python على 3.11 و3.12 و3.13، وتجربة المصدر، والتثبيت والتشغيل خارج مجلد الشيفرة، ثم بناء Lean ومقارنة جداول الصيغ وأدلة الخصائص وتدقيق المسلّمات. تعريف CI في المستودع لا يعني وحده أن تشغيلًا بعيدًا نجح؛ نتائج كل جولة مسجلة في [evidence](evidence/README.md).

## التحقق محليًا

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
python tools/check_integrity.py
python tools/check_conformance.py --lake /path/to/lean/bin/lake
python tools/check_axioms.py --lake /path/to/lean/bin/lake
python tools/check_property_evidence_table.py --lake /path/to/lean/bin/lake
python tools/source_learning_experiment.py
make check LAKE=/path/to/lean/bin/lake
python tools/benchmark.py --output evidence/benchmark-local.json
```

الإصدار المثبت في `formal/lean-toolchain` هو Lean **4.34.1**؛ لا يعتمد البرهان على Mathlib. يمكن تثبيته بـelan، أو على Linux x86_64 استخدام المثبت المحلي الذي يفحص SHA-256 قبل فك الحزمة:

```bash
python tools/bootstrap_lean.py --destination /tmp/nabt-tools
```

يتطلب المثبت `tar` و`zstd`. السكربت لا يعدّل أداة Lean العامة المثبتة على الجهاز.

## حدود الإصدار

- يقبل القارئ كلمة واحدة، وكل حامل يتبعه بالضبط واحد من العلامات الأربع. لا يخمّن تشكيل `كتب`.
- واجهة `AmbiguityForest` المنفصلة تقبل غياب العلامة بوصفه أربعة فروض، وتعيد مجموعة مسارات. لا تغيّر عقد القارئ الصارم ولا تختار قراءة واحدة.
- الشدة والتنوين وصور الهمزة والألف المقصورة والتاء المربوطة تنتظر جسور إملاء وصوت منفصلة؛ تعاد بأسباب تعليق، ولا تُمحى أو تُسوّى تلقائيًا.
- `CVV` لا يعني حركتين متناقضتين على حامل واحد. تمثل بعض المدود بخانة لاحقة ذات وزن صفري بشرط انتقالها. بناء الجسر الإملائي العام عمل تالٍ.
- `MAX_CELLS=4096` للترميز والتحليل؛ `MAX_WEIGHT=16` للعد والترقيم والشهادات. تجاوز الحد تعليق موارد.
- العدد العشري الطويل قد يظهر `null` مع بقاء العدد السداسي الدقيق في `numeric_code_hex`؛ تقبل أوامر الأعداد الصيغة السداسية.
- توليد صيغة عند وزن 3 أو 4 لا يجعلها جذرًا ثلاثيًا أو رباعيًا مستعملًا. هذا يحتاج سجل سماع وربطًا مراجعًا بين المادة والقاعدة.
- الشهادة إثبات اتساق داخلي مع القانون؛ ليست توقيعًا رقميًا على هوية منشئها.
- مسار اكتساب الانتقالات يعيد إنتاج قانون الصيغ المثبت. مسار التعلم من المصدر يقرأ ثلاثة أمثلة فعلية ضمن إسقاط حرفي مؤلف، ويمثل ست عبارات قواعد بصورة منفصلة. لا يوجد بعد قياس لغوي محجوب أو محلل عام يستخرج قواعد من أي كتاب جديد.
- فاحص البرامج يعيد التنفيذ مقابل العقود المثبتة. البراهين تغطي أرقام العمليات وتركيب مجالاتها، ولا تمثل بعد برهان تنقيح كامل لمفسر Python أو JSON أو UTF-8.
- بيانات الكتب المرفقة لها [ترخيص مستقل](src/nabt/data/source_evidence/LICENSE-DATA.md)؛ حقوق الشيفرة المنقولة مثبتة في [NOTICE.md](NOTICE.md).
