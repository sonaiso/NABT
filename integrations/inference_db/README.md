# قاعدة توثيق المنطوق والمفهوم

امتداد اختياري لقاعدة `grammar_db` يربط المقاطع الأصلية بملفات تفسير محددة
والقواعد الشرطية ومراجع المبرهنات. يحفظ المعنى المحتمل والمقام والشرط والمانع
في هويات مستقلة؛ الربط في SQL والدرجة المتجهية لا يمنحان حكمًا لغويًا أو شرعيًا.

يشترك المخطط مع `grammar_db` في PostgreSQL وامتداد pgvector والاعتماديات
ومدقق المتجهات. للمتجهات الجديدة جدول مستقل لأن نصوص المنطوق والمفهوم تختلف
عن نصوص القواعد النحوية. كل تشغيل يثبت بصمة الجرد، وهوية النموذج، ومراجعة
من 40 خانة، والأبعاد، ووصفة المدخل. الاسترجاع يفحص جميع المتجهات المخزنة
بالمسافة الدقيقة ويدمج ترتيبها مع ترتيب النص بـRRF قبل حد العرض.
لا تتحول المسافة أو RRF إلى احتمال صحة.

## التهيئة

استخدم الاعتماديات المثبتة في `integrations/grammar_db/requirements.txt`.
ضع الاتصال في متغير البيئة `NABT_DATABASE_URL` خارج المستودع.
ابدأ بتهيئة `grammar_db` وتحميل جردها المراجع، ثم:

```bash
PYTHONPATH=src:. python -m integrations.inference_db init
PYTHONPATH=src:. python -m integrations.inference_db load
PYTHONPATH=src:. python -m integrations.inference_db search \
  --inventory INVENTORY_SHA --query 'مفهوم المخالفة'
```

`load` يعيد فتح الملفات المحلية والتحقق من بصماتها ومقاطعها؛ لا يقبل جردًا
أو بصمة يرسلها المستخدم بدل هذه العملية. هوية جرد الاستدلال مستقلة عن هوية
جرد النحو. جدول `grammar_bindings` يثبت ارتباط الإصدارين؛ تغير جرد النحو
لا يعيد تعريف هوية المصدر الأصولي. لا يستبدل التحميل صفوفًا موجودة.

للبحث المتجهي استخدم `embedding_metadata` ثم `store_embeddings` ثم
`search(..., embedding=..., embedding_run=...)`. استخرج نص كل قاعدة من
`tools.mantuq_inference.retrieval.iter_documents`، مع تطبيع البحث بواسطة
`integrations.grammar_db.client.search_projection` للنصوص والأسئلة معًا.
لا يحمّل هذا الامتداد نموذجًا ولا يستدعي خدمة خارجية تلقائيًا.
الاستدعاء البرمجي يعيد قائمة مرشحين بهويات فقط؛ أعد بناء النص المحلي:

```python
from integrations.inference_db.client import search
from tools.mantuq_inference.retrieval import InferenceSearchIndex

proposals = search(connection, inventory_sha, 'دلالة الاقتضاء', k=10)
restored = InferenceSearchIndex().rehydrate_database(proposals)
```

هذه الاستعادة تمنع استعمال نص مقتبس أو اسم مبرهنة مزور من قاعدة البيانات.
تمرير المقترح إلى محرك الاستدلال يتطلب مقدمات صريحة ومراجعة الشهادة؛ البحث
لا يستخرج هذه المقدمات ولا يختار قراءة لغوية بالنيابة عن المراجع.

## الدلالة والحدود

| الجدول | ما يحفظه | ما لا يثبته |
|---|---|---|
| `sources/passages` | البصمة وحدود البايت والنص الخام | مطابقة الطبعة الأصلية غير المفحوصة |
| `reviewed_contexts` | سياق مصدر مراجع منفصل عن إحالات المبرهنات | ترخيص الواقعة أو اكتمال ترجمة الفصل |
| `profiles/rules` | تفسير محدد وقاعدة ذات شروط معلنة | اتفاق جميع المدارس أو الترخيص في كل مقام |
| `theorem_references` | إحالة مؤلفة إلى اسم تصريح | صحة الإحالة دون إعادة تجميع Lean |
| `obligations` | دور المقدمة والسبب والشرط وانتفاء المانع | أن المفقود من المعلومات نفي ثابت |
| `lexemes/concepts/senses` | علاقة متعددة الأطراف مع مقام وملف تفسير | أن اللفظ يملك مدلولًا وحيدًا |
| `observations` | بروتوكول ودليل ونتيجة عند توفرها | صدق تجريبي افتراضي أو قانون سببي |
| `embedding_runs/embeddings` | هوية النموذج والمتجه والمخزون المفحوص | جودة الفهم الدلالي أو اكتمال العربية |

الجرد الحالي يملأ 4 مصادر مقتطفة و54 مقطعًا و9 مخططات قواعد، ويحفظ 40 وصلة
سياق مراجع لخمس قواعد في جدول مستقل. يبقى الجرد التاريخي الأول (3 مصادر
و16 مقطعًا) محفوظًا. أضيفت مقاطع السبب والشرط والمانع والقياس؛ ما زالت
ترجمتها إلى قواعد تنفيذية كاملة وتحصيل مقدماتها مفتوحين. لا يُختلق بيت من
الألفية لتسويغ قاعدة أصولية. جداول
الألفاظ والمفاهيم والملاحظات التجريبية مجهزة لكنها غير مشحونة بدلالات
أو حقائق مصطنعة. المخزون المتجهي يمكن أن يكون جزئيًا؛ يظهر ذلك في
`vector_inventory_complete` و`stored_vector_count`.

الصفوف غير قابلة للتعديل والحذف والتفريغ عبر DML العادي. مدير قاعدة البيانات
القادر على تغيير المخطط أو تعطيل الحراس يظل خارج هذا الضمان؛ لذلك تبقى
إعادة المصدر المحلي وفحص البرهان لازمين. لا توجد خانة `proof_of_completeness`
تعامل نصًا حرًا على أنه برهان.

## التحقق

```bash
PYTHONPATH=src:. python -m unittest discover -s integrations/inference_db/tests -v
```

اختبارات PostgreSQL تتطلب `NABT_TEST_DATABASE_URL` وقاعدة مؤقتة. تهيئة مخطط
استدلال موجود تُرفض. يجوز تشغيل اختبارات `grammar_db` أولًا في القاعدة نفسها.
تقيس اختبارات المتجهات اتجاهات هندسية مصطنعة؛ لا تقيس دقة نموذج عربي.
