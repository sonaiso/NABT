# التخزين العلائقي الاختياري لشبكة الدلالة

`lexical_graph.sql` امتداد إضافي للمخطط القائم، وليس قاعدة جذور موازية.
لا يغيّر `schema.sql` أو محمّل البيانات أو مسار قبول NABT، ولا يشحن أي
معنى أو فرض أو حقيقة. يركب على `grammar_db` ثم `inference_db`، ويعيد
استعمال هويات الألفاظ والمفاهيم والمعاني والمقاطع والمقامات الموجودة.

## عقد التخزين

| الجدول | وظيفته وحدوده |
|---|---|
| `lexical_graph_snapshots` | يربط لقطة الرسم بجرد ومقام وملف تفسير واحد؛ لا خلط تلقائي بين المتكلمين والاصطلاحات |
| `lexical_graph_nodes` | ذرات ذات إشارة صريحة؛ المعنى المعجمي مربوط بالمفتاح الكامل للمعنى القائم، والذرة الدلالية المؤلفة بمفهوم ومقطع مصدر |
| `lexical_graph_references` | ذكر وتعريف وإحالة وتقابل منقول (`ATTESTED_OPPOSITION`) للتنقل، مع مصدر وحالة مراجعة؛ يسمح بالدورات، ولا يستعملها قواعد استدلال |
| `lexical_graph_rules` | مرشحات قواعد مصنفة، ذات خاتمة وقاعدة أساس قائمة ومصدر؛ اسم «التضمن» أو «اللزوم» لا يمنح الترخيص |
| `lexical_graph_premises` | مقدمات القاعدة مرتبة بهوية العقدة والإشارة والدور؛ انتفاء المانع يحتاج ذرة سالبة صريحة |
| `lexical_graph_seeds` | فروض معلنة أو مقدمات نقلية مصرح بها؛ لا حقيقة افتراضية ولا بذور تولد من إغلاق دورة |
| `lexical_graph_seals` | ختم لشكل البيانات وعدد صفوفها، يمنع الإضافة بعدها؛ لا يثبت صحة تفسير أو مصدر أو برهان |

الذرة السالبة تعني مقدمة ذات إشارة سالبة في الحساب، ولا تعني أن عدم وجود
صف موجب كاف لإثباتها. يفصل `node_kind` بين وقوع معنى معجمي وبين ذرة
تفسير مؤلفة. لا يساوي `concept_id` الجذر، ولا يحذف اشتراك لفظ في أكثر من
معنى. حين يلزم الانتقال بين مقامين، يجب تعريف عقد انتقال مستقل في المحرك؛
لا يجوز نسخ صفوف من أحدهما إلى الآخر تحت SHA واحد.

علاقات المرجع ليست قواعد Horn. حتى `AUTHORED_NECESSITY_LINK` يحفظ إحالة
مؤلفة فقط. يجب أن يعيد المحول المستقبل استعادة المقاطع من الملفات المحلية
المثبتة، وأن يطابق القانون والكتالوج والبصمات، قبل إرسال قاعدة محددة
بمقدماتها إلى Lean. لا يقبل هذا الامتداد تصنيف «متواتر» أو وزن ثقة على أنه
دليل، ولا يجلب معرفة العالم من تشابه متجهين.

## القيود والفصل عن البرهان

- لا طرف فارغًا للإحالة، ولا طرفًا من رسم آخر؛ تُربط كل الإحالات والذرات
  بالقواميس والمقاطع والمقامات عبر مفاتيح أجنبية مركبة.
- لا يتكرر مفتاح العقدة أو المقدمة. يمنع الختم تكرار القاعدة نفسها بحسب
  قاعدة الأساس ونوع الاستدلال والخاتمة ومجموعة المقدمات، بصرف النظر عن
  ترتيب إدخالها. اختلاف المصادر يستحسن حفظه كشواهد على قاعدة واحدة في
  طبقة المصدر القائمة، لا باعتباره برهانًا جديدًا.
- لا تختم قاعدة بلا مقدمات؛ إذا أريدت مقدمة ابتدائية فتوضع صراحة في
  `seeds` مع أساسها ومقطعها. غياب البذور مشروع للتشخيص، ولا يجعل الدورة
  مكتفية معرفيًا. عدّ صفوف منتهية لا يثبت استيعاب العربية.
- الختم يتحقق من الأعداد وترتيب المقدمات من الصفر دون فجوات. يُقفل صف
  اللقطة أثناء إدخال الأبناء والختم. **تُقبل هذه الكتابات فقط في مستوى
  العزل READ COMMITTED**؛ يرفض الحارسان REPEATABLE READ وSERIALIZABLE
  وREAD UNCOMMITTED. قفل أب لم يتغير إصداره لا يجدد لقطة معاملة
  REPEATABLE READ، ولذلك قد يخفي ختمًا التزمت به معاملة أخرى؛ القفل
  وحده ليس ضمانًا في ذلك المستوى. تُرفض
  عمليات UPDATE وDELETE وTRUNCATE بالطريقة القائمة في مخطط الاستدلال.
- تبقى بصمة المحتوى ادعاء واردًا إلى قاعدة البيانات حتى يعيد المحول
  المستقل حسابها. كذلك حالات المراجعة حقول وصفية، وليست توثيقًا ذاتيًا.
  المدير القادر على تعطيل الحراس أو تغيير المخطط خارج هذا الضمان.

لا توجد حدود جذور اعتباطية كـ20000 أو عمق خمس خطوات. لا يحتاج هذا العقد
إلى امتداد متجهات جديد أو بعد ثابت. البحث النصي/المتجهي القائم يمكنه اقتراح
معرفات مصادر وقواعد فقط، وتظل درجاته خارج سلطة القبول. التحقق من الأنواع
الأصلية لمدخل JSON، مثل رفض Boolean مكان العدد أو العدد العشري، يقع في
المحول؛ لا تدعي أنواع SQL استعادة شكل رقم محي بتحويل سابق.

## التركيب والاختبارات

ثبّت أولًا المخططين القائمين، ثم استعمل اتصالًا مخصصًا وتهيئة ذرية:

```bash
psql "$NABT_DATABASE_URL" --single-transaction --set ON_ERROR_STOP=1 \
  --file integrations/inference_db/lexical_graph.sql
PYTHONPATH=src:. python -m unittest discover \
  -s integrations/inference_db/tests -p test_lexical_graph_schema.py -v
```

لا يتكرر تثبيت الملف في المخطط نفسه؛ فشل وجود الجداول يمنع استبدالها
ضمنيًا. هذه تهيئة للمخزن فقط؛ لا يوجد في هذه الإضافة محمّل عام للكتالوج
الجديد أو مسار قراءة للموقع. بعد استكمالهما، لا يصدّران إلا رسمًا مختومًا
بعد إعادة مقابلة المحتوى بقانون المثبت، مع بقاء المصدر وفرضه ظاهرين.
تبدأ معاملات إدخال الرسم وختمه صراحة بـ`BEGIN ISOLATION LEVEL READ COMMITTED`
ولا تعتمد على مستوى العزل الافتراضي للاتصال.

في بيئة هذا العمل لم تتوفر PostgreSQL أو psycopg أو قيمة
`NABT_TEST_DATABASE_URL`. لذلك نُفذت **خمسة فحوص ساكنة** للعقد، وتُخطيت
**تسعة اختبارات PostgreSQL فعلية**؛ تنفيذ SQL وقيوده وتزامنه غير متحقق
هنا. الفحوص الساكنة ليست بديلًا عن تشغيل قاعدة البيانات.

عند توفير قاعدة مؤقتة والاعتماديات القائمة في `grammar_db`، تشغّل
الاختبارات الاختيارية المخطط، وتختبر المفاتيح المركبة، والقراءات المتعددة،
والأطراف الفارغة، والدورات بلا بذور، والمقدمة السالبة، والتكرار، ورفض
التعديل بعد الختم. تنشئ الصفوف ضمن معاملة تُعاد كلها، وترفض استبدال رسم
مثبت مسبقًا. اختبار العزل الإضافي ينسخ نص الحارسين الفعليين إلى `pg_temp`
في اتصال منفصل ويختبر رفض مستويات العزل الثلاثة غير المقبولة، ثم يتراجع
عن المعاملة ويغلق الاتصال دون نشر مخطط. اختبار سباق معاملتين متزامنتين
في READ COMMITTED يبقى مطلوبًا قبل النشر؛ اختبار الرفض ليس اختبار سباق.
