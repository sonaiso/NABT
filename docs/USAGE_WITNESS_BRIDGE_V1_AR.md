# وصلة شاهد الاستعمال إلى الرسم والمنسق — v1

خط الأساس `4ff938eb30ec9c32bfd257ba058eb17e637e127c`. تعيد هذه الدفعة استعمال
`tools.linguistic_truth.runtime.acquire` و`Nabt.LinguisticTruth` والفاحص
`linguisticTruth`، وهويات `lexicalDenotation`، وجدول الإرسال الحالي. لا تضيف
قارئًا لغويًا أو قانون استدلال أو شبكة عصبية أخرى.

## عقد التنفيذ

يقبل `neural.graph` الآن `lexical_text` و`context` و`usage_context` اختيارية.
المعجم وسياق الخطاب يصلان كاملين إلى صاحب العلاقات. ويمررهما
`cognitive.orchestrate` عند بلوغ مرحلة المفهوم؛ كان الاستدعاء السابق يحذفهما.
تظل مدخلات المشفر العصبي النص ومعرف مصدره، فلا تتحول القرينة إلى تسمية عصبية.

`usage_context` يحمل فقط `profile_id/subject/time/context` وفق صاحب الاستعمال.
هذه مقدمات سياقية صريحة، وليست شهادات قبول. عند غياب `profile_id` يحتفظ
المالك بالاصطلاحات المحتملة ولا يختار الوضع اللغوي ضمنًا. لا يقبل الطلب
أعلام الترخيص أو الأقنعة أو أوزانًا أو مسارات ملفات أو شهادات جاهزة.

يرجع `usage_witness` تقرير المالك كاملًا، وجميع بدائله، وبصمته، ثم يصل الشاهد
بالمصدر ونسخته وموضع اللفظ بايتيًا وإطار الاستعمال. يأخذ القرينة واستبعاد
المعنى الأصلي من المقدمات التي اكتسبها المالك في **الوقوع نفسه**، ويستهلك
متطلبات الحارس الأصلية مع حفظ السالب والتعارض. لا يصبح غياب الشاهد نفيًا.
تعذر الفاحص أو استنفاد ميزانيته يمنع قبول أي تطبيق جزئي.

تسجل التطبيقات في `concept_graph.source_use_applications`. يبقى
`admitted_concept_applications` و`grounded_world_claims` خاليين؛ المصدر قد
يشرح استعمال لفظ دون أن يثبت وجود مرجعه أو صدق خبره في العالم. وتبقى حواف
المشفر مقترحات غير مقبولة بذاتها. غياب النموذج الاختياري لا يمنح الشاهد
العصبي سلطة ولا يلغي فحص صاحب الاستعمال المتاح.

## الهوية بين صاحبي المعنى

تستعمل المراجع هويات المعاني الأصلية، دون إضافة مجال «أصولي» أو «معرفي» إلى
الهوية. يوجد ربط تحريري محدود واحد: `asad_animal` في سجل الاستعمال يشير إلى
`lisan:asad-animal` الموجود في المعجم والرسم. يسجل المرجعين كاملين:
«الحيوان المفترس» في شاهد الشخصية الثالث و«الأسد: من السباع معروف،» في
الشاهد المعجمي المحفوظ. يفحص السجلين المثبتين ويعيد تصدير التعريف الأصلي
من Lean. تغير المرجع يغير هوية الشاهد وإعادة قبوله.

هذا **اعتماد تحريري مشروط للمعنى الحيواني المختار**، موسوم
`SCOPED_EDITORIAL_ALIGNMENT` و`independent_review=false`؛ ليس برهانًا جديدًا
على تكافؤ تعريفين لغويين. لا تستنتج الوصلة التكافؤ من التطابق الكتابي أو
درجة النموذج. أما `asad_brave` وبقية المعاني غير الموجودة في المعجم العصبي
فتظل إحالات إلى هوياتها الموجودة في صاحب الاستعمال؛ لا تنشأ تعريفات بديلة
لها ولا يتغير جرد النموذج أو أوزانه.

## استهلاك بوابة المجاز وحد المسار الكامل

عند بلوغ المنسق مرحلة المفهوم، يستهلك حزمة كل مرشح مجازي على حدة، ويربطها
بسجل المنطوق السابق وبالسطر التنفيذي للمالك. القيد والقرينة واستبعاد
الحقيقة تدخل جدول `RuleRouting.Dispatch` المثبت. تبقى الإحالة إلى مالك
الدليل وسقف الدعوى وهوية الوقوع في سجل الإرسال. الشاهد لا يتجاوز طبقة
سابقة غير مغلقة، ولا يرفع النتيجة إلى تأسيس واقعي.

أظهرت التجربة الأصلية أن `أَعْنِي بِالْأَسَدِ الْحَيَوَانَ الْمُفْتَرِسَ`
يتوقف في المنسق عند الإملاء: صاحب الوحدات يعيد `DEFER_EXACT_A116_READING`
لبعض المضيفات ذات «الـ». لم تُحذف هذه البوابة ولم تُستبدل بشهادة الاستعمال.
لذلك تقاس التطبيقات الموجبة في هذه الدفعة عبر مسار `neural.graph` القائم؛
وهو لا يدعي شهادة المرور بالمراحل الست. اختبار استهلاك المنسق للحزمة
يفصل صراحةً بين شاهد استعمال حقيقي ومقدمة طبقة مصطنعة في اختبار السياسة.
يبقى إنجاز العبور الكامل لهذه الأمثلة التزامًا مفتوحًا في صاحب الدال.

## القبول وإعادة التشغيل

| المدخل ضمن السياق اللغوي المصرح | النتيجة المطلوبة |
|---|---|
| أعني بالأسد الحيوان المفترس | تطبيق استعمال حقيقي يشير إلى معرّف الأسد الموجود |
| أعني بالأسد الرجل الشجاع | قصد المعنى مكتسب، والمجاز معلق لغياب الاستبعاد |
| أعني بالأسد الرجل الشجاع لا الحيوان المفترس | استعمال مجازي مشروط بشاهده المحلي |
| نقل الاستبعاد إلى جملة أخرى | لا يستعيره الوقوع الأول |
| نفي المعنى وإثباته في الوقوع نفسه | تعارض، دون تطبيق مقبول |
| حذف الاصطلاح أو القرينة أو تعطيل الفاحص | تعليق مع حفظ السبب والبدائل |

تمر أمثلة `examples/io_gateway/usage_literal.json` و`usage_figurative.json`
بـ`gateway run` ثم `gateway verify` مع الطلب المستقل. تعديل المصدر أو
القرينة أو هوية المفهوم يبطل قبول الإيصال السابق. بصمة الواجهة تشمل سجل
الاستعمال ومصادره المحفوظة وحالة غيابها، إلى جانب الشيفرة والفاحص الأصلي.

```bash
make cognitive-orchestration LAKE=/path/to/lake
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/usage_figurative.json --output artifacts/local/usage.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/usage_figurative.json --receipt artifacts/local/usage.json
```

الاختبارات في `tests/test_usage_witness.py` تستعمل الفاحصين الحقيقيين، وتفحص
الحدود والتكرار والسحب والتعارض والاستعادة وحفظ السياق وإعادة الواجهة.
يسجل التشغيل الفعلي في طلب الدمج؛ وجود أمر الاختبار ليس نتيجة تشغيله.
لا توجد مبرهنة Lean جديدة في هذه الدفعة؛ تعاد مبرهنات الاستعمال والإرسال
الموجودة وفحوص مطابقة الجدول. لا يجري تحديث أوزان أو تحويل تلقائي للسجلات
إلى تسميات تدريب، وتبقى المراجعة الدلالية المستقلة والقياس والتقسيم والتأسيس
الواقعي واكتساب العربية العامة مفتوحة.
