# وصل الاكتساب بالتعلم والاستعمال والمراجعة

القانون: `nabt.acquired-knowledge-connection.v1`.

## عقد القبول قبل التنفيذ

المدخل نصوص أصلية مسماة، وسؤال، وأحداث تفعيل/سحب مصادر. لا يقبل المدخل
سمات أو تسميات تدريب أو قراءة مختارة أو حكمًا متوقعًا. تعاد قراءة النصوص
بقارئ `nabt.controlled-arabic.v1` الموجود و`SemanticKernel`؛ لا يضاف محلل
للعربية الحرة. تُحفظ مواضع UTF-8 وترتيب أطراف العلاقات والنفي.

الفجوة المحددة: لا تصل تجربة `source_learning_experiment` الحالية قراءة
مصادر جديدة إلى `LearningSession` وإلى جميع مجموعات الدعم المصدرية الكافية
ثم إلى `EvidenceLifecycleV1`. الوصلة الجديدة محول بين هؤلاء المالكين،
وليست قارئًا أو محرك استدلال بديلًا.

تستخرج السمات الأحادية وتسميات الأمثلة من الأخبار الصريحة؛ لا يصبح غياب
الخبر نفيًا. يستبعد فرد السؤال من التدريب. يظل توافق الفرضيات مرشحًا؛
مطابقة قاعدة صريحة في النص هي سند استعمالها النسبي إلى المصدر. يكتسب
المحرك شروط الحالة الجديدة من نصوصها، ولا يحقن المرشح قانونًا عامًا.

معايير القبول:

1. المثال المضاد الصريح يغير فضاء الفرضيات؛ المجهول يبقى معلقًا.
2. أسماء جديدة وترتيب أطراف معكوس يعالجان من النص لا بقائمة أمثلة.
3. الأمثلة وحدها لا تمنح تعميمًا؛ القاعدة الصريحة ومقدماتها تمنحان اشتقاقًا.
4. تُستنفد مجموعات المصادر ضمن حد معلن؛ يبقى الدعم البديل بعد سحب طريق،
   ويسقط بعد سحب مقدمة مشتركة. النسخة التابعة لا تصبح مصدرًا مستقلًا.
5. يعاد التعلم والاستدلال بعد كل حدث؛ يُحفظ الفرق بين الدعم المتنازع عليه
   والدعم النظيف، ولا يولّد السحب نفيًا.
6. تتحقق منافذ Lean الموجودة من البرنامج الأرضي ودورة حياة الدعم.
   يرفض إعادة التشغيل أي تغيير في الشرح أو النص أو السؤال أو الأحداث.

الحدود: ثمانية مصادر، ست سمات أحادية، ستة عشر حدثًا، وميزانيات صريحة
للتأريض والدعم. الاستنفاد خاص بمجموعات **المصادر** لا بكل أشجار البرهان
ولا بسحب جزء من مصدر. الكلمات رموز في اللغة المضبوطة، والأخبار مقدمات
منقولة لا قياسات للعالم. لغة الفرضيات تستنفد الاقترانات الموقعة للسمات
المكتسبة: حتى ست سمات و730 فرضية، دون إسقاط المرشحين المختلفين.
المحول إلى التأريض يفحص في Python؛ مقارنة تنفيذاته بـLean محدودة ولا
تُسمّى برهان تنقيح عامًا. لا تدعي الوصلة اكتساب قواعد الكتب من نثرها الحر.

## التشغيل وإعادة الفحص

```sh
make -f tools/source_learning_connection.mk source-learning-connection LAKE=/path/to/lake
PYTHONPATH=src:. python -m tools.source_learning_connection \
  --request examples/source_learning_connection/request.json --output /tmp/connection.json
PYTHONPATH=src:. python -m tools.source_learning_connection \
  --request examples/source_learning_connection/request.json --verify /tmp/connection.json
```

يحمل كل مصدر `id/text/parents`. الأبوّة بيان منشأ صريح؛ لا يكتشف النظام
انتحال المصدر أو استقلاله التاريخي. تحفظ `initial_active` الحالة الابتدائية؛
وتسحب `events` المصادر المسماة أو تعيد تفعيلها دون تعديل محتواها. السؤال
يحدد المطلوب، ولا يُستعمل شاهدًا لتدريبه. يحظر نقل فرد السؤال إلى التدريب.

في المثال المودع يتغير عدد المرشحين 2→1 بعد إدخال المثال المضاد، ثم تبقى
نتيجة الحالة بدعم القاعدة الثانية بعد سحب الأولى. سحب نص الحالة المشتركة
يجعل الجواب `UNKNOWN`، وإعادته تعيد `SUPPORTED`.

`minimal_source_supports` يستنفد مجموعات الدعم المصدرية الصغرى لكل قطبية.
لا تمثل شهادة واحدة مختارة كل الأشجار ذات المصادر نفسها؛ تلك الأشجار
ليست وحدة السحب في هذا الإصدار. `signed_support_status` يصف وجود الدعم؛
أما `history.status` فيحفظ كذلك تعارض المقدمات وفحص الدعم النظيف في المحرك
وفي Lean. لا يُستبدل الثاني بالأول. يعاد توليد الفرضيات بعد كل حدث.

`ground_inference` يحفظ التأريض كله مع المصدر والتعويض وشهادة Lean.
تبقى قراءة القاعدة الكلية وتأريضها في Python، وتثبت اختبارات المطابقة
الحالات المنفذة فقط. عند خلو النظرية تمامًا يبقى الجواب مجهولًا، ويظل
`chain_complete=false` لأن منفذ القراءة الأصلي يشترط مصدرًا غير فارغ.
غياب المنفذ أو تجاوز الميزانية لا يصدر نجاحًا.

أعيد استخدام `SourceSpan` و`text_reader` و`SemanticKernel` و`LearningSession`
و`VerifiedReading` و`EvidenceLifecycleV1`. لا تحتاج المطابقة العادية لقواعد
Horn هنا إلى سياسة منطوق/مفهوم جديدة؛ يبقى `QualifiedInference` مالك تلك
السياسات الخاصة. يبقى النموذج العصبي مقترح ترتيب دون سلطة قبول، ولا
تُمرر سماته التي تفقد ترتيب الكلمات بدل علاقات القارئ المرتبة.

تُكتسب مفردات السمات مرة من النصوص المقدمة كلها وتثبت خلال الحلقة؛ التفعيل
والسحب يغيران الشواهد المستعملة، ولا يمحوان أسماء السمات. لذلك ليست
تجربة التفعيل اختبارًا محجوبًا لاكتشاف مفردات جديدة. مصادر المثال والاختبارات
مؤلفة لا منسوبة إلى الكتب؛ يبقى نمط شواهد سيبويه وقطر الندى القديم كما هو.
