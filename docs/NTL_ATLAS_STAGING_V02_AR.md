# أطلس NTL: مرحلة اقتراحات موثقة لا جهة ترخيص جديدة

## النطاق

هذا التغيير يضيف `tools/ntl_atlas.py` كأداة مطور لتحضير جرد ومعاني مرشحة
وطلبات للبوابة الموجودة. لا يغير `src/` ولا `formal/` ولا البوابات أو
أوزان الشبكات القائمة. لا يضيف قارئًا عربيًا أو سجل مبرهنات أو رتبة قبول.

الحاجة غير المغطاة: الحزمتان المحليتان المقدمتان للجرد والنواة العصبية
لم تكونا تملكان سجل اقتران موحدًا يحفظ شاهد المدخلة ورقم وقوعها، ويمنع أن
تتحول مراجعة مؤلف أو نتيجة نموذج إلى ترخيص لغوي داخل NABT.

## الأصول المعاد استعمالها وحدودها

- `AGENTS.md` و`docs/IO_GATEWAY_V1_AR.md`: `gateway run/verify` هو حد
  الإدخال والإخراج الخارجي الوحيد. أداة الأطلس تصدر خطة `NOT_RUN` فقط.
- `docs/NABT_FOUNDATION_REUSE_AR.md` و`docs/PROGRESSIVE_UNITS.md`:
  رقم الحزمة ليس خلية 116 جديدة، والهوية ليست دلالة. الترميز المحلي للحزم
  نقل بيانات فقط، ولا يستبدل ترميز A116 أو يدعي برهان Lean.
- `docs/RELATIONAL_RAG_V1_AR.md`: مالك العلاقات والقابليات الحالي لا
  يُستبدل. لا تتحول مخرجات المختبر الاصطناعي إلى أجوبة هذا المالك.
- `docs/LEXICAL_DENOTATION.md`: هوية المعنى وشاهده التزام مستقل. وجود
  الجذر أو المدخلة في اقتباس لا يصدر شهادة مطابقة أو تضمن أو التزام.

## العقود

1. Source: بايتات UTF-8، وهوية وإصدار ومجال ورخصة وبصمة مثبتة.
2. Inventory: استنفاد سطور المصدر بعد مطابقة بصمة Git المستقلة؛ تبقى
   المداخل متميزة بمواضعها، ولا تطبع الهمزة أو الياء أو التاء صامتًا.
3. Proposal: اقتباس بايتي ومدخلة ومعنى مرشح، وحالة `PROPOSED_ONLY`.
   تلزم بايتات مصدر الجذور المحفوظة مستقلًا وبصمة Git المتوقعة عند الإنشاء
   وإعادة الفحص والمراجعة. يعاد بناء الجرد بالأداة نفسها ومقارنة السجل كاملًا
   بتمثيله القانوني: موضع الوقوع ورقم السطر والصيغة والطول والأبجدية والهوية
   الرقمية والحالة والبقايا والسلطة. إعادة حساب بصمة سجل مزور لا تثبت عضويته
   في المصدر؛ وتبقى الوقوعات المتكررة للصيغة نفسها هويات مستقلة.
4. ReviewEvent: قرار مسار مراجعة مستقل عن المؤلف؛ المخرجات هي طلب
   إعادة فحص لدى المالك، أو الرفض، أو التأجيل. لا توجد قيمة ACCEPT هنا.
5. GatewayPlan: طلب `text.read` الأصلي مع مصدره وبصمته، لا تشغيل مختلق.
   يمر الطلب بمحقق `gateway_routes.validate` القائم قبل إنشاء الخطة وعند
   إعادة فحصها. النص الفارغ وحدود بايتات المصدر وعدد الوقوعات وحجم المفردة
   تضبطها البوابة نفسها؛ لا يجزئ الأطلس النص أو يختصره كي يتجاوز حدودها.
6. Freeze: إنشاء حصري، لا كتابة فوق أثر سابق.

هوية المراجع مقدمة مسار عمل وليست توقيعًا رقميًا. يلزم توثيق الدخول في
نظام الإنتاج؛ اسم المراجع المكتوب لا يثبت شخصيته. وتبقى جميع المخرجات
`authority=NONE` و`NOT_ADMITTED` مهما ارتفعت درجة عصبية خارجية.

## الجرد المصدرّي المقيس في الحزمة المحلية

المصدر العام: `linuxscout/arabic-roots`، الإيداع
`da81dd4568593b877d3fd7306be6eee70e381231`، والمسار `data/roots.txt`.
بصمة Git blob: `351c31fe7fce883cf596c05ca446bae93acd2914`.
استنفاد المصدر في الحزمة المرفقة ينتج 9520 مدخلًا: 6385 ثلاثية المحارف
و3135 رباعية المحارف. هذا لا يصادق جذريتها ولا معانيها. لم تُنسخ بيانات
GPL أو المعاجم أو ملفات المستخدم الخاصة إلى هذا المستودع.

## التشغيل

```sh
PYTHONPATH=src:. python -m unittest discover -s tests -p test_ntl_atlas.py -v
python -m tools.ntl_atlas inventory --source SOURCE \
  --source-id SOURCE_ID --revision COMMIT --sha256 EXPECTED_SHA256 \
  --blob EXPECTED_GIT_BLOB --license SOURCE_LICENSE --out NEW_DIRECTORY
```

ينشئ التشغيل `records.jsonl` و`summary.json`، ويرفض مجلد نتائج موجودًا.
جميع حواف المعنى والتعدية والآلية والغرض تحتاج وسمًا ومراجعة مستقلين.

واجهات `make_proposal` و`check_proposal` و`review_event` تتطلب وسيطين
مسميين بلا قيمة افتراضية: `root_source` و`expected_root_blob`. يوردهما
المستهلك من المصدر وبصمته المحفوظين مستقلًا عن سجل الاقتراح. مثال:

```python
proposal = make_proposal(
    root_record, lexical_source, lemma, sense_key, start, stop, author,
    root_source=retained_root_source, expected_root_blob=retained_git_blob,
)
valid = check_proposal(
    proposal, root_record, lexical_source,
    root_source=retained_root_source, expected_root_blob=retained_git_blob,
)
```

تعاد قراءة الجرد المحدود عند التحقق؛ لا تعتمد النتيجة على مخبأ أو سجل جذر
قدمه صاحب الاقتراح. هذا فحص اقتران بالمصدر المحدد، وليس توثيقًا خارجيًا
للمصدر أو قبولًا لمعنى المدخلة.

كل طلب خارجي فعلي يدخل فقط:

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run \
  --request REQUEST --output RECEIPT
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify \
  --request REQUEST --receipt RECEIPT
```

يحتفظ المستهلك بالطلب مستقلًا. نجاح شكل الخطة أو إعادة طيها لا يثبت أن
هذين الأمرين نُفذا. كذلك نجاح إعادة البوابة لا يوسع سلطة جواب المالك.

## الاختبارات وحدود الإنجاز

توجد حالات نقض لفقد المصدر، واختلاف موضع UTF-8، وتعديل المعنى أو الجذر،
والمراجعة الذاتية، ورفع الاقتراح إلى قبول، وتزوير التنفيذ، وحقن درجة عصبية،
وتكرار مفاتيح JSON، ومحو التاريخ. تشمل إصلاحات الدمج السجل الأدنى المزور
ذي البصمة الصحيحة، وتعديل حقول السجل مع إعادة البصمة، واستبدال مصدر الجذر،
وخلط الوقوعات المتكررة، والتباس `True` بالعدد `1`، وخطط نصوص تتجاوز عقد
القارئ وخطط الحدود الصحيحة المحفوظة دون اقتطاع. اختبارات الجرد تعتمد مصدرًا اصطناعيًا
صغيرًا مستقلًا عن بيانات المستخدم. إعادة التقييم الشامل لمحركات NABT
مسؤولية CI الأصلي؛ هذه الأداة ليست إعلان إصدار جديد للنواة.

لا تدريب جديد، ولا استخراج آلي للحاجات الباطنة، ولا قانون فيزيائي مكتشف،
ولا جسر عام إلى Relation/Ifadah/Hukm. الخطوة التالية المسموحة هي وسم
شواهد مدخلات ومعانٍ محددة ومراجعتها، ثم اختبارها عبر المالك الحالي.
