# Sourced acquisition v3: bounded composition contract

This additive development follows the audit of main
`b5f5bf1e09254b0d91b3ac4ed4e7bfe5b772176a`. Historical v1/v2 laws,
source packets, independent matrices and first results remain unchanged.
This document and the component specifications are committed before the new
independent matrix; that matrix is committed before production implementation.

## Separate obligations

The component contracts are `SOURCED_ACQUISITION_V3_CONNECTED.md`,
`SOURCED_ACQUISITION_V3_PERSON_NOMINAL.md`,
`SOURCED_ACQUISITION_V3_NATURAL.md` and
`SOURCED_ACQUISITION_V3_ARCHITECTURE.md`. They define finite accepted domains,
retained primary-source passages, excluded contacts/readings, and API fields.
An accepted shape is not lexical attestation; person is not a discourse
referent; a nominal predication is not a true claim about the world; a retained
dictionary sense is not a unique intended sense. No caller status, hash or
supplied analysis confers authority. Verification replays the complete original
source and binding with the installed, versioned law.

Connected realization preserves the original partition and citation identities.
Deletion in pronunciation does not delete source bytes or extend a piece across
a word boundary. A connected phrase is shape-checked as a phrase; an elided
onset must never be passed off as a separately licensed citation word.

Person and nominal handoffs must carry the exact acquired source, word bounds,
and positive acquisition evidence. Unknown reference, unsupported inflection,
ambiguous analysis, missing lexical witness, invalid input and resource failure
remain distinct. The bounded nominal grammar names its roles; it must not reuse
agent/object roles to fabricate subject/predicate evidence.

Natural-use candidate retrieval and unique intended-use selection have separate
denominators. A plausible collocation alone must not establish unique intention.
Every new lexical designation has a local source citation and declared scope.
The existing PR 34 source/query inference language remains available and is not
silently expanded through spelling normalization or rewritten source strings.

## Evaluation and chronology

The independent matrix retains four families: orthography, person/category,
nominal predication and conditional/meaning acquisition. Each case identifies
its entry point and an exact bounded-contract projection. Positive required
goals are separate from that expected bounded behavior: correct abstention on a
required positive example is a coverage miss. Unmeasured goals are never passes.
Variants include reordered constituents, number/person/case changes, incomplete
marks, cross-word spans, unsupported contact, quotation, absent/negated premises
and unresolved reference. Finite tests do not become a general Arabic theorem.

Before importing runtime modules, the evaluator checks committed source bytes,
native executable hashes, frozen specification and independent matrix hashes.
It then compares the initial snapshot directly with that validated freeze,
imports repository Python from validated source bytes only, and checks source,
native and loaded-module integrity after execution. Source and binary inventories
are disjoint. The trusted interpreter, standard library and host are explicit
assumptions; snapshots do not claim atomic isolation from concurrent mutation.

The first execution attempt, including a failed preflight, is preserved. All
subsequent attempts are exposed replays. Chronology checks establish Git ancestry
and pinned contents, not secrecy or absence of undisclosed external execution.
Reports record actual commands, commit identities and limitations; no result or
grammar certification flag is authored in advance.

## Integration and architecture

The 24 designated classical operators receive explicit, narrowly scoped theorem
links and nonempty implementation scopes in a new metadata version. Historical
crosswalks remain evidence of their original versions. A theorem about finite
action enumeration is not a proof of a Python window recognizer or of linguistic
fidelity. Any changed compiled manifest requires synchronized current proof and
grammar/meaning/inference link snapshots, with the former snapshots preserved.

Entropy, import topology, dependency cycles and exact AST duplicates guide
interface review. They are not a target function, an Arabic completeness score,
or a reason to remove independent test oracles. Core-to-tools imports remain
forbidden. Changes require the project's formal, conformance, test and existing
integration gates, together with focused boundary and mutation regressions.
