# استدعاء الشاهد من تمثيل السؤال والعبارة

يدخل النص والسؤال من البوابة بعقد `text.read` مع `witness_recall: true`. يحفظ القارئ بايتات العبارة ومعرّف المصدر والبصمة وحدود كل قرينة. تمثل ذاكرة الشواهد وقوعات مختلفة حتى عند تكرار اللفظ. يقرأ المشفّر GRU القائم بايتات السؤال وكل قرينة. تتخذ متجهات الوقوع أربعة حدود أمامية وعكسية، ثم يُحسب متوسطها. يقرأ رأس السؤال العمليات الأربع، ويقرأ رأس القرينة محور الآلة أو شرط الوصول. دُرّب الرأسان بانحدار خطي ذي تنظيم تربيعي على تسميات مصرح بها دون تغيير المشفر.

ترتّب درجات الرؤوس القرائن، ويعيد محلّل الإطار الموثّق جميع الشواهد وحالاتها. يختار المفكّ أقصر مجموعة كافية بين المجموعات الدنيا المقبولة، ويرجّح ترتيب الشبكة عند التساوي. يبقى شاهد النفي متعلقًا بمحوره، ويحتاج التعارض إلى الشاهدين، ويُرجع السؤال المفتوح نموذجين موافقين للنص. يُكتب الجواب ثم يعيد مقوّم الأجوبة الموجود تفكيكه وفحص كفاية تعليله. تُحفظ مجموعات السند البديلة وشواهدها أيضًا.

```sh
export PYTHONPATH=src:.
python -m tools.grammar_catalog gateway run --request examples/io_gateway/witness_recall.json --output /tmp/recall.json
python -m tools.grammar_catalog gateway verify --request examples/io_gateway/witness_recall.json --receipt /tmp/recall.json
python -m tools.evaluate_witness_recall --output /tmp/recall-metrics.json
python -m tools.evaluate_witness_recall --public --output /tmp/recall-public.json
```

تُبنى فواحص القارئ كما في IO_GATEWAY_V1_AR.md وبالنسخة المثبتة من Lean. لإعادة التدريب استخدم `python -m tools.lexical_training.train_witness_recall --output /tmp/new-weights.json` مع NumPy. الحزمة تتضمن الأوزان. التشغيل الطبيعي يستعمل Python والفواحص المحلية. في غياب الأوزان أو فسادها يظل فاحص الدليل متاحًا في نطاقه، وتظهر حالة تعذر المقترح.

يقتصر هذا المقطع على أربعة أطر مستقبلية معلومة، وأسئلة مقيّدة الصيغة، وما تدل عليه القرائن المكتوبة. يتلقى رأس القرينة العبارات التي جزأها المالك. استخراج القرينة من نص حر وتعلم الالتزامات الصرفية أو إثبات واقعة خارجية مراحل مستقلة. تعرض خطة المنظومة المرفقة تصميم الذاكرة والسلالات ومسار التوسع.
