الزمن هنا مفتاح مطابق، لا حساب فترات؛ والوحدة قيد مطابق، لا تحويل وحدات.

## إعادة التشغيل

من جذر المستودع، مع Lean4.34.1 الرسمي:

```bash
make -f tools/evidence_lifecycle_v1.mk evidence-lifecycle-evaluation \
  LAKE=/path/to/lean-4.34.1-linux/bin/lake EVIDENCE_DIR=artifacts/local/lifecycle-replay
PYTHONPATH=src:. python -B -m tools.productive_lifecycle_cli targets
PYTHONPATH=src:. python -B -m tools.productive_lifecycle_cli read sentence.txt --events events.json
PYTHONPATH=src:. python -B -m tools.productive_lifecycle_cli verify receipt.json \
  --source sentence.txt --events events.json
```

الوضع الافتراضي للإعادة `exposed`. يحمل `events.json` قائمة أحداث؛ مثال
السحب: `[{"event_id":"w1","kind":"withdraw","target":"qatr","reason":"مراجعة المصدر"}]`.
يجب توفير النص والأحداث وربط المصدر المتوقع بصورة مستقلة عن الإيصال.
