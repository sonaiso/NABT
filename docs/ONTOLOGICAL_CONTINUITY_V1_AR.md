# اتصال المعنى الحدثي ببنية تحققه — عقد التنفيذ v1

الأصل: `833b9a541a0cb20479bc4c986a7f9b599bc8b8f8`.
المطلب: يبقى المصدر والمشتق متصلين بالأجناس والأدوار والخواص وبنية الزمن
والمكان؛ المتغير غير المعيّن لا يعامل كعلاقة محذوفة أو غير منطبقة.

## إعادة الاستعمال والنقص المحدد

نعيد استعمال `relations.analyze` و`relational_bridge` و`verifiedReading`
و`QualifiedInference` و`RelationalBridge` ومعرفات قراءاته الأربع.
القانون v1 يربط الواقعة بحامل وجنس وخاصية وزمان ومكان، لكنه لا يصدر مخططًا
عامًا محفوظًا عند التجريد، ولا يطلب شاهدًا مستقلاً يصل الخاصية بهذه الواقعة.
لذلك لا تكفي خاصية للحامل في وقت آخر لترخيص حالته في الواقعة المطلوبة.

لا يضاف قارئ حر أو فهرس معانٍ موازٍ. تعرض أسماء المصادر الموجودة في حقل
`sense` باعتبارها تسميات للمخطط المثبت، لا باعتبارها شهادة تحليل نحوي جديد.
تظل القراءات البديلة والمواضع والمصادر الأصلية محفوظة، ولا يحذف ترتيب
الاسترجاع مرشحًا. البيانات الأنطولوجية العامة غير المعينة تبقى متغيرات.

## شروط القبول قبل التنفيذ

1. يصدر المالك الأصلي مخطط المعنى: حدث وحامل وجنس وخاصية وزمن ومكان
   وعلاقات بينها؛ نفس المعنى في الماضي واسم الفاعل يحتفظ بالمخطط نفسه.
2. التخصيص يحتفظ بكل موضع مطلوب، بما فيه غير المعيّن والمجهول؛ حذف موضع
   أو تبديله أو تكراره ليس تخصيصًا صالحًا.
3. ترخيص التطبيق v2 يتطلب جميع شروط v1 وشاهد `حدث1 حالة خاصية1`.
   تبقى هذه شهادة مصدرية مضبوطة، وليست تحققًا خارجيًا أو اكتسابًا للعربية الحرة.
4. نقصان شاهد الخاصية في الواقعة أو الزمن أو المكان يمنع الترخيص الأعلى.
   يبقى المخطط العام موجودًا؛ سحب الشاهد لا يمحو تعريف المعنى.
5. التعارض والتلوث الاستدلالي وسحب المصدر يعاد فحصها عند المالك الأصلي.
   سند مستقل صالح يمكن أن يبقي النتيجة؛ المصدر القديم لا يعاد استعماله بعد تغييره.
6. بوابة I/O تعيد كامل التقرير وتكشف تعديل المخطط أو الربط أو الشهادة.
7. أي تدريب في هذه الدفعة ينتج اقتراحًا فقط، ويعلن البيانات والبذرة والمقارنة
   المرجعية والاختبار الأول. لا تتغير شروط الترخيص بدرجة النموذج.

## حدود الدعوى

جرد المعاني هو جرد المالك الحالي؛ لا إثبات لجميع المصادر والمشتقات أو لجميع
أجناس حواملها. نوع الجنس قيد مرتبط بالخاصية وشاهد العضوية؛ لا يخترع النظام
جنسًا مقبولًا من التشابه. الموضع المكاني قد يكون نطاقًا مسمى؛ لا يختلق إحداثيات.
الفاعل النحوي وحامل الصفة والمؤثر السببي أدوار مرتبطة ذات شروط مختلفة.

## التنفيذ والقياس

المالك `Nabt.RelationalBridge` يصدر ستة مواضع وسبع علاقات لكل معنى من
المعاني الثلاثة في القراءات الأربع الحالية. أضيفت تسع مبرهنات إلى السجل
الوحيد: حفظ المخطط والمواضع، وجود رابط الخاصية بالحدث والزمان والمكان،
واتصال ترخيص v2 بترخيص v1 واشتقاق شاهد الحالة من المصدر المقبول.
لا تعني سلامة بنية المخطط أن كل قيمة مقترحة له لها شاهد.

في ناتج `relations.analyze` يظهر `semantic_continuity`. يحتفظ المصدر
«اصفرار» والفعل «اصفرّ» والمشتق «مُصْفَرّ» بمخطط واحد؛ تبقى القراءة
الصرفية وتعيين الموضع مستقلين. `general_bindings` متغيرات عامة؛
`occurrence_bindings` تعيينات لها شواهد مصدرية أو مواضع مجهولة.
لا يساوي المجهول الصفر، ولا يسمح مخطط الحدث الفيزيائي بإلغاء الزمان أو المكان.

يمكن إضافة `neural_continuity: true` إلى طلب المسار نفسه لعرض ترتيب
تجريبي للمعاني. يعاد استعمال GRU الحالي ومتجهاته عند حدود البايتات في
الاتجاهين (96 بعدًا)، مع تدريب رأس خطي فقط. المخطط صادر عن Lean ولا
تتعلمه الأوزان أو تعدله؛ التفسير هنا هو تتبع البنية والشاهد والقاعدة، وليس
ادعاء أن كل إحداثي خفي في GRU صار مفهومًا مسمى.

التدريب الأول محفوظ في `evidence/ontological_continuity_v1/training`:

| القياس | النتيجة |
|---|---|
| الأمثلة: تدريب / تحقق / سياق اختبار / تهجئة محجوبة | 104 / 26 / 39 / 3 |
| خطوات التحسين | 400؛ تغير أوزان الرأس L2 = 5.36685 |
| تغير أوزان المشفر السابق | صفر |
| المواضع المستهدفة الصحيحة في سياقات الاختبار | 29 / 30 |
| الإيجابيات الكاذبة في الكلمات الخلفية | 48 / 152 |
| التهجئات الثلاث المحجوبة عن التدريب | 3 / 3؛ لا قياس لجذور جديدة |
| أكبر فرق بين NumPy والتنفيذ المحمول | 3.56e-15 تقريبًا |

المرجع المعجمي المباشر أصاب 30/30 من المواضع المعروفة دون إيجابيات
كاذبة، ولم يتعرف على التهجئات الثلاث المحجوبة عن جدول تدريبه.
لم يعتمد الرأس العصبي للاختيار التلقائي؛ تظهر جميع المعاني دون حذف،
وسلطته `NONE`. النتائج من أمثلة تعليمية مؤلفة، وليست تحكيمًا لغويًا مستقلًا.
لم تستخدم نتائج الاختبار لتغيير الأوزان أو اختيار الحقبة. يبقى `FIRST_TEST.json`
والتنبؤ الفردي لكل موضع محفوظين، بما في ذلك الأخطاء.

## التشغيل وإعادة الفحص

```sh
python -m tools.grammar_catalog gateway run --request examples/io_gateway/relational_bridge.json --output /tmp/relational.json
python -m tools.grammar_catalog gateway verify --request examples/io_gateway/relational_bridge.json --receipt /tmp/relational.json
make relational-bridge LAKE=/path/to/lake
make check LAKE=/path/to/lake
```

التدريب يعاد في مجلد جديد بواسطة
`python -m tools.lexical_training.relational_training --output-dir /path/to/new-run`؛
يرفض الكتابة فوق تجربة سابقة. البوابة العامة هي وحدها مدخل الاستعمال الخارجي.
نتيجة البوابة الكاملة تسجل في طلب الدمج؛ وجود أوامر الاختبار هنا ليس إعلان نجاح.
