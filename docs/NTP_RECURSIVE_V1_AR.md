# مدخل NTP والتعلم العودي من A116

العقد المثبت قبل التدريب، 2026-11-17. الأساس 9416ff1c.

NTP هو منسق التشغيل الوحيد تحت بوابة I/O الموجودة. المسار `ntp` يقبل
`operation` و`input` فقط؛ أسماء المسارات السابقة محولات توافق تدخل المنسق
نفسه. لا تتغير أغلفة nabt.io.request.v1 وnabt.io.result.v1 ولا شرط إعادة
الفحص مقابل الطلب المستقل. لا يوجد منفذ خارجي خام جديد.

كل عملية قديمة تحيل إلى صاحبها الحالي بشروطه وإيصالاته؛ لا يصبح نجاح
المنسق شهادة Lean أو ترخيصًا دلاليًا. العمليات القابلة للاشتقاق تتعلم
اقتراحًا، بينما جدول القانون المثبت وفواحِص المعجم والنحو يحددان القبول.

## النقص الذي تعالجه الإضافة

shared_encoder يملك مدخل A116، لكن رؤوس الإفادة المجمدة لا تعيد الخطأ
إلى تركيب خلاياها. نضيف مؤلفًا عصبيًا عوديًا مشتركًا، لا قارئًا أو قانونًا
لغويًا أو سجل مبرهنات جديدًا. الباني العصبي يجمع وحدتين مرتبتين؛ صلاحية
السلسلة تحسب بمالك Machine وأثره المثبت، مستقلة عن الأوزان.

تمثل الخلية بسبعة بتات مع تمثيلي الحامل والحالة المتعلمين. تطبق tanh
على الأوراق، ثم tanh(W[left;right]+b) على كل عقدة ضم. الانتشار الخلفي
تحليلي إلى المؤلف وتمثيلات البتات والحامل والحالة؛ تفحصه فروق عددية
مستقلة. الترتيب والمدخل الأصلي وعدد السلسلة محفوظة خارج المتجه.

## التقييم المحدد قبل الملاءمة

يعيد التدريب استعمال الثلاثين سجلًا التعليميًا الموجود من shared_cell_reading_v1.
تقسيم الجذور والحقبة النهائية والبذرة مثبت في protocol.json. الرؤوس الثلاثة
قراءة وصرف وتعلق. لا يدعي الاختبار عمى مستقلا: البنك منشور وقد استعمله
المشروع سابقًا. المقارنة قبل التدريب ومع مؤلف/تمثيلات مجمدة تستخدم البيانات
والحقب نفسها. لا اختيار للحقبة أو العتبة من الاختبار.

فحص التدرج، تغير المعلمات، إعادة التدريب، استرجاع الخلايا، وثبات تقرير
القانون عند تغير الأوزان اختبارات منفصلة عن دقة التعلم. إخفاق الشبكة لا
يعدل القانون ولا يحول المجهول إلى سلب.

## حدود الشريحة

هذه أول وصلة تدريب فعلية، لا تدريب لجميع بانيات المعنى والعوامل والأجناس.
تظل الإفادة العامة عبر أصحاب text.read وrelations.analyze وcognitive.lesson
الحاليين. وضع الشبكة REVIEW_ONLY. لا تدعي الشريحة CertifiedBridge عامًا
أو تنقيح المؤلف العصبي إلى MeaningPreservation.Hom، ولا معنى معجميًا
لترقيم الخلايا أو صدقًا خارجيًا. توسيع التدريب إلى برامج الإفادة يتطلب
أهداف بانيات وقراءات مرتبطة بشواهدها؛ لا يكفي تغيير اسم الرأس.

## التشغيل والنتائج المحفوظة

```sh
export PYTHONPATH=src:.
python -m tools.ntp run --request examples/io_gateway/ntp_bits.json --output /tmp/ntp-bits.json
python -m tools.ntp verify --request examples/io_gateway/ntp_bits.json --receipt /tmp/ntp-bits.json
python -m tools.ntp run --request examples/io_gateway/ntp_think_bits.json --output /tmp/ntp-think.json
python -m tools.ntp verify --request examples/io_gateway/ntp_think_bits.json --receipt /tmp/ntp-think.json
OPENBLAS_NUM_THREADS=1 python -m tools.lexical_training.train_ntp_recursive --check
make ntp-check
```

`forward` يقبل نص كلمة مضبوطة أو `packed_hex` بإطار `pack_cells` نفسه؛
يفحص التأطير والعدد والحشو، ويفك البتات دون اختراع حركة. `think` يصل
النص الأصلي أو النص المفكوك من الإطار إلى صاحب `text.read` ويحفظ ناتجه
كاملا بجوار مقترحات الشبكة. المدخل متعدد الكلمات يمر إلى القارئ؛ تعذر
تمثيل لفظ في A116 يبقى معلنا ولا يصلح ضبطه سرا. النطاق العصبي كلمة من
1 إلى 64 خلية. في النصوص الأطول يعلن تقرير الملاحظات اقتصاره على أول
128 وقوعا؛ صاحب النص يحتفظ بميزانيته وتقاريره الأصلية.

لكل ضم يعاد استعمال `compose_effects` على أثر حالة الدخول، وتبقى الحمولة
الأصلية. تمت مقارنة الأثر المركب بالقراءة المباشرة من حالات الآلة الـ97.
رقم السلسلة يعرض بصيغة hex كي لا يتجاوز حد الأعداد الصحيحة في غلاف I/O.
لا يثبت أثر الشكل وحده شهادة معجم أو إعراب.

| القياس المثبت | النتيجة |
|---|---|
| بيانات train / development / test | 15 / 5 / 10، بجذور منفصلة |
| إصابة الرؤوس الثلاثة معا قبل التدريب في test | 1/10 |
| الإصابة مع تمثيل ومؤلف مجمدين وتدريب الرؤوس فقط | 9/10 |
| الإصابة بعد التدريب الكامل | 10/10 |
| أكبر خطأ تدرج تحليلي مقابل فروق عددية | 2.422e-11 |
| إعادة التدريب المحلية | النموذج مطابق بالبايت، فرق المعلمات والتقييم صفر |

هذه مقارنة تشخيصية صغيرة منشورة سابقا، لا اختبار فهم عام أعمى. حفظت جميع
تنبؤات التدريب والتطوير والاختبار والمرجع المجمد في evaluation.json.
تدرجات البتات والحامل والحالة والمؤلف غير صفرية، وتغيرت معلماتها فعلا.
الاستدلال المحمول لا يستورد NumPy أو Torch؛ NumPy مطلوب للتدريب فقط.
يفرض CI مقارنة البنية والقرارات والهويات حرفيا ويسمح بفارق 2e-9 للعوامات
فقط بين البيئات؛ لا يعيد كتابة أول نموذج أو تقييم.

محاولات الفحص محفوظة في validation.json، بما فيها إخفاق اختبار أولي
خلط الوزن العددي للأثر بقيمة None التي يستعملها تقرير التحليل عند الحالة
الميتة. صحح مرجع الاختبار إلى مجموع أثر الانتقالات؛ لم يتغير قانون الآلة.
بناء Lean وmake check الكامل لم ينفذا محليا لغياب الأدوات الأصلية؛ أضيف
اختبار NTP أصلي إلى البوابة الإلزامية ليعمل في CI عند توفرها.
