# ربط المصدر بالاستدلال وطيه وإعادة فحصه

## المنجز وحده

هذه وصلة التنفيذ الأولى لدراسة المنطوق والمفهوم في SLGE: تجعل
الانتقال المحدد ومقدماته وشواهده وبقاياه قابلة للتسجيل والاستعادة
والفحص، تمهيدًا لاستعمال الاشتقاقات المرخصة في التعلم. يبقى جبر
التوليد والتركيب المرخص الموجود هو أساس العمل اللاحق على الأشجار.

تضيف هذه الدفعة إلى مدخل `tools.mantuq_inference` القائم أربع عمليات:
`source` و`fold` و`unfold` و`verify-fold`. تبدأ العملية بنص وسؤال فعليين
في اللغة المضبوطة التي يفحصها `verifiedReading`، وتحمل جواب
`explainable_pilot` v2 كاملًا إلى مقيم الاستدلال المؤهل الموجود. تحدد
الخطة أدوار المقدمات وموضع قاعدة المصدر؛ يستخرج القارئ الشواهد
والاستنتاج من المصدر والسؤال نفسيهما.

هذا استعمال تنفيذي للقراءة والإسناد وبوابات المنطوق والمفهوم القائمة.
الطي يحفظ النتيجة ومدخلاتها وشواهدها في مجال عددي معلن، ثم تفك
الحزمة بوصفها بيانات، ويعاد اعتمادها بمقابلة إعادة تنفيذ مستقلة.
لم يدرَّب نموذج عصبي، ولم تكتسب هذه الدفعة العربية الحرة أو تغلق
`CertifiedBridge` أو تثبت تنقيح محول Python في Lean.

## أصحاب العمليات المعاد استعمالهم

| الوظيفة | المالك الموجود | استعماله في الوصلة |
| --- | --- | --- |
| قراءة النص والسؤال | `explainable_pilot.answer` و`verifiedReading` | الجمل ومواضع البايتات والاستنتاج والإغلاق الكامل والنظيف وإيصال الفحص |
| عرض أسانيد الحكم | شهادة القراءة وعقود الشرح v2 | الاحتفاظ بالجواب كاملًا، وربط كل مطلب بمعرف شاهد كامل ونظيف ومعارض |
| ملفات الاستدلال | `mantuq_inference.evaluator` وسجل السياسات | الأنواع التسعة القائمة ومتطلباتها وموانعها وأولوية أحكامها |
| الاستنتاج المشروط | `mantuq_mafhum.derive_controlled` و`classicalSemanticProbe` | فحص الاشتقاق من المقدمات والقاعدة المحددتين، بمهلة مستدعي الوصلة |
| JSON المقيد | `meaning_preservation_v1` | القراءة الصارمة والترميز القانوني؛ يسبق الترميز عدّ تراكمي للحجم |
| فهرس القدرة | `entropy_framework reuse` | تحديث عائلة المنطوق والمفهوم الموجودة ومستهلكيها، دون سجل براهين آخر |

لم تتغير النواة الرسمية ولا قانون اللغة ولا جدولها ولا المشغلات
الكلاسيكية. الصيغ المحكومة هنا هي الصيغ التي يقبلها القارئ الموجود؛
أسماء `سبب` و`شرط` في المثال ليست دليلًا على سببية خارجية أو على
تصنيف أصولي صحيح لواقعة عربية جديدة.

## عقد الخطة والمصدر

يتكون الطلب المستقل من بايتات المصدر والسؤال والخطة، وهوية المصدر
ونسخته ونطاقه وسياقه وزمنه، وحدود التنفيذ، ومساري الفاحصين الموثوقين.
الخطة `nabt.mantuq-source-plan.v1` تحتوي:

| الحقل | ما يسمح به |
| --- | --- |
| `policy_id` | إحدى السياسات الموجودة، مثل `guarded_cause` أو `opposition` |
| `requirements` | أدوار ومحمولات موقعة؛ تنطبق عليها متطلبات المقيم وأحكام التمييز بين الأدوار |
| `bridge_clause` | مرجع قاعدة فعلية `cN`، أو `null` عند غياب شاهدها |
| `contrast_kind` | خاص بالمخالفة؛ يحفظ اصطلاح الملف المثبت وحدود ترخيصه |
| `necessary_clause` | خاص بالمخالفة؛ مرجع قاعدة الضرورة الصحيحة الاتجاه، أو `null` |

لا تقبل الخطة قائمة `hypotheses` أو إيصال نجاح أو علمًا يمنح الحقيقة
أو السلطة. تستخرج المقدمات من الإغلاق الكامل الذي فحصه القارئ،
وتحمل معه الشواهد المعارضة دون إسقاط ما لم تطلبه الخطة. يجب أن
يطابق جسم قاعدة `bridge_clause` المقدمات بالترتيب المعلن، وأن يطابق
رأسها الاستنتاج الذي قرئ من السؤال.

في المخالفة يلزم فوق ذلك مرجع مصدر مستقل للعلاقة `Q → P`، مع
المقدمة الصريحة `¬P` والاستنتاج `¬Q`. إحلال `P → Q` يرفض؛ وإغفال
مرجع الضرورة يبقي النتيجة `UNKNOWN` عند اجتياز البوابات الأخرى.
تبقى للرفض والتعارض وأحكام ملف المخالفة أولوية المقيم القائمة.
إعلان أسماء الأدوار وتصنيف
القيد يظلان من الخطة، ولا يشهد لهما مجرد وجود محمول يحمل الاسم نفسه.
القواعد هنا مفترضة بالنسبة إلى نص المصدر؛ اعتمادها الخارجي التزام
مستقل.

### حفظ أثر التعارض

قد يشتق المصدر `سبب` من `أصل`، ويحتوي في الوقت نفسه `أصل` و`¬أصل`.
حينئذ يمكن أن يظهر `سبب` في الإغلاق الكامل دون أن يملك اشتقاقًا
نظيفًا. لو أعيد إدخاله كواقعة مستقلة في المقيم لفقدنا سبب تعليق حكمه.
لذلك تفحص الوصلة سند كل مطلب قبل منح الاستنتاج، وتصدر
`DEFER / CONTESTED_SOURCE_PREMISE` عندما يتوقف الانتقال على هذا
الاشتقاق وحده. إذا أضيف شاهد نظيف مستقل صح استعماله؛ وإذا سحب
عاد التعليق. تعارض خارج طريق المقدمات لا يلغي سندًا نظيفًا مستقلًا.

تظل أحكام المقيم المصدرية محفوظة: نفي شرط مطلوب قد يعطي `REFUTED`
لطريق التطبيق، ولا يثبت به نفي الاستنتاج؛ وجود العلامتين يحفظ
`CONFLICT`؛ وعدم العثور على نفي المانع يعطي `UNKNOWN`، ولا يصنع
نفيًا تلقائيًا. جواب القارئ ونتيجة السياسة حقلان مستقلان.

## ماذا يطوى؟

تحمل نتيجة `nabt.mantuq-source-result.v1` ثلاثة عشر حقلًا بالضبط:

| المجموعة | الحقول |
| --- | --- |
| الحكم | `schema`, `status`, `reason`, `conditional_consequence` |
| المدخلات الأصلية | `input_binding`, `plan`, `budget` |
| القراءة والأسانيد | `source_answer`, `source_witnesses` |
| التطبيق | `conditional_request`, `conditional_result` |
| أدوات الفحص والحدود | `native_checkers`, `limits` |

يحفظ `input_binding` النص والسؤال الخامين مع هوية المصدر ونسخته
ونطاقه وسياقه وزمنه. يحفظ `budget` الحدود المطلوبة فعلًا، بما فيها
مهلة الاستدعاء الأصلي. لا يكتفي النقل بخلاصة الحكم أو تجزئته، ولا
يحذف الجمل غير المستعملة أو فروع الإثبات أو مواضع المصدر.

الحمولة التي ترمز إلى بايتات `B` هي الكائن القانوني التالي كاملًا،
وليست حقل `result` وحده:

```text
{schema: "nabt.mantuq-source-fold-payload.v1",
 domain: "nabt.mantuq-source.canonical-json-utf8.sentinel256.v1",
 result: full_source_result}
```

بعد ترميزه إلى JSON قانوني وUTF-8، يمثل العدد بايتات `B`:

\[
N = \operatorname{int}_{256}(\texttt{0x01} \mathbin{\|} B).
\]

الغلاف `nabt.mantuq-source-fold.v1` له ستة حقول بالضبط:
`schema` و`domain` و`number_hex` و`payload_sha256` و`authority`
و`requires_source_replay`. يصدر العدد في `number_hex` بصيغة سداسية
صغيرة قانونية، و`authority=TRANSPORT_ONLY` و`requires_source_replay=true`.
حقل `payload_sha256` يخص بايتات `B` دون بادئة `0x01`؛ يفحص هوية
الحمولة ولا يمنح صحة معرفية.
المجال هو:

```text
nabt.mantuq-source.canonical-json-utf8.sentinel256.v1
```

يبقى هذا المجال مختلفًا من ABI الخاص بـ`Program` ومن أعداد الأشجار
في الجبر العودي. لا يقبل المستهلك استبدال اسم المجال أو نسخته.
هذا تمثيل دقيق قابل للاستعادة؛ العرض السداسي يزيد حجم الحمولة إلى
نحو ضعفيها، فلا يدعي ضغطًا أو تسريعًا أو اكتساب مفهوم لمجرد تحويله
إلى عدد. لم تضف الدفعة جبر تركيب بديلًا للجبر المرخص الموجود.

### الفك غير إعادة الاعتماد

يعيد `unfold_source` بيانات السجل كما هي؛ لا يشغل فاحصًا ولا يمنح
الأعلام التاريخية سلطة حالية. لذلك يغلف أمر CLI الناتج بحالة
`DECODED_UNVERIFIED` و`verified=false` و`action_authority=NONE`.

أما `verify-fold` فيطلب المصدر والسؤال والخطة والنسخة والميزانية
من المستدعي مستقلين عن الحزمة. يعيد القراءة والاستدلال بواسطة
الفاحصين المعينين حاليًا، ثم يقارن التمثيل القانوني الكامل. استبدال
الطلب أو النسخة أو الميزانية أو أي شاهد، ولو أعيد حساب التجزئة،
يفشل المقابلة. تغيير بصمة بايتات الفاحص يوجب حزمة جديدة حتى إن أعطى
الحكم نفسه؛ نقله إلى مسار آخر مع بقاء بايتاته لا يغير هويته هنا.
لا تنفذ الحزمة مسار برنامج أو أمرًا مستعادًا من محتواها.

نجاح الإعادة `VERIFIED_REPLAY` يمكن أن يخص نتيجة `UNKNOWN` أو
`DEFER` محفوظة؛ ليس اسمًا آخر لـ`SUPPORTED`.

## التشغيل

ابن الفاحصين بالأداة المثبتة في `formal/lean-toolchain`:

```sh
cd formal
lake build verifiedReading classicalSemanticProbe
cd ..
mkdir -p artifacts/local/mantuq-source-demo
```

ثم نفذ المثال المؤلف، وهو مثال تعليمي عن نظرية مصدر، لا شهادة عن
واقعة خارجية:

```sh
PYTHONPATH=src:. python -m tools.mantuq_inference source \
  examples/mantuq_source_fold/guarded.txt \
  examples/mantuq_source_fold/guarded_query.txt \
  --plan examples/mantuq_source_fold/guarded_plan.json \
  --output artifacts/local/mantuq-source-demo/source.json

PYTHONPATH=src:. python -m tools.mantuq_inference fold \
  examples/mantuq_source_fold/guarded.txt \
  examples/mantuq_source_fold/guarded_query.txt \
  --plan examples/mantuq_source_fold/guarded_plan.json \
  --output artifacts/local/mantuq-source-demo/fold.json

PYTHONPATH=src:. python -m tools.mantuq_inference unfold \
  artifacts/local/mantuq-source-demo/fold.json \
  --output artifacts/local/mantuq-source-demo/unfolded.json

PYTHONPATH=src:. python -m tools.mantuq_inference verify-fold \
  examples/mantuq_source_fold/guarded.txt \
  examples/mantuq_source_fold/guarded_query.txt \
  artifacts/local/mantuq-source-demo/fold.json \
  --plan examples/mantuq_source_fold/guarded_plan.json
```

المثال الثاني في `examples/mantuq_source_fold/opposition*` يعرض
مخالفة مشروطة ذات علاقة ضرورة صريحة وموضع قاعدة معلوم. يمكن
استبدال ملفات `guarded*` بنظائرها الثلاثة في أوامر القراءة والطي
والإعادة. يلزم اسم مخرج جديد لكل تشغيل؛ لا يمحو CLI ملفًا سابقًا.

يمكن تمرير `--checker` و`--semantic-probe` من إعداد موثوق، أو
تعيين `NABT_VERIFIED_READING` و`NABT_CLASSICAL_SEMANTIC_PROBE`.
كل خيار هوية أو سياق أو ميزانية استعمل في الطي يجب إعادته نفسه عند
التحقق؛ تغيير `--revision` إلى `2` مثلًا يرفض الإعادة القديمة.

## حدود الموارد وحالات الفشل

| المدخل أو العملية | الحد |
| --- | --- |
| المصدر | 65,536 بايت، مع قيود اللغة الأصلية |
| السؤال | 8,192 بايت |
| ملف الخطة | 1 MiB؛ حتى 16 مطلبًا وفق نوع السياسة |
| حمولة الطي | 8 MiB قبل الترميز الكامل |
| ملف الغلاف أو الخرج | 17 MiB، مع سطر ختامي في CLI |
| عمق JSON | الحد الموجود: 32 |
| أعداد JSON العادية | أعداد صحيحة في حد المالك؛ العدد المطوي سلسلة سداسية |
| مهلة الفاحص | عدد صحيح 1–60 ثانية؛ الافتراضي 20 لكل استدعاء |
| الميزانية الافتراضية | 64 قراءة كحد طلب، 128 فرضية، 2048 ذرة؛ هذه الوصلة تنتج قراءة واحدة |

المهلة لكل استدعاء أصلي وليست حدًا إجماليًا للعملية. تعد كل مرات
ظهور الكائن المشترك في شجرة JSON قبل تخصيص الوثيقة الكاملة، فلا
تخفي إعادة استعمال كائن Python تضخم التصدير. ترفض مفاتيح JSON
المكررة وUTF-8 المعيب والأعداد العائمة وخلط `true` بـ`1` والتمثيلات
العددية غير القانونية.

تتمايز المدخلات المعيبة، والخروج من اللغة المثبتة، ونفاد المورد،
وتعذر الفاحص، وفشل المصدر عن الحالات المعرفية الخمس. لا يصدر الطي
حزمة إثر فشل تقني. الرمز 0 في CLI يدل على إتمام العملية، وقد يحمل
`UNKNOWN` أو `DEFER`؛ الرمز 2 لفشل المدخل أو التنفيذ أو الإعادة.

## بوابة دائمة وحد البرهان

```sh
make -f Makefile -f integrations/mantuq_inference.mk mantuq-inference
```

يبني هذا المسار الفاحصين وينفذ اختبارات المصدر والطي بواسطة Lean
الفعلي، إضافة إلى مطابقة الاستدلال والفهرس القائمة. تستخدم بوابة
`catalog-proof-links` الحالية هذا الهدف؛ لم تتغير مهلة العشرين
دقيقة ولا `Makefile` المجمد ولا سير CI الرئيسي.

مرجع القبول مؤلف استقلالًا في
[`acceptance_contract.json`](../evidence/mantuq_source_fold_v1/acceptance_contract.json).
يختبر نقص الشاهد والتعارض وسحب البديل النظيف ودوران التبرير
واستبدال القاعدة والمصدر والميزانية، ويعيد حساب التجزئة في هجمات
العبث حتى لا يكون فشلها مجرد تجزئة قديمة. راجع
[`سجل النتائج`](MANTUQ_SOURCE_FOLD_V1_RESULTS_AR.md) للنتائج المنفذة
ومصادر الأدلة وحدود النشر.

براهين القراءة والاستدلال الأصلية باقية ضمن فروضها. وصل Python
بين القراءتين وترميز الحزمة مفحوصان باختبارات مستقلة، دون دعوى
مبرهنة تنقيح جديدة. تبقى أمانة استخراج الأدوار من العربية الحرة،
وحصر قراءاتها، والحقيقة اللغوية والعرفية، واعتماد القاعدة في الخارج،
ومبرهنتا القناع والتمام ضمن نحو ومعجم معينين، التزامات منفصلة.
