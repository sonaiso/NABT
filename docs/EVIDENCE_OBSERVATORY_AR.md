# مرصد الأدلة في مختبر NABT

أضافت هذه النسخة مسارًا محليًا لقراءة سجل الطبقات الأربع ومقارنته بتصريحاته.
يمكن اختيار ملف JSON أو لصقه، ثم البحث في الادعاءات وتصفية طبقتها ورتبتها
وفتح دليل كل ادعاء. لا يتصل هذا المسار بـMashru، ولا ينفذ ملفات Lean، ولا
يرفع الملف أو يحفظه في التخزين المحلي للمتصفح. يبقى تشغيل NABT الحي في
تبويبه المنفصل وتحت بوابة التفعيل القائمة.

## ما يستفاد من الشاهد المرسل

النص `ذَهَبَ الْوَلَدُ` يتكون من 16 نقطة Unicode، وتطابق بصمته المعطاة
SHA-256 المحسوبة من UTF-8 دون تطبيع:

`34c9ac0fff60bc73c9ed17b600b1c133d2f0c83d5b47427e921bb533853450e2`

يحوي السجل 14 ادعاءً: 8 برتبة «مبرهن على الشاهد»، وواحد برتبة «مبرهن»،
و4 «مطابَق»، وواحد «مقيس». ويحوي 9 تصريحات بنجاح مبرهنات. هذه الأعداد
أُعيد اشتقاقها من الصفوف؛ ليس معنى ذلك إعادة التحقق من المبرهنات التسع.

| الالتزام | ما يصرح به السجل | ما يحتاج فحصًا مستقلًا |
| --- | --- | --- |
| هوية النص | نص وبصمة وNFC وعدد نقاط Unicode | يعاد حسابها محليًا؛ ليست حكمًا دلاليًا |
| المدلول | تعريف `dhahab` و`walad` في Mashru | إحالة معجمية كاملة معلنة لواحد من مدلولين فقط؛ لم يُقرأ المصدر هنا |
| الإطار | اختيار إطار ثم قبول `hukm3` | صحة اختيار الإطار من النص واستنفاد البدائل المرخصة |
| الزمن والمكان | مرساة صفرية وإزاحة −1 ساعة | قيم مفترضة؛ لا تثبت توقيت واقعة أو موضعًا مستخرجًا من العبارة |
| الإسناد | بنية موضوع ومحمول معرفة في الشاهد | عقد استخراج من النص؛ القابلية ليست بذاتها وقوع الحدث |
| البرهان العام | رتبة «مبرهن» لتصريح واحد | نص المبرهنة ومعاملاتها لتحديد مداها الفعلي |
| إعادة الإنتاج | HEAD وبصمات وشجرة غير نظيفة | ملفات الأداة غير المتعقبة والاعتماديات؛ HEAD وحده لا يحددها |

الشجرة غير النظيفة لا تبطل برهانًا تلقائيًا. لكنها تمنع التعامل مع HEAD
بوصفه وصفًا كاملًا للأداة المنفذة. قائمة المسلّمات `propext` و`Classical.choice`
و`Quot.sound` تقارن بالسجل فقط؛ لا تُستخرج من بيئة Lean في المتصفح.

مصفوفة المراحل تحتفظ بالقيم المنطقية الثلاث: نعم، لا، وغير مقاس. مرحلة
`S3_HOKOM_TAQDIR` غير مطلوبة في هذا الشاهد؛ لا تُحسب اختبارًا ناجحًا أو
فشلًا لغويًا. لا يُستعمل اكتمال المراحل نسبةً لاكتمال العربية.

## التصميم التنفيذي

- `web/evidence-audit.js`: قارئ JSON صارم ومدقق اتساق مستقل عن DOM والشبكة.
- `web/evidence-ui.js`: عرض الادعاءات، وعدسة الدليل، والفجوات والمراحل،
  واستيراد الملفات وتنزيل نتائج التدقيق أو السجل المدخل.
- `web/evidence-sample.js`: مقتطف مُعلن من سجل المستخدم؛ يحفظ البيانات
  اللازمة للمراجعة ويحذف مسارات الجهاز الشخصية وأوامرها. ليس أرشيف مصدر.
- `tests/evidence-audit.test.mjs` و`tests/evidence-ui.test.mjs`: اختبارات مستقلة
  للاتساق وحالات التضليل والتلاعب واستيراد الملفات والتفاعلات.

الصيغ المقبولة هي `Tabaqat4Record:v1` و`nabt.proof-lab-result.v1`.
في تقارير NABT المستوردة، تبقى أعلام `verified` و`native_checked` تصريحات
من ملف قابل للتحرير. لا تستعمل قناة النتائج الحية ولا تحصل على مصادقتها.
تعرض تقارير القياس المستوردة الصفوف والنتائج المعاد عدها، بما فيها الإخفاق.

يعيد المدقق حساب بصمة النص الأصلي باستخدام WebCrypto. عند عدم توفره،
تبقى البصمة غير محسومة؛ لا يستعاض عنها بقيمة السجل. يحتاج WebCrypto عادةً
سياقًا آمنًا؛ معاينة HTTP قد لا توفره. تثبت اختبارات Node البصمة المعروفة
بـWebCrypto مستقل، ويستعمل الموقع المنشور HTTPS.

يُرفض JSON ذو المفاتيح المكررة حتى عند ترميز الاسم بمحارف الهروب، والمفاتيح
المحجوزة، وUnicode التالف، والأعداد غير المنتهية أو الصحيحة خارج دقة التمثيل.
حدود الاستيراد: 2 MiB، وعمق 32، وطول سلسلة 65536 وحدة UTF-16، و4096 عنصرًا
للقائمة، و1024 مفتاحًا للكائن، و50000 عقدة إجمالًا. هذه حدود موارد للقارئ،
لا حدود على العربية.

تُعرض النصوص عبر `textContent` وعناصر DOM، ولا تُفسر HTML أو JavaScript.
لا تحول قائمة مسلّمات مفقودة إلى قائمة خالية. تقارير البنية المقبولة التي
تحوي تناقضًا تظل قابلة للمراجعة، مع ظهور التناقض وعدم منحها سلطة برهانية.
أما JSON غير المقبول فيزيل النتيجة السابقة قبل عرض خطئه.

## التحقق

```bash
node --test integrations/proof_lab/site/tests/*.test.mjs
cd integrations/proof_lab/site
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

شمل الفحص المرئي على المعاينة المكتبية: عرض الشاهد، ورفض مفتاح مكرر،
وإخفاء التقرير السابق عند الرفض، واستعادة الشاهد، وتصفية المدلول والبحث
عن `walad` وعرض فجوة مصدره. روجعت أنماط CSS للشاشات الضيقة؛ لم يُدّع
اختبار متصفح مستقل على هاتف. لا تعدل هذه الإضافة النواة أو المعجم أو
قانون قبول اللغة، ولا تضيف مبرهنات أو تحسن تغطية المجموعة المرجعية بذاتها.

الواجهة الأوضح تجعل قياس الدليل والفجوات ممكنًا، لكنها لا تسد فجوة البرهان
باستبدال تسميته أو عدّ نجاحات محلية.
