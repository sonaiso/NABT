# التحصيل المصدرّي v3: ما أضيف وكيف يُفحص

ينفذ هذا الامتداد جسرًا محدودًا من الرسم الأصلي إلى الشخص والإسناد، ونطقًا
متصلًا محدد المجال، وقراءات معجمية طبيعية محدودة. تبقى قوانين v1 وv2 ولغة
الاستدلال في PR 34 ونتائجها التاريخية مستقلة؛ لا يعاد وسم نتائج قديمة كنجاح جديد.

## السلوك المنفذ

| المسار | القدرة المضافة | الحد الذي يبقى ظاهرًا |
|---|---|---|
| روابط القوانين | جميع المؤثرات الـ24 لها مجال تنفيذ وإحالة صريحة: أُكملت 18 إحالة و10 مجالات ناقصة | هذه بيانات ربط إلى براهين مشروطة؛ لا تثبت تنقيح Python أو شمول المصدر |
| التحصيل والنطق | 34 قراءة تمثيلية و151 صورة دخل حرفية؛ ألفاظ محدودة من «أل»، وحذف همزة الوصل عند الاتصال المرخص، وإدغام لام «الرجل» | لا تعويض عام للحركات؛ اتصال الساكن والتنوين والمد قبل الكلمة التالية خارج هذا الملف |
| الشخص | `قمتُ/قمتَ/قمتِ` ونظائرها كاملة الضبط؛ يحتفظ بعلامة التاء الأصلية عند الوقف | الشخص النحوي ليس هوية المتكلم أو المخاطب؛ غير المضبوط يبقى فرضيات تشخيصية |
| الإسناد | «الولدُ ذاهبٌ»، والتقديم، والمثنى والجمع ضمن الجدول المحدد، مع فحص التوافق والعلامة | ليست كل مجاورة اسمين إسنادًا؛ تبقى دلالتا الفرد والجمع في «ولد» دون تعيين واقع |
| المعجم والاستعمال | ثلاثة معانٍ موثقة لـ«العين»، وصور محددة للتنوين، وتراكيب وصف وإدراك ونفي وشرب | تُحفظ البدائل؛ القراءة في الاصطلاح المحدد لا تثبت قصد المؤلف الفعلي أو صدق الخبر |

يعيد كل مسار قراءة النص الأصلي نفسه. لا يرسل نصًا مصححًا أو مشكولًا بدل
المصدر إلى قارئ الإسناد أو المعنى. تتصل العلامات المستكملة بقالب مؤلف محدد
ومقطع مصدر أصلي؛ ليست سلاسل القوالب اقتباسات حرفية من الكتب.

في الوصل، تبقى خلايا الكلمة عند الابتداء منفصلة عن خلايا النطق المتصل.
تبقى قطعة الألف وموقعها حتى حين يصير نطقها فارغًا، وتُفحص العبارة المتصلة
مرة واحدة من حالة البداية. لا تصدر شهادة كلمة منفردة لابتداء حُذفت همزته.

## البرهان ومراجع التكامل

أضيفت 30 مبرهنة معلنة: 15 للتحصيل المتصل وحفظ المصدر والتسليم للشكل، و15
للقراءة المعجمية الصورية والقواعد المحدودة للشخص والإسناد ودقة محللها.
أصبح الفهرس المترجم 1544 تصريحًا و1541 بنية عبارة مطبعة. يبقى تدقيق جميع
تصريحات `Nabt` مفعّلًا؛ لا مسلمة مشروع أو `sorry` أو تجاوز للنواة.

«دقة المحلل» هنا بالنسبة إلى العلاقة الصورية والجدول المعلنين، وليست
برهانًا أن هذا الجدول يستوعب العربية أو يطابق كل تأويل للمصادر. فحص
التنفيذ الأصلي ومقارنته بـPython شاهد تنفيذ محدود، لا مبرهنة تنقيح عامة.

تجتمع مراجع البرهان واللغة والمعنى والاستدلال والتحصيل في
`evidence/sourced_acquisition_v3/integration/`. يختارها الملف الواحد
`integrations/current_proof_references.mk`. ظلت اللقطات القديمة محفوظة.
يربط فهرس القواعد الحالي 54 إحالة، والفهرس الجديد للتحصيل 38 إحالة
مراجعة إلى تصريحات مترجمة؛ المقاطع المحفوظة دون دعوى مبرهنة ظاهرة منفصلة.

## التشغيل

من جذر المستودع، بعد تثبيت إصدار Lean المثبت في `formal/lean-toolchain`:

```sh
cd formal
lake build connectedAcquisitionV3 acquiredSyntaxV3 linguisticTruth
cd ..
PYTHONPATH=src:. python -m tools.sourced_acquisition_cli --task person --text 'قمتُ' --summary
PYTHONPATH=src:. python -m tools.sourced_acquisition_cli --task nominal_syntax --text 'الولدُ ذاهبٌ' --summary
PYTHONPATH=src:. python -m tools.sourced_acquisition_cli --task pronunciation --text 'قَالَ الْحَقَّ' --onset connected --summary
PYTHONPATH=src:. python -m tools.sourced_acquisition_cli --task natural --text 'الْعَيْنُ الْجَارِيَةُ' --onset connected --summary
```

`--summary` يغير العرض وحده. التقرير الكامل يحفظ المصدر والخلايا والمقاطع
والبدائل ونتائج الفحص. `chain_complete` لا يصح مع تحصيل مؤجل ولو نجحت
قراءة نحوية أو معجمية داخلية. `verified` وإعادة الإيصال واكتمال المرحلة
ليست مفاهيم مترادفة؛ يحدد عقد كل واجهة مجالها.

تعيد واجهة الأوامر رمز الخروج 2 عند تعطل التحقق، بما فيه
`SHAPE_CHECK_FAILED`. يبقى التأجيل العادي `DEFER` تنفيذًا ناجحًا برمز 0،
مع بقاء القراءة غير مكتسبة. لا يغير `--summary` هذا العقد.

## المواصفة والاختبار المستقل

ثُبتت المواصفات والمصادر في `88264da`، ثم صُححت إحالة داخلية واحدة إلى
الشاهد النهائي للنفي في `d597b85` قبل أي تنفيذ. ثُبتت المصفوفة في
`286651f` قبل إنشاء وحدات الإنتاج الجديدة. تضم 161 حالة و109 أهداف موجبة
مطلوبة في أربع عائلات. كُتبت توقعاتها دون قراءة التنفيذ الجديد أو تشغيله؛
الضوابط العشرة المنقولة من PR 34 موسومة بوصفها أمثلة تاريخية مكشوفة.

يقارن المقيم بايتات المصادر والملفات الأصلية بالنسخة المجمدة قبل استيراد
التنفيذ، ويستورد Python من المصدر المتحقق منه، ثم يعيد فحص الهويات بعد
التشغيل. يفحص حدود القطع داخل كل كلمة في تمثيلي الابتداء والوصل، وربط
خلايا الشهادات، ومقاطع الشخص والإسناد والمعنى. لا تكفي أعلام المنتج أو
تساوي لقطة البداية والنهاية إذا اختلفتا عن النسخة المجمدة.

```sh
make -f tools/sourced_acquisition_v3.mk sourced-acquisition-evaluation \
  LAKE=/path/to/pinned/lake EVIDENCE_DIR=artifacts/local/v3-run-1
```

تُستعمل وجهة جديدة لكل تشغيل؛ لا تستبدل المحاولة الأولى. البوابة تبني
وتفحص وتعـيد v1 وv2 وPR 34 أولًا، ثم النسخة الجديدة. نتائج `first` تسجل
دعوى أول تنفيذ مع فحص التسلسل والبصمات؛ لا يثبت Git سرية المصفوفة أو عدم
وجود تشغيل خارجي غير معلن. كل إعادة بعد ظهور النتيجة موسومة `exposed`.

حُفظ التشغيل الأول الفعلي على `ab8640b` في
`evidence/sourced_acquisition_v3/validation/first-matrix-ab8640b/`.
أظهر 158/161 مطابقة و90/109 هدفًا موجبًا و52/52 ضابطًا سالبًا.
كانت الاختلافات الثلاثة في أرقام خلايا «العين»: كتب مؤلف المصفوفة 64
المخصصة لـ«ظَ»، بينما تعريف A116 المجمد يوجب 68 لـ«عَ».
راجع ذلك مؤلف المصفوفة ومراجع البرهان كلٌ على حدة؛ التنفيذ يعيد 68 بالفعل.
يسجل `gold_erratum_v1.json` ستة تصحيحات عددية فقط، دون تغيير أي حالة أو
غاية أو مقام. الأصل ونتيجته محفوظان. إصدار المقيم `review1` يقبل الإعادة
المكشوفة فقط، ويُظهر إسقاطات الأصل والتصحيح معًا. هذا تصحيح للقياس ولا
يُحسب اكتسابًا لغويًا جديدًا. كما يمنع المقيم احتساب ترخيص خاطئ ضمن التغطية
أو السلاسل الكاملة لمجرد مطابقته غايةً تقتصر على حالة النجاح.

الإعادة الفعلية المكشوفة على `eee0016` اجتازت 161/161 مطابقة مصححة، مع
90/109 غايات موجبة و52/52 ضابطًا سالبًا وصفر ترخيص خاطئ مرصود.
تطابقت تقارير المنتج الـ161 مع التشغيل الأول حرفيًا عند مقارنة JSON
المطبّع. تُفصّل [حصيلة التشغيل والديون المتبقية](SOURCED_ACQUISITION_V3_RESULTS_AR.md)
المقامات والفحوص والمحاولات المحفوظة وقياس الاقتران.

تُنشر مطابقة العقد، والتغطية الموجبة، وضوابط الامتناع، والمرشحات المعجمية،
والسلاسل الكاملة بمقامات منفصلة. الامتناع الصحيح عن مثال مطلوب موجب نقص
تغطية. لا تجمع نتائج العائلات المتباينة في «نسبة اكتمال العربية»، ولا تجعل
نجاح استرجاع المعاني بديلًا عن تحصيل القراءة المطلوبة.

## الانتروبيا والالتزامات المتبقية

توجّه الانتروبيا ومكونات الاعتماد مراجعة واجهات الربط. تبقى المراحل الجديدة
في `tools/`، ويستخدم فاحص سلامة المقيم المكتبة القياسية فقط. لا تدخل النواة
في اعتماد عكسي على الأدوات، ولا تزال النسخ التاريخية أو المراجع المستقلة
موجودة. اتجاه تغير Shannon ليس حكمًا على الجودة أو اكتمال العربية.

تبقى خارج المجال: التحصيل العام للكلمات غير المضبوطة، تعويض الألفات
المحذوفة بمعجم شامل، جميع إصلاحات التقاء الساكنين في الوصل، الصرف والإسناد
المنتجان غير المحصورين، المرجع المستتر العام، اختيار المراد المجازي من
السياق الحر، وصدق الخبر في العالم. تُضاف هذه بقوانين ومصادر ومصفوفات جديدة،
دون توسيع صلاحية النسخة الحالية بصمت.
