# الوقوع والمعنى والإحالة

تضيف هذه الحزمة إلى NABT مسارًا يبدأ من موضع لفظ في نص فعلي، ويستعيد
قراءاته الصرفية المشهودة، ثم يعرض مرشحات معانيه مع فحص جهة الدلالة
المشروطة بكل معنى. تحمل الاستجابة أيضًا إيصال الإحالة الابتدائية في المقام
نفسه. المقصود بـ«الوقوع» هنا وقوع اللفظ في النص، وليس إثبات وقوع حدث في العالم.

بُني العمل على `130fa4ba13ed505039d425271a1e5fcf56058f86`، أساس PR #43.
أعيد استعمال `ContextualReference` و`LexicalDenotation` وكتالوج الدلالة
ومصفوفة المحاذاة. لا توجد تبعية تشغيلية لـMashru، ولا شهادة عامة تسمح
بإسناد أي معنى لأي جذر. المقارنة المحددة مع Mashru ومراجعة التفسير في
[المراجعة المصدرية](OCCURRENCE_SENSE_SOURCE_REVIEW_AR.md).

## السلوك

| الطبقة | العمل المنفذ | الحد |
|---|---|---|
| وقوع اللفظ | حفظ النص الخام وبصمته والموضع ببايتات UTF-8 وفهرس الكلمة الخارجية | محتوى الاقتباس لا يدخل في فهرسة الكلمات الخارجية |
| اكتساب القراءة | جمع جميع شواهد STEM المتوافقة في مصدر QAC المثبت وحفظ اختلاف الصيغة واللمّة والجذر والنوع | التغطية خاصة بهذا المصدر وسياسة الرسم؛ لا توليد عام للتصريف |
| مرشحات المعنى | فحص جميع روابط المصفوفة المثبتة، وحفظ المعنى الكامل ومصدره | المحاذاة بين المعجم والصرف مؤلفة ولم تحسم لغويًا لكل وقوع |
| جهة الدلالة | المطابقة والتضمن والالتزام لكل معنى كامل بالمدقق الموجود | لا تصبح أجزاء عبارة الشرح أجزاء اصطلاحية تلقائيًا |
| الإحالة | إعادة تشغيل إيصال PR #43 على النص والمقام نفسيهما | الإيصال متعلق بوقوعه الابتدائي، ولا ينقل إحالة «هذا» إلى الاسم التالي |

يظل معنى «القلم» المراد معلقًا عندما توجد عدة معانٍ مرشحة. ولا تجعل
إحالة «أنا» إلى متكلم معين معنى الاسم الخبري أو صدق الخبر أمرًا مثبتًا.
حتى المرشح الوحيد يحمل قيد عدم اكتمال دليل انطباق المعنى في السياق.

## واجهة الطلب

`tools.occurrence_sense.assess(request)` يستقبل خمسة حقول فقط:

```json
{
  "text": "قلم",
  "context": {},
  "token_index": 0,
  "target": ["الذي يكتب به"],
  "budget": 100000
}
```

`token_index` يبدأ من صفر ويعد وحدات `written_run` الخارجية في القارئ
القائم. لا يعد علامات الترقيم أو محتويات الاقتباس. `target` سؤال دلالي
صريح من مقومات كاملة، وليس جوابًا أو مصدر سلطة. لا يقبل الطلب جذورًا أو
معاني أو شواهد أو نتائج مرجعية يختارها المتصل.

`budget` عدد صحيح غير سالب؛ ترفض القيم المنطقية مكان الأعداد. الحد
العام 1,000,000، والحد الداخلي 256 مجموعة صرفية، و4096 شاهدًا، و1 MiB
لحمولة الفاحص الأصلي. يرتبط الإيصال بالميزانية المطلوبة، وتستعمل المقارنة
الحد الفعال الأصغر. نفاد الميزانية يخرج بنتيجة `RESOURCE_LIMIT` مستقلة.
تبقى الحدود الأدنى للقارئ المعاد استعماله نافذة؛ حد غلاف JSON لا يوسع
نطاق قراءة النص.

تحتوي الاستجابة `readings` و`candidate_senses` وشواهد المصدر وإيصال
`initial_reference` المنفصل. `native_checked` يخص فحص الحزمة المعجمية؛
يفحص المستهلك أعلام إيصال الإحالة أيضًا عند الاعتماد عليه. لا تعني
`certificate_checked` اختيار المعنى أو صحة السياق المعلن في العالم.

| الحالة | معناها |
|---|---|
| `CANDIDATES_ONLY` | لكل قراءة مكتسبة مرشح في الكتالوج؛ لا اختيار للمعنى |
| `PARTIAL_CANDIDATES` | بعض القراءات لا يملك مرشحًا معجميًا، وبقي ظاهرًا |
| `NO_DICTIONARY_CANDIDATE` | قراءات مشهودة بلا رابط في الكتالوج المحدود |
| `NO_MORPHOLOGY_READING` | لا شاهد صرفي مطابق في نطاق المصدر والسياسة |
| `RESOURCE_LIMIT` | توقف بسبب حد موارد؛ لا حكم لغوي |
| `INVALID_INPUT` | طلب لا يوافق العقد |
| `UNMEASURED` | مصدر أو مدقق مفقود، أو فشل مطابقة الإيصال أو الهوية |

لا تعني حالتا غياب المرشح أن الكلمة غير عربية أو بلا معنى.

## حدود البرهان والثقة

قانون `nabt.occurrence-sense-candidates.v1` ينفذ في
`formal/Nabt/OccurrenceSense.lean`، ومدققه `occurrenceSense` يعيد تحليل
الشواهد وتعداد القراءات وروابط المعاني وفحص الدلالات. لا يكتفي بقبول
علم نجاح من Python. يقارن المحول تصدير الكتالوج والروابط من الملف
التنفيذي بالسجلات المثبتة، ويعيد فحص الهوية قبل التنفيذ وبعده.

البرهان عام بالنسبة إلى المدخلات والميزانية والسجل المثبت: يحفظ وقوع
النص والمقام والسؤال والميزانية، ويمنع إعادة استعمال الإيصال عند تغير
هذه القيود، ويبقي جميع البدائل المكتسبة والمرشحات المرتبطة بها. جمع
جميع شواهد ملف المصدر، وصحة تحويلات Python، وتفسير النصوص المعجمية،
ونسبة المصدر وتاريخ نقله تظل التزامات منفصلة عن نواة Lean.

النتائج الدلالية مشروطة بانطباق المعنى الكامل. لا توجد قاعدة لاختيار
المعنى السياقي في هذه الإضافة، ولا قاعدة لربط إحالة الضمير بالاسم
الخبري، ولا دعوى باستنفاد العربية أو إثبات التواتر أو صدق العالم.

## القياس المستقل وإعادة التشغيل

ثُبّتت 20 حالة و5 علاقات تبديل و6 التزامات سلامة قبل كتابة الجسر في
commit `16f8cb0`. لم يقرأ مطورا التشغيل والبرهان أجوبتها أثناء التنفيذ
الأول. المرجع مؤلف بواسطة وكيل مستقل ضمن الجلسة؛ ليس تحكيمًا لغويًا
بشريًا خارجيًا. تبقى ملفات التثبيت الأصلية دون تعديل.

تقاس سلامة الشهادة، واكتساب المرشحات، والتغطية اللغوية المطلوبة، وبقاء
الغموض، والإحالة، وأثر تبديل المقام كل على حدة. الامتناع الصحيح لا يحتسب
نجاحًا في اكتساب معنى لم يستعده النظام. لا تتغير الحالات التاريخية الـ25
أو مقاماتها بهذه الحزمة.

ظهر في التشغيل الأول خطأ تأليف في المرجع: مشاركة قائمة مرشحين مع
قائمة أصول أدت إلى إدخال `QATR-REFERENCE` و`SIRAFI-PARTICIPANTS` في تسع
قوائم مرشحين وقائمة منع واحدة. هذان معرفا مقاطع وليسا معرفي معنى في
الكتالوج المثبت. يسجل `reference_erratum_v1.json` كل قيمة قبل التصحيح
وبعده، ويحظر تعديل المدخلات والمعاني الحقيقية. بقيت ملفات التجميد
والتقرير الأول دون تعديل. المرجع المصحح موثق **بعد المشاهدة**؛ لا يوصف
كتقييم أعمى جديد، ولم يتغير التنفيذ بين القياسين.

| المحور في المرجع المصحح | النجاح / المقام | تفسير النتيجة |
|---|---|---|
| سلامة حدود الاستجابة | 20/20 | يشمل الامتناع الصريح؛ ليس دقة لغوية |
| الفحص الأصلي في الحالات المؤهلة | 18/18 | استقلال صحة الإيصال عن صحة المرجع |
| اكتساب المرشحين المطلوبين إيجابيًا | 10/14 | أربع حالات فشل فعلية باقية |
| جميع التزامات قوائم المرشحين | 13/17 | يتضمن ثلاث قوائم فارغة مطلوبة؛ لا يخلط مع المقام الإيجابي |
| جهات الدلالة المشروطة | 13/17 | نجاحها يتطلب أولًا اكتساب المعنى المطلوب |
| حفظ جميع البدائل المرجعية | 7/10 | ثلاث حالات تعذر فيها اكتساب المرشحين |
| الإحالة الابتدائية | 6/6 | بالنسبة إلى المقام المعلن والوقوع الابتدائي فقط |
| فصل إحالة الضمير عن الاسم التالي | 20/20 | لا توجد ترقية غير مرخصة |
| أزواج تبديل المقام أو السؤال | 4/5 | الزوج المتبقي يتعثر عند اكتساب «قَلَمٌ» |
| التزامات الحدود والموارد والتغطية | 5/7 | الغياب الآمن لا يحقق اشتراط وجود القراءة |
| مطلب تغطية إضافي | 0/1 | «سَرِيرٌ» غير مكتسب في هذا المسار |

لم تُكتسب صيغ «الشَّمْسُ» و«قَلَمٌ» و«سَرِيرٌ» و«رِجْلٌ» في الحالات
المحددة. القارئ هنا يطابق صيغ STEM المشهودة دون تبديل الحركات النهائية
أو تركيب أداة التعريف آليًا. العلاج اللاحق يحتاج جسر تصريف وتركيب
مسندًا إلى قانون؛ لا يكفي حذف العلامات أو توسيع شهادة الجذر. نجح تبديل
المتكلم في «أَنَا رَجُلٌ» مع ثبات مرشحات الاسم وتغير مرجع «أنا»، وبقي
إسناد الاسم إلى المرجع خارج نطاق البرهان.

التقريران `benchmark_initial.json` و`benchmark_initial_corrected.json`
وسجل `benchmark_review.json` يتيحون المقارنة بالأرقام الأصلية. العدد
الحالي للمبرهنات المفحوصة 1524، منها 21 جديدة؛ وفهرسة العبارات المترجمة
تعطي 1521 بنية متميزة دون زيادة التكرارات التاريخية الثلاثة.

```bash
make -f Makefile -f integrations/occurrence_sense.mk occurrence-sense LAKE=/path/to/lake
python tools/occurrence_sense.py --request evidence/occurrence_sense_v1/example_request.json
python tools/benchmark_occurrence_sense.py --require-native --require-safety --output artifacts/local/occurrence-sense/benchmark.json
make test formal conformance LAKE=/path/to/lake
make check LAKE=/path/to/lake
```

بوابة GitHub Actions في `.github/workflows/occurrence-sense.yml` تعيد
المصادر والبناء وتدقيق المسلمات والاختبارات والمرجع المستقل. لا تحسب
إضافة ملف البوابة نجاحًا لها عن بُعد؛ سجل الفحص المحلي منفصل.

اجتازت بوابة الحزمة المحلية 46 اختبارًا دون تخطٍّ، مع إعادة المصادر
وبناء المدققين وتدقيق المسلمات. اكتملت بوابات `make check` على مراحل:
توقف الاستدعاء الأول عند غياب صلاحية التنفيذ لملف مولد، ثم أعيدت
صلاحية ملفين دون تغيير بصماتهما، واجتازت الأهداف المتبقية والفحص
النهائي للسلامة. لم تعدل قاعدة لتجاوز الاختبار. سجل الاستدعاء الأول
المحفوظ جزئي؛ لذلك لا يقدم عدد إجمالي لاختبارات المستودع. تفاصيل
الأوامر وحدود السجلات في `evidence/occurrence_sense_v1/validation.json`.
