# وكيل الإعراب والاسترجاع — عقد الدفعة الأولى

المشكلة: يعرض وكيل العوامل الإسناد، بينما يعرض قارئ الإعراب العلامات
في أطر محدودة؛ يحتاج المستعمل إلى مدخل واحد يسترجع الباب ويعرض الدور
والحالة والعلامة والمحل، مع شهادة صاحبه والبدائل التي لم تحسم.

## عقد القبول المثبت قبل التنفيذ

- يستعمل الوكيل `read_discourse` و`read_inflection` والفهرس المصدري
  و`SearchIndex` الحاليين. لا يضيف قواعد قبول إلى النواة.
- أربعة مناظير للحالات: المرفوعات والمنصوبات والمجرورات والمجزومات.
  ومناظير للعلاقات: الفاعلية، النيابة عن الفاعل، المفعولية، الإسناد،
  الإضافة، التبعية، الحال والتمييز والظرفية، السببية والمسببية.
- الحالة المطلوبة في مرشح ليست الحالة الثابتة. تحفظ البدائل بمعرف
  صاحبها وتحليلها؛ لا تدمج نتائج قارئين في شهادة واحدة.
- يحفظ الإعراب اللفظي والمحلي وعلامات الظهور والتقدير والحذف كما
  أرجعها صاحب القاعدة. لا يحوّل كل ضمة إلى فاعل ولا كل فتحة إلى مفعول.
- الاسترجاع والشرح مرتبطان بمواضع المصادر المحققة. حد عرض الاسترجاع
  لا يختزل تحليلات القارئ. تصنيف البطاقات تأليف تعليمي قابل للمراجعة.
- السببية والمسببية منظورا طرفي علاقة تحتاج شاهدًا؛ ليستا حالتين
  إعرابيتين، ولا تعني المسببية استنتاج السبب من النتيجة. شاهد قطر
  الندى الحالي يخص فاء السببية وشروطها. السببية الواقعية، والعلة
  الأصولية، والسببية والمسببية في المجاز المرسل تحتاج عقودًا وشواهد
  مستقلة. لا ينشئ هذا المدخل علاقة سببية من ظهور الفاء أو «لأن».
- يعيد التحقق تشغيل المالكين من طلب مستقل، ويقارن التقرير كله، بما
  فيه الشرح والفهارس والمصادر. سحب المعجم أو تغيير النص يبطل التطابق.
- الاختبارات تشمل رفض الخلط بين الرفع والفاعلية، وحذف النون وحرف
  العلة، والمبني في محل جزم، وسحب الشاهد، وتزوير الدور أو الشرح،
  واختلاف حدود عرض الاسترجاع. الاختبارات دليل تنفيذ محدود؛ ليست
  برهان اكتمال العربية ولا برهان تنقيح Python إلى Lean.

## الاستخدام

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog irab catalog
PYTHONPATH=src:. python -m tools.grammar_catalog irab answer 'المرفوعات'
PYTHONPATH=src:. python -m tools.grammar_catalog irab answer 'السببية والمسببية' --domain cause
PYTHONPATH=src:. python -m tools.grammar_catalog irab analyze --request examples/irab_agent/jussive.json --output /tmp/irab.json
PYTHONPATH=src:. python -m tools.grammar_catalog irab analyze --request examples/irab_agent/jussive.json --verify /tmp/irab.json
make -f Makefile -f integrations/grammar_catalog.mk irab-agent
```

طلب التحليل: `text`، واختياريًا `lexical_text` بصيغة QAC و`context`
وفق عقد قارئ الخطاب، و`query` و`domain` و`limit` للاسترجاع فقط.
لا يقبل الطلب أعلامًا تمنح ترخيصًا نحويًا أو سببيًا.

`owner_reports` يحتفظ بالمخرجين الكاملين؛ `rows` عرض مشتق، و`views`
فهارس لمعرفات الصفوف المرخصة فقط. `analysis_id` أو `relation_id`
يحفظ ارتباط كل دور ببديله. `candidate_role` لا يرقى إلى `actual_role`.
وجود صف مرخص لا يعني اكتمال جميع قراءات النص. تبقى حالات أصحاب
التقارير ونواقصهم ظاهرة، وتظل الحقيقة الخارجية مستقلة عن صحة الإعراب.

## حدود هذه الدفعة

البطاقات تحيل إلى القواعد والشواهد المنصبة؛ لا تدعي استيعاب كل أبواب
المنصوبات أو استنتاج كل عامل محذوف. التحليل الآلي مقيد بتغطية القارئين
والمعجم والسياق المعطيين. المنظور السببي يعرض النقص ولا يمنح شهادة
تطبيق جديدة. هذه واجهة استرجاع وتحليل، وليست تدريبًا عصبيًا جديدًا.
