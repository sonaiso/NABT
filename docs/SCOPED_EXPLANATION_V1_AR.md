# إعادة الصياغة وشرح سند النطاق — v1

## عقد القبول قبل التنفيذ — 2026-11-10

أصل الفحص `de3dd2af6dd934803b3356843571d22d5fb40eaf`.
نجح تشغيل مثال الكم الحالي وإعادة قبول إيصال البوابة. حفظ المالك نطاق
النفي والشواهد وتاريخ السحب، لكنه لم يُصدر إعادة صياغة يعيد قراءتها، ولا
عرضًا لكل مقدمة في طرق تأييد القضية ومعارضتها مرتبطًا بموضع شاهدها.

نوسع خرج `composition.analyze`، في ملفه الكمي الحالي فقط. لا نغير اللغة
المقبولة أو قانون الكم أو حد الأفراد الأربعة، ولا نضيف محرك استدلال أو
سجل مبرهنات. يعاد استعمال `ScopedQuantifier` و`source_learning_connection`
و`VerifiedReading` و`EvidenceLifecycleV1`. يحفظ `MeaningPreservation` عقد
النقل في مجاله الأصلي؛ لا نسمي هذه المقارنة برهانًا عامًا لتكافؤ العربية.

1. تعاد صياغة المصدر بصيغة عربية مضبوطة؛ ثم يقرأها فاحص Lean الموجود
   مستقلًا. يجب أن تتطابق بنية النطاق والجنس والصفة وقوة القول والمجال
   والقواعد المولدة والاستعلام، مع الاحتفاظ بالمصدر ومواضعه كما هي.
2. السؤال يظل سؤالًا. لا تدخل العبارة المعاد صياغتها ضمن شواهد القضية،
   ولا تتحول صحة الفهم إلى ثبوت الواقعة أو اعتماد الجواب.
3. لا يكفي تساوي الجواب على عينة لإعلان حفظ النطاق: «ليس كل» و«كل… ليس»
   قد تتفقان في النتيجة وتختلفان في المضمون. تغيير النطاق في إعادة
   الصياغة يمنع اكتمال السلسلة ولو اتفق الجواب.
4. يقرأ شرح الأدلة الشهادة الأصلية فقط: لكل طريق تأييد أو معارضة قائمة
   مقدمات، ومؤشرات إلى الوقائع المصدرية ومواضعها، والشواهد المضادة،
   وتوافر القاعدة، والنقص والتعارض. الحكم من المالك الأصلي وحده.
5. مصدر نشط يعتمد على مصدر مسحوب لا يعرض كشاهد جاهز. سحب السياسة منفصل
   عن اكتمال مقدماتها. لا يصبح نقص شاهد العضوية نفيًا للعضوية أو الصفة.
6. يحفظ عرض التاريخ تغير الشواهد مع ثبات الحكم، وتغير الحكم عند سقوط
   سنده. تبقى الشواهد البديلة والوقائع الخارجية عن مجال الكم في الأصل.
7. لا يصدر عرض أدلة مكتمل إذا لم تكتمل الفحوص الأصلية. لا يَقبل العميل
   حقل صياغة أو حكم أو تفسير مفروضًا؛ إعادة فحص البوابة تحمي الخرج كله.

## أمثلة القبول والإبطال

| المدخل أو التغيير | النتيجة المطلوبة |
| --- | --- |
| «ليس كل طالب مجتهدًا» | صياغة «ليس كل طالب هو مجتهد.» مع فحص النطاق نفسه |
| «هل كل مهندس ليس هو حاضر؟» | حفظ السؤال والنفي الداخلي؛ لا إثبات حضور أو غياب من السؤال |
| نفي الاجتهاد عن كل فرد في العينة | اتفاق جواب العبارتين لا يدمج شجرتي نطاقهما |
| استبدال الصياغة بـ«كل طالب ليس هو مجتهد.» | فشل حفظ النطاق عند مصدر «ليس كل…» |
| سحب انتماء المثال المضاد إلى الجنس | مقدمة عضوية ناقصة؛ لا مثال مضاد مكتمل |
| سحب أصل تعتمد عليه نسخة أخرى | تبقى النسخة في السجل وتختفي من الشواهد الجاهزة |
| سحب السياسة مع بقاء الوقائع | عرض اكتمال الوقائع وغياب القاعدة وحكم غير محسوم |
| تحريف مؤشر شاهد أو الصياغة في الإيصال | رفض إعادة القبول عبر البوابة |

الفحص تنفيذي محدود. لا يضاف تدريب عصبي، ولا برهان عام لتنقيح Python
إلى Lean، ولا شهادة أصالة للمصدر أو صدق للعالم. قائمة المجال ليست شاهد
انتماء أفرادها، والمصدر الأصلي لا يُستبدل بإعادة صياغته.

## الخرج وإعادة الاستعمال

يضاف `reading_view` و`evidence_view` إلى نتيجة المسار الحالي، دون تغيير
حقول الطلب. الأول يحمل النص المضبوط وفحصه الأصلي وإسقاط المعنى المقارن.
قد يكتمل فحص القراءة مع بقاء الشواهد ناقصة أو تعذر استكمال فحصها؛ فلا
يُستعمل هذا الحقل وحده بوصفه حكمًا مثبتًا.

الثاني عرض للشهادة الأصلية، ولا يعيد حساب القرار. يحتوي `source_ledger`
بمواضع UTF-8، و`history` بكل خطوة، ثم `branches` التي تشير إلى القواعد
الأرضية ومواضع مصادرها. لكل مقدمة مؤشرات شواهدها وشواهد نقيضها، وعضويتها
في الإغلاق العام والنظيف. يعرض النقص والمعارضة وعدم نظافة الدعم منفصلة؛
وجود شاهد مباشر لا يضمن نظافة كل طريق استدلال يستهلكه.

انتقل عرض الوقائع والمقدمات الموجود في `case_application` إلى
`source_evidence_view` لإعادة استعماله هنا مع الحفاظ على خرج تطبيق
الواقعة نفسه. لا يستبدل هذا العرض مصدرًا ولا فاحصًا ولا دورة أدلة.
يبقى `owner_result` كاملًا، بما فيه الدعم البديل والاعتماد والتعارض.

```sh
make scoped-composition LAKE=/path/to/lean-4.34.1-linux/bin/lake
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/composition_explanation.json --output artifacts/local/composition-explanation.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/composition_explanation.json --receipt artifacts/local/composition-explanation.json
```

تشمل بوابة التركيب الأصلية اختبارات `test_composition_explanation`،
وتختبر بوابة تطبيق الواقعة استمرار خرج العرض المشترك. فهرس البرهان
وملف المبرهنات وملفات Lean لم تتغير؛ روابط الاختبارات ملاحة إلى الفحوص
وليست دعوى تشغيلها أو برهانًا لتنقيح طبقة الشرح. يسجل التنفيذ الفعلي
في مخرجات الاختبارات وCI الخاصة بالإصدار.
