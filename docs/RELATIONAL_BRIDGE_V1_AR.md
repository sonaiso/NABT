# الجسر المرخص للأجناس والخواص والقابلية والوقوع والسببية

القانون `nabt.relational-bridge.v1` امتداد داخل `relations.analyze` في
بوابة NABT الوحيدة. لا يوجد فهرس مبرهنات أو محرك استدلال أو منفذ خارجي
جديد. يعاد استعمال `VerifiedReading` لاستعادة النص الأصلي وفحص إغلاق
الاشتقاق الكامل والنظيف، و`QualifiedInference` للشروط والموانع والتعارض.

## المجال المنفذ

يستقبل `bridge` نص سجل علاقات بالعربية المضبوطة لبروتوكول القارئ الموجود،
ومصدره ونسخته ونطاقه، وإطارًا يحدد اللفظ وموضعه وقراءته والفرد والجنس
والخاصية والحدث والزمان والمكان والسبب. يدخل النص المراد تحليله في
`payload.text`، ويُفتح مستقلًا عن الشهادة. offsets هي محارف Unicode
وليست بايتات UTF-8. حدود الكلمة واجبة؛ لا يؤخذ «اصفرّ» من «واصفرّ» أو
«اصفرّون» على أنه وقوع مستقل.

مراتب هذه الشريحة: `disposition` ثم `occurrence` ثم `causality`.
يفرض Lean نفسه قائمة المتطلبات، ولا يقبل حذفها بخطة المستدعي:
ربط الوقوع بالنص الكامل والموضع؛ العضوية؛ القراءة المحددة؛ ربط موضع
اللفظ بالحدث المعين؛ معنى الحدث؛
حامل الصفة؛ الخاصية؛ قبول الجنس للخاصية؛ صلة المعنى بالخاصية؛ القابلية؛
الشروط؛ شاهد نفي المانع؛ المكان؛ الزمان. يضاف شاهد وقوع للمرتبة الثانية،
وشاهد السبب والأثر للثالثة. المصدر يقرر تفسير هذه المحمولات؛ التحقق
لا يمنح المعنى أو الصدق لاسم محمول بمجرد تسميته «دليل_سببي».

ربط النص يستخدم سلسلة أعداد محارفه كاملة، لا بصمة مختزلة، ويعيد Lean
حسابها. يربط سجل `موضع` البداية والنهاية، فلا يعاد استعمال شاهد موضع
لتكرار آخر من اللفظ نفسه. عندما يزيد اسم الربط عن حد القارئ، 512 محرفًا،
تكون النتيجة `RESOURCE_LIMIT`؛ لا يبتر النص ولا يدعي اكتمالًا لغويًا.

القراءات المثبتة هي اصفرّ، ومُصْفَرّ، وكَبِرَ للسن، وكَبُرَ للعظم.
تُحفظ قراءتا «كبر» عند غياب التشكيل؛ الترخيص مشروط بالقراءة المحددة في
السجل وشاهدها. الجرد محدود، ولا يعلن استنفاد العربية أو تعيين المعنى
المقصود في كل مقام. مراجع المراجعة المعجمية وتطبيقها مسجلة في
`tools/grammar_catalog/data/relational_readings_v1.json`، وتظهر ضمن
بطاقات RAG الحالية. هذه مراجعات مختارة وليست ادعاء تدقيق طبعة كاملة.
تقع البيانات ضمن امتداد البوابة وتغطيها بصمتها؛ لا يتغير جرد `src/`
المجمّد لتقييمات العربية السابقة ولا تُعدّل مراجع نجاحها أو إخفاقها.

## التحقق والبرهان

يوجد القانون في `formal/Nabt/RelationalBridge.lean` ويستهلكه المنفذ
الموجود `verifiedReading` عبر مساره الداخلي `relational`. يقترح Python
شهادة القارئ الموجودة، ثم يعيد Lean قراءة المصدر المستقل وفحص جميع
المقدمات. يحتفظ الإيصال بالنصين والإطار والقائمة الكاملة للمقدمات،
وحالة كل منها: موجودة، نظيفة، ومعارضة، وبالشهادة الأصلية ومخطط شواهدها.

المبرهنات مسجلة في `formal/theorems.json` وفي الفهرس المجمّع الحالي:
شرط القبول الدقيق، ومطابقة مصدر الشهادة، واشتقاق كل متطلب مقبول من
نظرية المصدر، وعدم الانتقال إلى الوقوع أو السببية دون شاهدهما،
ووجوب نفي المانع صراحة، ومنع المعارض والسند المشتق من تعارض، ورفض
شهادة المصدر القديم بعد تغيره، وحفظ الفروق داخل الجرد الصرفي المحدد.
هذا برهان لعقد التحقق، وليس برهانًا على صدق السجل أو الحس أو اكتشاف
سبب طبيعي. لا يستخدم القانون `sorry` أو مسلمات خاصة أو `native_decide`.

القبول يعيد `SCOPED_SOURCE_LICENSE` مع دعوى ذات سلطة `SOURCE_RELATIVE`.
يبقى `world_truth_established=false` و`empirical_causality_established=false`
و`grammar_acquisition_proved=false`. لا يصح قراءة هذه العلامات بوصفها
غيابًا للتنفيذ؛ التنفيذ ينجز شهادة مشروطة بالسجل، ويصرح بالالتزامات
التي تقع خارج نطاقه. بدون `bridge` يبقى سلوك وصلة العلاقات السابق.

## التشغيل

```sh
make relational-bridge LAKE=/absolute/path/to/lake
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/relational_bridge.json --output artifacts/local/relational-receipt.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/relational_bridge.json --receipt artifacts/local/relational-receipt.json
```

أمثلة الاختبار مؤلفة ومعلنة. حالات سحب السبب، والقابلية دون وقوع،
والمانع المجهول والمثبت والمنفي، والتعارض المباشر والموروث، والسند
البديل، وفروق التشكيل، وتكرار اللفظ، وتبديل المرجع أو الموضع، وتحريف
الشهادة؛ كلها في `tests/test_relational_bridge.py`. تحفظ سجلات التشغيل
المنجزة وأوامرها وحدودها في سجل هذه الدفعة، ولا تُستبدل الأدلة السابقة.
