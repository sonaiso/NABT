## العقود المشتركة

يبقى `gateway run/verify` حد الإدخال والإخراج الخارجي الوحيد. يحتفظ المستهلك
بالطلب مستقلًا ويقبل إيصال البوابة بعد إعادة تشغيله. تستخدم الدفعة محققات
العلاقات والدروس والمصدر وLean القائمة؛ لا تضيف سجل مبرهنات أو بوابة سلطة
منافسة. إحالات `tools/entropy_framework/registry.json` مراجع اكتشاف واختبار
وليست دليلًا على تنفيذ تلك الاختبارات أو إثباتًا لجسر دلالي عام.

| موضع الوصل | السلوك بعد التكامل |
| --- | --- |
| `cognitive.lesson` | تبقى جميع محولات الدروس التسعة، ومنها المدرسة والشواهد وOpenCyc، مسجلة معًا |
| `relations.analyze` | يقبل `report_model` و`opencyc_slice` معًا؛ يفحص كل مالك مدخلاته ويحتفظ بنتيجته |
| `text.read` | يحتفظ بإحالة `rule-learning` وبجميع مراجع المالك السابقة |
| الأطلس | يتحقق من سجل الجذر بمصدر مستقل، ومن خطة النص بمحقق `text.read` نفسه |
| السحب | سحب أصل في شريحة OpenCyc يعيد نتيجتها ولا يغير شواهد الخبر المستقلة |

وجود المصدرين في طلب واحد لا يثبت تكافؤ معرفاتهما أو محاذاة لفظ عربي
بصنف أنطولوجي. يحتفظ الاختبار المشترك بغياب دعوى المحاذاة وبانفتاح الصدق
الخارجي، حتى عندما يقبل المالك اشتقاقًا داخل شريحته.

## العيوب المعالجة

1. **تلوث قراءة الآية بالمخرجات السابقة:** كان مخبأ التحليل يعيد قواميس
   وقوائم قابلة للتعديل. أصبحت قراءة ملف الشاهد الصغير مستقلة في كل مرة.
   تفسد اختبارات النقض البنى المعادة كلها ثم تشترط استعادة النتيجة الأصلية.
2. **تعطل التحقق من الدرس:** كانت نتائج دروس الشواهد ونقل السياق تفتقد
   `execution_measured` الذي يتطلبه المتحقق المشترك. يسجل المالكان الآن
   تنفيذ العملية المحدودة، وتبقى حالة الفاحص الأصلي والقراءة المجهولة
   والترخيص الدلالي مستقلة. يرفض المتحقق الحقل المفقود أو غير البولياني.
3. **سجل أطلس مزور متسق البصمة:** تلزم واجهات الاقتراح والمراجعة مصدر
   الجذور وبصمة Git المحفوظين مستقلًا. يعاد بناء الجرد ومقارنة السجل كاملًا،
   فلا تستبدل البصمة الذاتية موضع الوقوع أو حقوله المشتقة.
4. **خطة نص غير قابلة للقبول:** تستدعي خطة الأطلس محقق البوابة القائم قبل
   إصدار `NOT_RUN`. يرفض النص الفارغ وتجاوز حدود المصدر والوقوع والمفردة
   دون اقتطاع الأصل أو اختراع تشغيل سابق.
5. **تعارض التسجيل والفحوص:** جُمعت قوائم الدروس والحقول والمراجع وأهداف
   Make جمعًا يحفظ جميع الإضافات، مع اختبار الطلب الذي يشغل المالكين معًا.
6. **إلغاء الفحص الأصلي بمهلة المهمة:** ألغيت مهام #109 و#118 بعد 30 دقيقة
   وهي داخل مجموعات فحص لاحقة. رُفعت مهلة `native-admission` إلى 60 دقيقة،
   مع بقاء كل أمر واختبار واشتراط للفاحص الأصلي.

تغيير واجهة الأطلس مقصود: `make_proposal` و`check_proposal` و`review_event`
تحتاج `root_source` و`expected_root_blob` كوسيطين مسميين إلزاميين؛ يوضح
[دليل الأطلس](NTL_ATLAS_STAGING_V02_AR.md) أمثلة الانتقال.

## إعادة التحقق

```sh
PYTHONPATH=src:. python -B -m unittest \
  tests.test_ntl_atlas tests.test_lesson_dispatch_regression \
  tests.test_ntl_pr_integration tests.test_ntl_witness_pilot \
  tests.test_opencyc_slice tests.test_opencyc_boundary \
  tests.test_opencyc_inquiry tests.test_opencyc_source_binding \
  tests.test_relational_input_regression \
  tests.post_segmentation_routing.test_ayat_al_dayn_routing \
  tests.post_segmentation_routing.test_ayat_cognition \
  tests.post_segmentation_routing.test_report_rank -v
make ntl-school-check
make io-gateway-native LAKE=/path/to/pinned/lake
```

أضيفت فحوص التكامل والأطلس إلى `io-gateway` و`io-gateway-native`. تبقى
`ntl-course-check` و`scoped-report-native` و`opencyc-slice-native` متطلبات
للفحص الأصلي، مع متغيرات تجعل غياب executables الأصلية فشلًا. اختبار
السحب المشترك يتطلب `verifiedReading` فعلًا؛ تخطيه في بيئة التطوير الخفيفة
لا يعد دليلًا أصليًا. يجب اعتماد نتائج CI على إيداع التكامل النهائي، لا
جمع نجاحات من رؤوس قديمة.

## حدود النتيجة

هذا تكامل تنفيذي مع إصلاحات قابلة لإعادة الإنتاج. تحفظ الأدلة السابقة
نتائج التدريب الضعيفة وحدود العينات المؤلفة؛ لا تمنح الرؤوس العصبية سلطة
اختيار آلي أو حكم على الواقع. يبقى تغطية المناهج الكاملة، والتحكيم
التعليمي المستقل، والمصادقة التشغيلية، ومحاذاة العربية بالأنطولوجيا
التزامات منفصلة. لم تشغّل بيئة التطوير المحلية بوابة الإصدار الكاملة
`make check` أو بناء Lean؛ نتائج مهام GitHub الأصلية على إيداع التكامل هي
الدليل المستقل لهذه المسارات، وليست هذه الوثيقة إعلان نجاحها مسبقًا.
