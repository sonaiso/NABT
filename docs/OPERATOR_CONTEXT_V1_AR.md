# سياق المؤثر المصدري بجانب إيصال التوجيه

تأتي هذه الدفعة بعد تنظيم القواعد والسياسات في PR 64. موضوعها حمل
شروط الاستعمال الموصوفة في المصادر وموانعها وأمثلتها إلى صف التوجيه
الموجود، ثم إعادة فحص التقرير الكامل من الطلب الأصلي. العقد المثبت قبل
التنفيذ هو [OPERATOR_CONTEXT_V1_SPEC.md](OPERATOR_CONTEXT_V1_SPEC.md)،
ومصفوفة القبول المستقلة في
[acceptance_cases.json](../evidence/operator_context_v1/acceptance_cases.json).
نتائج التنفيذ والمراجعة الأولى والإصلاح والمثال العامل في
[OPERATOR_CONTEXT_V1_RESULTS_AR.md](OPERATOR_CONTEXT_V1_RESULTS_AR.md).

## ١. الوصلة التي يعالجها التغيير

يملك `classical_laws` بالفعل مقيمًا للمؤثرات وإيصالات يعاد بناؤها
بالكامل. ويملك الجرد الأصلي نص النطاق والموانع وحدود الاستعمال
والأمثلة ومقاطع مصادرها. كان التوجيه يحتفظ بمعرف المؤثر وإيصاله،
ويختزل صفوف فهرس المؤثرات إلى معرفاتها عند ترتيب الفحص.

يحمل تقرير التوجيه v2 كائن `source_context` بجانب `receipt` و
`verification` في كل صف مفحوص. يظل الإيصال نفسه بصيغته الأصلية،
ويظل محققه القائم مسؤولًا عن إعادة حسابه. لا تنسخ هذه الإضافة قانون
المؤثر أو طريقة تقويمه إلى محرك آخر.

| المادة | صاحبها الحالي | ما يظهر للمراجع |
| --- | --- | --- |
| المؤثرات المنصبة ومعرفاتها | `classical_laws.catalog()` | 24 مؤثرًا مشروطًا، مع استكمال جميع المعرفات عند التوجيه |
| وصف النطاق والموانع والحدود | الجرد المثبت عبر `replay_inventory()` | النص الأصلي بوصفه وصفًا مؤلفًا للاستعمال |
| الأمثلة الموجبة والسالبة | الجرد نفسه | المصفوفات الأصلية ومجال كل مثال، دون توليد مقدمات منها |
| المقاطع المصدرية | ملفات المصادر المثبتة ومواضعها | النص الخام والحدود والبصمات والبيانات المرافقة |
| نتيجة الحالة المعينة | المقيم الموجود للمؤثر | البدائل والموانع المحسوبة والنتائج الجزئية كما أعادها صاحبه |
| صحة نقل التقرير | `verify_routing_report` | إعادة الحساب من السؤال والإطارات والميزانية والمصادر |

الجرد الأصلي يضم 38 سجلًا، والفهرس العام يضم 125 سجل قاعدة. سياق
هذه الدفعة يخص المؤثرات المنصبة الـ24 فقط. لا تتغير مقامات الجرد أو
شكل الفهرس، ولا تصبح بقية السجلات قابلة للتنفيذ بمجرد ظهورها فيه.

## ٢. ثلاث مواد مختلفة داخل صف واحد

**الوصف المصدري** يبين كيف صيغت القاعدة أو قيدت في المواد المعتمدة.
و`source_scope` و`source_blockers` نصان مؤلفان؛ لا تدعي الإضافة أنها
حولتهما إلى شروط بولية مستخرجة من العربية.

**إطار الحالة** هو المقدمات التي قدمها المستدعي للمؤثر. يعيد التقرير
إيصالها كما يعرفه المقيم القائم. السؤال المكتوب في خانة البحث لا
يثبت صحة هذه المقدمات في كلمة أو جملة بعينها.

**النتيجة المشروطة** تبين ما أعاده المؤثر عند تلك المقدمات. قد يكون
الإيصال صحيح الإعادة، وتكون نتيجته `BLOCKED` أو `OUTSIDE_SCOPE`.
لذلك تعني `CHECKED_CONDITIONAL` نجاح إعادة التقويم المشروط، ولا
تعني أن تحويلًا لغويًا قد وقع أو أن تحليل النص الحر قد ثبت.

وتظل سلطة السياق `AUTHORED_SOURCE_CONTEXT_ONLY`، وسلطة فاحص
التقرير `ROUTING_REPLAY_ONLY`، مع `semantic_authority=NONE` و
`action_authority=NONE`. يبقى اكتساب مقدمات الحالة من نص حر وتحقيق
مناطها التزامين مستقلين.

## ٣. حفظ الأمثلة والخلاف والنتائج الجزئية

للأمثلة السالبة في الجرد نطاقها المحفوظ: قد يكون المثال مقابلًا أو
خارج هذه القاعدة دون أن يكون تعبيرًا عربيًا غير جائز. لا تتحول هذه
الأمثلة إلى مرشح يستبعد لهجة أو قراءة أعادها المقيم القائم.

في سجل النون قبل الباء، توجد حالة `textual_discrepancy` ومقطعان
مصدران في الجرد، مع اختلاف النص المنقول. وقد يحمل الإيصال التنفيذي
شواهد إضافية. يحتفظ كل منهما بأدلته الأصلية؛ لا تستبدل قائمة السياق
المصدري أدلة الإيصال، ولا يحسم التنفيذ المشروط الخلاف بين المقطعين.

| الحالة | السلوك المطلوب والمحمي |
| --- | --- |
| أصل الألف مجهول في قاعدة همز محددة | يبقى الناتج مؤجلًا وموضع النقص ظاهرًا |
| أصلها معين على وجه يمنع القاعدة | يبقى المانع المحسوب مستقلًا عن الجهل السابق |
| للمؤثر بدائل لهجية مرخصة في إطاره | تبقى البدائل وأسماؤها وترتيبها في الإيصال |
| نتيجة إدغام جزئية لا تعين الحركة | تبقى جزئية؛ لا تملأ الإضافة الحركة |
| بعض ملف النون الخفيفة غير محسوم | تبقى الملفات غير المحسومة معلنة |
| لم يقدم إطار للمؤثر | يظهر `MISSING_PREMISES` مع سياقه المصدري ودون إيصال مختلق |
| انتهت الميزانية قبل استنفاد الجرد | تبقى المعرفات المنتظرة و`RESOURCE_EXHAUSTED` |

## ٤. لماذا يحتاج التقرير إلى ربط بالطلب الأصلي؟

يسوي البحث بعض الفروق في إسقاطه لأغراض الاسترجاع. لذلك يمكن لسؤالين
مختلفين أن يعيدا ترتيب البحث نفسه. كما قد تتغير مقدمات مؤثر لم يصل
إليه الفحص بعد دون أن يتغير أي إيصال معروض. وقد تعطي الميزانية
المحذوفة النتيجة نفسها التي تعطيها ميزانية صريحة قدرها 24.

يحفظ طلب v2 السؤال الخام، وقائمة المعرفات المقترحة بترتيبها، وبصمة
الإطارات المقدمة كلها، والميزانية كما طلبت. يثبت ذلك الفروق في الطلب
حتى عندما تتفق النتائج الظاهرة. ولا تستبدل هذه الهوية الدليل على
صحة الإطارات نفسها.

يعاد بناء فهرس موثق بالمصادر قبل التوجيه، ويقارن الفهرس المزود
بهويته وسجلاته وحالة ترتيبه. يعاد استعمال صاحب الفهرس والتحقق
الموجودين؛ لا تكفي مطابقة حقل بصمة قابل للتعديل. يحتفظ الفهرس بجذره
الأصلي حتى يعاد فحص المصدر نفسه عند استعمال نسخة محفوظة منه.

عند التحقق، يطلب النظام السؤال والإطارات والميزانية من جديد، ويبني
فهرسًا جديدًا ويعيد التقرير كله. تغيير وصف مانع، أو إسقاط مثال، أو
نقل سياق قاعدة إلى أخرى، أو تغيير إطار غير مفحوص، أو إعادة حساب
بصمة في ملف محرف، لا يقوم مقام إعادة الفحص من أصحابه.

## ٥. التشغيل

من جذر المستودع، مع اختيار اسم ملف إخراج جديد:

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog route 'همزة الأمر' \
  --frames examples/operator_context_frames.json \
  --output artifacts/local/operator-route-v2.json

PYTHONPATH=src:. python -m tools.grammar_catalog verify-route \
  artifacts/local/operator-route-v2.json --query 'همزة الأمر' \
  --frames examples/operator_context_frames.json
```

يحمل المثال مقدمات صريحة لمؤثر الأمر المهموز في ملف `all_attested`.
هو مثال تشغيل مؤلف، وليس استخراجًا تلقائيًا لهذه المقدمات من السؤال
ولا مادة اختبار محجوبة. تنتج بقية المؤثرات المفحوصة حالة نقص مقدمات
حين لا تقدم لها إطارات.

لإنتاج التقرير السابق للمقارنة:

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog route 'همزة الأمر' \
  --frames examples/operator_context_frames.json --legacy
```

يحفظ الخيار القديم صيغة v1. الفاحص الجديد يقبل v2 فقط، لأن التقرير
السابق لا يحمل هوية الطلب الكاملة المطلوبة هنا. وإذا استعملت
`--budget` في الإنشاء، فأعد القيمة نفسها عند التحقق؛ الميزانية
المحذوفة متميزة من القيمة الصريحة.

يبقى المدخل ضمن منفذ إعادة الاستعمال الموجود:

```sh
python -m tools.entropy_framework reuse --family rule-routing
python -m tools.entropy_framework reuse --run grammar-catalog -- --help
PYTHONPATH=src:. python -B -m unittest discover -s tests \
  -p 'test_grammar_catalog_operator_context.py' -v
```

## ٦. الحدود التشغيلية وإعادة الإنتاج

حد الوثيقة 8 MiB، وعمق JSON يساوي 64، وعدد القيم مليون. تبقى حدود
السؤال وقائمة المرشحين وإطار كل مؤثر كما يحددها أصحابها. يفحص الكاتب
حجم البايتات الفعلية التي سيحفظها، ويرفض استبدال ملف موجود. وترفض
القراءة تكرار مفاتيح JSON والقيم غير المنتهية والتحويلات غير الصريحة.

نفاد موارد الوثيقة يعيد خطأ الموارد القائم ورمز خروج 3. فساد المدخل
أو المصدر أو عدم تطابق الإعادة يعيد رمز 2. أما خطأ إطار مفحوص فيبقى
في صفه مع نوعه الأصلي؛ وقد يكون ذلك خطأ مدخل أو حد موارد. تعطل
المصدر المثبت لا يسجل بوصفه مجرد خطأ في إطار المستخدم.

ثبتت المواصفة ومصفوفة القبول قبل التنفيذ في `50e3f51`. حُفظ التقرير
السابق و20 ملاحظة حدية عن المقيمات القائمة، مع بصمات المصادر. ويبين
سجل حفظ المراجعة كيف استعيدت نسخة المرجع السابقة لإضافات فحص النطاق
مع مطابقة بصمتها المنشورة؛ لا يصفها السجل بأنها نسخة أخذت قبل التعديل.
القبول اختبار هندسي مكشوف، وتظل سلامة النقل متميزة من دقة التفسير
اللغوي وشمول العربية وصدق الخبر الخارجي.

## ٧. صلته بالجبر والتكوين والتطبيق

تعاد الاستفادة من مبرهنات `RuleRouting` لاستكمال الجرد والمحافظة على
عضويته وبيان حدود الميزانية. لا يضيف السياق المصدري إلى هذه المبرهنات
دليلًا على صدق مقدمات الحالة أو على استنفاد العربية.

كذلك لا يصبح المثال الموجود مع القاعدة تاريخًا لتكوّنها، ولا يصبح
إيصال صحيح حدث اعتماد لها. يبقى وصل مرشح المتعلم بمستند اعتماد
مستقل مسارًا محددًا بعد تنظيم القواعد والسياسات.

وتبقى شجرة التطبيق النحوية الفعلية وشواهد أبنائها لازمة لإغلاق
`CertifiedBridge` وفروض التحقيق. توفر هذه الدفعة سياق القاعدة بجانب
حالتها المشروطة؛ ولا تملأ متطلبات الشجرة بأعلام أو مراجع غير مطبقة.
