# التحصيل المحاذي للمصدر في NABT

القانون `nabt.aligned-acquisition.v1` يضيف مسارًا مستقلاً من النص الأصلي إلى
خلايا `nabt.a116.v1`. يعيد Lean قراءة المصدر نفسه، ويقارن Python النتيجة
الكاملة: القطع، والبايتات، ونقاط Unicode، والقواعد، والخلايا، وهوية المصدر،
والمراجعة، والمقام، واختيار الوقف أو الوصل. لا تكفي بصمة يعيد المستدعي حسابها.

## التشغيل

من جذر المستودع، وبأداة Lean المثبتة في `formal/lean-toolchain`:

```sh
lake --dir formal build alignedAcquisition licensedInference
PYTHONPATH=src python -m nabt read-acquired input.txt --source-id input --revision 1 --scope default --ending wasl > receipt.json
PYTHONPATH=src python -m nabt verify-acquired receipt.json --source input.txt --source-id input --revision 1 --scope default --ending wasl
```

فاحص الاستلام يحتاج المصدر المستقل والمعرّفات المتوقعة؛ لا يستخرج الثقة من
حقول الشهادة. عند غياب التنفيذي يعيد `VERIFICATION_UNAVAILABLE`. حزمة Python
المنفردة لا تحتوي تلقائيًا أداة Lean، وتبقى غير مخوّلة بمنح فحص أصلي دون بنائها.

`propose_acquisition` حساب تشخيصي؛ `acquire` يتطلب إعادة الحساب الأصلية؛
`read_acquired` يضيف القارئ الموجود وفحص الشكل؛ `verify_acquired` يعيد المسار
كله. لم يتغير `parse_word` أو قانون الشكل أو ترقيم الخلايا أو القارئ القديم.

## معنى النتيجة

| الحقل | ما يثبته ضمن النطاق |
|---|---|
| `acquisition.status` | اكتمال التمثيل المحلي وفق القواعد المؤلفة، أو دين مسمى، أو مدخل معيب |
| `verified` | تطابق إعادة الحساب الأصلية كاملة، لا صحة نحوية أو صدقًا في العالم |
| `word_reader` | خرج القارئ القديم على البايتات الأصلية دون تعديل |
| `shape_handoffs` | قبول قانون الشكل للكلمات المكتملة فقط، أو رفضه، أو نفاد موارده |
| `source_evidence` | سلامة سجل مثبت يضم 23 شاهدًا وتسعة اصطلاحات مؤلفة، مع فصل سلطتيهما |
| `open_obligations` | الديون الباقية بين التمثيل المحلي والتفسير اللغوي العام |

الكلمة الناقصة لا تحصل على شهادة شكل. شهادة الشكل الداخلية لا تحمل
`source_text` مصطنعًا؛ تربطها بالقطع الأصلية شهادة التحصيل الخارجية. تحفظ
القراءات الخام اختلاف قمتُ وقمتَ وقمتِ حتى لو تشابه إسقاطها عند الوقف.

القارئ الموجود يفرض معرّف مصدر من `[a-z][a-z0-9_]*` ومقامًا بطول أقصاه 256؛
واجهة التحصيل تقبل هوية Unicode غير فارغة أقصاها 512 رمزًا بلا C0/C1. إذا
خرجت الهوية عن مجال القارئ بقي تحصيلها مفحوصًا وأظهر `word_reader` سبب عدم
القراءة صراحة. لا تُغيّر الهوية أو النص لإجبار القارئ على القبول.

## حدود معلنة

`wasl` اختيار محلي لهيئة الآخر؛ لا ينفذ كل أحكام الوصل بين الكلمات. تطبق
`waqf` على آخر كلمة فقط، ويظل المصدر الخام محفوظًا. لا يستنتج البرنامج
الحركات المفقودة أو الألف المحذوفة من مجرد الرسم. سجل الرسوم المؤجلة محدود
بالهياكل المعينة في المواصفة؛ تقسيم السوابق في «وهذا/فهذا/ولكن» غير مكتسب.
لذلك قد تكتمل خلايا وفق القراءة المحلية المؤلفة دون أن تثبت القراءة الإملائية
العرفية الكاملة. لا يرفع `ACQUIRED` هذه النتيجة إلى شهادة نطق صوتي أو نحو.

الضمير ومرجعه، والمبتدأ والخبر، وتصنيف الاسم والفعل، واستخراج الدلالة من كتب
العربية، والشمول العربي تبقى عقودًا أخرى. يقيس الاختبار الشرط عبر محرك
الاستدلال الموجود على المصدر نفسه؛ لا يجعل نجاحه برهانًا صادرًا من خلايا
التحصيل، ولا يحوّل الجملة الشرطية وحدها إلى وقوع شرطها.

## التحقق وإعادة التشغيل

```sh
make aligned-acquisition-conformance
make aligned-acquisition-evaluation EVIDENCE_DIR=artifacts/local/acquisition-replay
make test
make formal
make conformance
```

التشغيل الأول يثبّت التنفيذ قبل فتح المصفوفة؛ تحفظ نتائجه دون استبدال. جميع
الإعادات التالية على مادة مكشوفة. يفصل المقيم سلامة المصدر والامتناع، وصحة
الخلايا المرجعية، وتغطية الاكتساب المطلوبة، وأهداف الصرف والنحو والاستدلال.
يفشل فحص التراجع عند اختلاف خلية مرجعية، حتى لو اتفق Python وLean على الخطأ.
لا تُحسب الأهداف الموجبة المؤجلة نجاحًا، ولا تُحذف من المقام.
