# استعمال مقدرات NABT الموجودة والمحافظة على استمرارها

## قرار هذه الدفعة

يبدأ العمل اللاحق من العقد المبرهن ومستهلكه الحالي. أُضيف أمر `reuse` إلى
إطار المتابعة الموجود `tools.entropy_framework`، واستهلك فهرس البراهين
الحالي وسجل المشروع نفسه. يتيح الأمر العثور على المقدرة، وفحص اتصال
مصادرها، وتشغيل مدخلها التنفيذي الموجود بالمدخلات الأصلية.

الأساس المفصل في [أصل البرهان والجبر المتدرج](NABT_FOUNDATION_REUSE_AR.md).
يظل `formal/theorems.json` قائمة التصريحات الوحيدة، ويظل
`tools/proof_catalog.py` منتج الفهرس المترجم. يحدد
`integrations/current_proof_references.mk` اللقطة الحالية، وتبقى اللقطات
التاريخية محفوظة. لم تتغير ملفات Lean أو قوانين اللغة أو شيفرة `src/`
في دفعة إعادة الاستعمال هذه.

في القياس الحالي بتاريخ ٢٠٢٦-١٠-٣١ تضم الخريطة ٨٢ وحدة رسمية: ٨٠ ذات
تصريحات مبرهنة، ووحدتي بيانات، وتستمد ١٦٠٥ تصريحات و١٦٠٢ مجموعة نصوص
معيارية متميزة من الفهرس المترجم. تنظمها ٣٩ عائلة استعمال، مع ٢٨ مدخلًا
تنفيذيًا موجودًا. هذه مقامات جرد وربط؛ لكل عملية تشغيل نتيجتها المستقلة.

### تنظيم القواعد والسياسات

عند العمل على تكوين قاعدة أو اعتمادها أو تطبيقها أو مراجعتها، استخدم
العرض الاختياري المشتق من أصحاب العقود أنفسهم:

```sh
python -m tools.entropy_framework reuse --organization --summary
python -m tools.entropy_framework reuse --organization \
  --output artifacts/local/rule-policy-map.json
```

يحفظ الملف التقرير الكامل حتى عند طلب ملخص الشاشة، ولا يستبدل ملفًا
موجودًا. يفصل العرض الدور التنظيمي عن نوع العملية وعن مراحل الاستعمال؛
ويحتفظ بنطاق صاحب العقد مستقلًا عن ملاحظة النطاق المؤلفة. لا يجمع
`--organization` مع `--family` أو `--module` أو `--run`، ولا ينفذ
مراجع البيانات. كل مرحلة فيه `NOT_OBSERVED`؛ اكتمال حل المرجع لا يثبت
حدوثها. عند غياب التنظيم يعلن `NOT_DECLARED` وتظل سجلات الفهرس ظاهرة.

تشرح [خطة التنظيم](NABT_RULE_POLICY_ORGANIZATION_AR.md) موضع المتعلم
المحدود والتعريفات والقبول والاستدلال ودورة الأدلة، والوصلة الباقية
بين المرشح وسند اعتماده. تبقى الدفعة التنظيمية الأولى 11 سجل إحالة
وموضوعين مصنفين مباشرة من 125 سجلًا؛ الأعداد لا تقيس شمول العربية
أو نجاح التفسير، وغير المصنف لا يعني غياب مقدرته التنفيذية.

### سياق المؤثر وإعادة فحص التوجيه

يعرض مسار `grammar-catalog` سياق المؤثرات المنصبة بجانب إيصالاتها في
تقرير v2. يصف النطاق والموانع والأمثلة كما يملكها مصدرها، ويحفظ نتائج
المقيمات الأصلية. ويطلب `verify-route` السؤال والإطارات والميزانية من
جديد لإعادة بناء التقرير كله. يبقى `--legacy` خيار إخراج v1، وتبقى
حالات النقص والتعارض والجزئية متميزة من وصف القاعدة.

```sh
python -m tools.entropy_framework reuse --family rule-routing
python -m tools.entropy_framework reuse --run grammar-catalog -- --help
```

التشغيل والمقامات وحدود السلطة موثقة في
[سياق المؤثر المصدري](OPERATOR_CONTEXT_V1_AR.md). لا يستبدل ظهور
مثال في التقرير شاهد تحقق مقدمات ذلك المثال في نص المستخدم.

## البداية العملية لكل وكيل

من جذر المستودع:

```sh
python -m tools.entropy_framework reuse
python -m tools.entropy_framework reuse --module Nabt.LicensedDerivation
python -m tools.entropy_framework reuse --family recursive-source
```

يفحص الأمر جميع الوحدات والمراجع قبل تضييق العرض. اختيار وحدة واحدة لا
يخفي تقادم ملف آخر أو سقوطه من الجرد. العرض الافتراضي مدخل موجز؛ اختيار
الوحدة أو العائلة يفتح الشروط والمستهلكين والاختبارات والالتزامات الباقية.

لحفظ التقرير التفصيلي في ملف جديد:

```sh
python -m tools.entropy_framework reuse \
  --output artifacts/local/capability-map.json
```

لا يستبدل الأمر تقريرًا سابقًا يحمل الاسم نفسه. يُشتق التقرير من المصادر
الحالية، ولا تُنسخ أسماء المبرهنات أو أعدادها يدويًا في سجل ثانٍ.

إذا توقف الفحص بسبب تقادم الفهرس بعد تغيير رسمي مقصود، تُستعمل أداة
الفهرسة الأصلية مباشرة لإعادة البناء، ثم تُجدّد المراجع السبعة معًا وفق
تعليمات `CLAUDE.md` و[دليل الفهرس](PROOF_CATALOG.md). مثلًا:

```sh
python tools/proof_catalog.py --lake /path/to/pinned/lake \
  --output artifacts/local/new-compiled-catalog.json
```

لا يُستبدل المرجع التاريخي، ولا يُعطّل فحص التقادم. مدخل `reuse --run`
يفحص سلامة الخريطة أولًا، ولذلك يبقى الأمر المباشر طريق الصيانة حين
يتوقف ذلك الفحص.

قبل تنفيذ تعديل، يعين الوكيل العقد والمستهلك القائمين، ويفحص مقدمات
العملية وحدودها ومثالها المضاد. ثم يذكر في وصف تغييره: ما استعمله، وما
عدّله في الوصلة، وما نفذه للتحقق، وما بقي معلقًا. تفسر الحاجة إلى مكون
جديد بمقدمة أو وظيفة لا يحققها الموجود، لا بغياب اسمه من ذاكرة الوكيل.

متميزة؛ لا ينسب إلى كل وحدة استدعاء جميع ملفات عائلتها.

## تشغيل الموجود فعلًا

يفوّض `--run` إلى برنامج مسمى في قائمة تنفيذ مثبتة في الشيفرة. تبقى
مدخلات البرنامج ومخرجاته وتشخيصاته ورمز خروجه كما يعرفها مدخله الأصلي؛
لا تُستخلص رتبة معرفية من نجاح العملية في نظام التشغيل. لا يتحول نص
السجل أو معرّف المصدر أو علامة حالة مزودة إلى أمر تنفيذي.

### الجبر المتدرج

```sh
python -m tools.entropy_framework reuse --run progressive \
  < examples/progressive_units.jsonl
```

هذه طلبات JSONL للمنفذ الأصلي `progressiveUnitProbe`. تعرض عقود الأثر
والبناء والترخيص والاستنفاد بحسب كل طلب. إذا كان المنفذ غير مبني، يظهر
عدم توافر التحقق؛ يبنى الهدف الموجود بإصدار Lean المثبت:

```sh
cd formal
lake build progressiveUnitProbe
```

### الاستدلال النصي القائم

```sh
python -m tools.entropy_framework reuse --run licensed-inference -- \
  examples/licensed_inference_source.txt \
  examples/licensed_inference_query.txt
```

يظل التفسير متعلقًا بلغة الاستدلال المحددة وبالمصدر والسؤال الأصليين
وشروط تعداد القراءات وإغلاق الاستدلال. غياب المعنى أو المصدر أو المنفذ
يحتفظ بتشخيصه الأصلي.

### وصلتا الإسناد والاسم اللتان أُصلحتا

```sh
python -m tools.entropy_framework reuse --run core -- ask-discourse \
  examples/interpretive_links_source.txt 'هل سَالِمٌ كَاتِبٌ؟' \
  --qac examples/interpretive_links_training.tsv \
  --context examples/interpretive_links_context.json \
  --lexical-source examples/interpretive_links_lexical.txt
```

يستعمل هذا الأمر القارئ نفسه الذي أُصلح سابقًا. تبقى خصائص الاشتقاق
مرتبطة بالقراءة، والوصف المعجمي مشروطًا بقرينة اتحاد المعنى حيث لم تثبت.

### القراءة الإنتاجية ونقل المعنى

```sh
python -m tools.entropy_framework reuse --run meaning-preservation -- \
  productive --request examples/meaning_preservation_v1/productive.json
```

المدخل الحالي يعيد استعمال التحصيل وقارئ الجملة الإنتاجية ونقل القراءات
المترابطة والفاحص الأصلي. لإعادة فحص نتيجة محفوظة، يُستعمل أمر `verify`
الموجود مع الطلب الأصلي والإيصال ونمط `productive`. دليل المجال والتشغيل
في [حفظ المعنى](MEANING_PRESERVATION_V1_AR.md).

يمكن كشف معلمات أي مدخل Python قائم دون حفظ نسخة ثانية من تعليماته:

```sh
python -m tools.entropy_framework reuse --run productive-lifecycle -- --help
python -m tools.entropy_framework reuse --run core -- --help
```

## ما الذي يجعل الاستمرار قابلًا للفحص؟

تُكتشف اختبارات إعادة الاستعمال ضمن بوابة الاختبارات الحالية، وأضيفت
بوابة CI باسم `NABT capability reuse`. تتحقق من:

- مطابقة مصادر اللقطة المترجمة وقائمة المبرهنات للمصادر الحالية.
- وجود كل وحدة رسمية مرة واحدة في خريطة العائلات، بما فيها وحدات البيانات.
- وجود ملفات المستهلكين والفاحصين والاختبارات والمداخل وأهداف Lake المشار إليها.
- بقاء الشروط والالتزامات الباقية ظاهرة، ورفض حقول تدعي التنفيذ أو السلطة
  داخل بيانات التنقل.
- رفض المسار المفقود أو المتقادم أو المتسلل خارج الشجرة، ومعرّف التنفيذ
  المجهول، والمدخلات التي تتجاوز الحدود المعلنة.
- المحافظة على المخرج الأصلي والتشخيص الأصلي عند تفويض التنفيذ، وإظهار
  عدم توافر المنفذ بدل اختيار محرك بديل.

تعليمات البدء مثبتة في `AGENTS.md`، ومؤشر العمل الحالي في `CLAUDE.md`،
ومدخل المستخدم في `README.md`. هذه الآليات تكشف فقد الربط والتقادم في
الشيفرة. يظل تقييم صحة اختيار الوكيل للمقدرة ومقدماتها عمل مراجعة فعليًا.

أعيدت أوامر بوابة CI الثلاثة في نسخة مستقلة بلا بيانات Git أو برامج
Lean مبنية. نجحت الخريطة، و٣٠/٣٠ اختبارًا لإعادة الاستعمال، و٣/٣
لاستمرار مرجع البرهان. السجل في
`validation/clean_checkout_review_v1/` تحت مجلد هذه الدفعة؛ هذه محاكاة
محلية لأوامر البوابة، وليست نتيجة تشغيل GitHub Actions عن بعد.

### حفظ تعليمات التأليف التاريخية

كان الذهب المستقل للمنطوق والمفهوم يثبت بايتات `AGENTS.md` عند تأليفه.
أظهر الفحص الشامل الأول ١١ خطأ عند مطابقة هذا المدخل بعد تحديث تعليمات
الاستمرار. بقي سجل الإخفاق محفوظًا، ونُقلت النسخة التاريخية نفسها إلى
`evidence/capability_reuse_v1/historical_contract_inputs/agents_at_f48012e.txt`.
بصمتها هي البصمة الأصلية في الذهب، ومصدرها الالتزام `f48012ec15aa30746c38c706512fc1403101df3d`.

يعين فاحص المقياس هذا المدخل الواحد إلى أرشيفه الثابت، ويحتفظ بفحص
المصادر الدلالية الأربعة الأخرى على بايتاتها الحالية المطابقة للأصل.
لا يقبل نسخة التعليمات الحالية بديلًا من الأرشيف المفقود أو الفاسد،
ولا يتغير الذهب أو منطق التصحيح. يسجل `execution_inputs` التعليمات
الحالية وبصمتها منفصلتين عن عقد التأليف التاريخي. اجتازت الاختبارات
التاريخية الاثنا عشر والضوابط الجديدة السبعة مراجعة تنفيذ مستقلة.

## ما أُعيد استعماله وتشغيله في هذه الدفعة

حُفظت المدخلات والمخرجات الأصلية وسجل المقابلات في
`evidence/capability_reuse_v1/validation/consumer_runs_v1/exposed_run_02/`.
نفذ السجل ١٣ عملية عبر واجهة التفويض، من بينها حالة امتناع مقصودة
برمز خروج ٣. هذه أمثلة مكشوفة لإثبات الاتصال بالسلوك الموجود؛ ليست
تقييمًا مستقلًا لتغطية العربية.

| المقدرة الموجودة | الشاهد التنفيذي المسجل |
| --- | --- |
| `program.py` للتعلم وإعادة الحساب | ترجمة البرنامج، وتشغيله، والتحقق من إعادة تشغيله؛ التنفيذ من رقمه مطابق بايتًا ببايت |
| المصدر وشهادة التعلم | مشاهدة ثلاثة مصادر، ثم سحب المصدر وإعادة مشاهدته: اتفاق مشروط، ثم عدم تعيين، ثم عودة الاتفاق المشروط |
| الإجراء المتعلم | نجاح فحص مطابقة تصدير DAG الموجود |
| الاستدلال النصي المرخص | `SUPPORTED` مع تحقق أصلي وإعادة تحقق ناجحين |
| القراءة الإنتاجية وحفظ المعنى | `FINITE_CONTRACT_VERIFIED` ثم `VERIFIED_RECEIPT` من الطلب الأصلي |
| دورة حياة الشاهد | `LICENSED_CLAUSE → PENDING_DEPENDENCIES → LICENSED_CLAUSE`، مع تطابق إعادة التشغيل |
| الاستقصاء العقلي | `LICENSED` برتبة ٢ وفق مقدمات المثال الموجود |
| الحد المصدرّي للقارئ الإنتاجي | بقاء المدخل ذي السطر النهائي `DEFER`؛ لم تحذف الواجهة السطر لتغيير النتيجة |
| الاسم والاشتقاق والإسناد | جواب سؤال «هل سالمٌ كاتبٌ؟» يحفظ أربعة تفسيرات محمول؛ مخرجاته وتشخيصه ورمز خروجه مطابقة للمدخل الأصلي، وصدق العالم `NOT_ESTABLISHED` |

المحاولة الأولى محفوظة أيضًا. كشف سجلها تغير ملف من شيفرة الواجهة
أثناء التشغيل، ولذلك لم تُعتمد تشغيلًا ثابت المصدر؛ حُفظ سببها وكررت
العمليات على الشيفرة المستقرة. وحُفظت تجربة السطر النهائي نفسها ضابطًا
سلبيًا في التشغيل النهائي.

تسجل تجربة الأساس المنفصلة ١٣/١٣ إسقاطًا ناجحًا في الجبر التدريجي
و١/١ في جسر المصدر. أعيد بناء فهرس التصريحات بأداة Lean المثبتة
ومقابلته باللقطة الحالية: بقي ١٦٠٥ تصريحات و١٦٠٢ مجموعة نصوص، بالبصمة
المعيارية نفسها. أما الخريطة الساكنة فلا تدعي بناء Lean أو تشغيل هذه
المسارات؛ سجلات التنفيذ والبناء أدلة مستقلة عنها.

نجح الفحص العام النهائي: ٢٩٧٥ طريقة ناجحة و٥٥ متخطاة من ٣٠٣٠، دون
إخفاقات أو أخطاء أو أصناف متخطاة. ثبتت بصمات ٦٣٨ ملف شيفرة واختبار
طوال التنفيذ. يشمل المقام ٣٧ اختبارًا جديدًا لهذه الدفعة؛ لا يضاف
إليه عدد التجارب أو نتائج مراجعة CI. يجمع
`evidence/capability_reuse_v1/validation/verification_summary.json`
المقامات والبصمات والأسباب وروابط النتائج الأصلية.

## التزامات لا يغلقها الجرد

أهم الوصلات الباقية مذكورة بجانب مقدراتها الحالية:

1. `RecursiveSourceBridge.CertifiedBridge` يحتاج رخصة المصدر، وقائمة
   المضيفين، ورخصهم، وترخيص القواعد، وتطابق التحقيق السطحي. شجرة الاستعادة
   المتوازنة في المحول الحالي لا تختلق شجرة التحليل الأصلية ولا شواهدها.
2. تركيب الآثار الكامل موجود؛ توسيع استعماله داخل القراء أو تسريع حسابه
   يحتاج قياسًا ومقابلة تحافظ على حالة الدخول والحمولة ونسخة القانون.
3. التصنيف الاسمي والاشتقاق والقواعد الدلالية تنتفع بمقدماتها المصدرية؛
   اتفاق الكتابة أو الوزن لا يحل محل شاهد الوضع أو الصلة بين القراءات.
4. `SemanticInference.model_sound` يحتاج تفسيرًا للذرات وصحة للوقائع
   وحفظًا للمعنى بواسطة القواعد. `MeaningPreservation.Faithful` وتمام
   علاقة القراءات مقدمات مستقلة للنقل المقصود.
5. الاستنفاد داخل جرد معلن لا يثبت شمول العربية المفتوحة. وسلامة اللغة
   أو نقل المعنى لا تثبت واقعة العالم أو أصالة المصدر أو اتفاق العقول.

تُحفظ نتائج التشغيل لهذه الدفعة تحت `evidence/capability_reuse_v1/`.
نجاح خريطة الوحدات لا يُجمع مع نجاح الأمثلة أو اختبارات اللغة في نسبة
عامة للذكاء التفسيري؛ لكل منها مقياسه ومرجعه وحده.
