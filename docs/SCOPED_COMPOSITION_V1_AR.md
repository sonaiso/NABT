# حفظ بنية العمليات ونطاق الحكم

القانون الجديد: `nabt.scoped-composition.v1`. أصل العمل المفحوص:
`44f5beca50208519c5084c08c9ffaf61b0ab5b13`، بعد تطبيق الواقعة في PR91.

## عقد القبول المثبت قبل التنفيذ

تضيف هذه الشريحة مدخل `composition.analyze` فوق المالكين الموجودين.
تفصل فهم التركيب، وحساب مضمونه الصوري، وإثباته من الشواهد، وصدق الواقعة.
المقارنة بين تركيب العربية وPEMDAS تفسير هندسي؛ لا ننسب إلى النبهاني
قانون ترتيب حسابي أو آلة تقرأ الذهن. تعتمد الخلفية المعرفية على المقاطع
المحتفظ بها في `evidence/cognitive_curriculum_v1/source_review.json`.

1. الحساب: أعداد صحيحة مكتوبة، والأقواس و`+ - * / ^` و`× ÷`، بحساب كسري
   دقيق. الضرب والقسمة في رتبة واحدة، والجمع والطرح كذلك؛ الأس يربط يمينًا.
   السالب الأحادي أدنى من الأس: `-2^2=-4`. القسمة على صفر محجوبة؛ وكذلك
   `0^0` في هذا الإصدار. الأس عدد صحيح غير سالب لا يزيد على 12.
2. تحتفظ شجرة المصدر بمواضع UTF-8 وعلامات التجميع؛ وشجرة العمليات تحفظ
   التعلق وترتيب المعمولات. تساوي القيمة لا يساوي تطابق الشجرتين.
3. العبارة الكمية غير قضية المساواة. لا تصبح نتيجة الحساب شاهدًا على عدد
   أشياء موجودة في العالم. لا تدخل تعليمات Python أو دوال تنفيذية في النص.
4. الكم: مجال مصرح به من فرد إلى أربعة أفراد، مع شواهد انتمائهم إلى الصنف.
   لا تمثل هذه القائمة جميع أفراد الجنس في العالم. يبقى نقص الشاهد مجهولًا.
5. يحفظ `كل` و`ليس كل` و`كل… ليس` كنطاقات مختلفة. الصيغ الإنتاجية هنا
   مضبوطة بـ`هو`؛ وتقبل عبارتا المستخدم عن الطالب والاجتهاد بمحاذاة معجمية
   مؤلفة معلنة، لا بحذف التشكيل أو بافتراض تحليل صرفي عام.
6. لا يضاف خبر الكم نفسه إلى المقدمات. تُفحص دعواه على شواهد مستقلة، سواء
   وردت في صورة خبر أو سؤال؛ ويحفظ نوع القول في التمثيل.
7. يحوّل مترجم النطاق القضية المحدودة إلى قواعد أرضية ثم يسلمها إلى
   `source_learning_connection` و`VerifiedReading` و`EvidenceLifecycleV1`.
   لا يضاف محرك استدلال أو دورة حياة أو حسم إحصائي آخر.
8. مسار الشرط يعيد استعمال طلب المالك المصدرّي نفسه. فهم الشرط لا يثبت
   تحققه ولا عكسه ولا السببية الفيزيائية. تبقى المقدمات وشواهدها والسحب
   والتعارض في النتيجة الأصلية.
9. فاحص Lean مستقل يعيد قراءة النص الحسابي ونص الكم ويعيد حساب الإسقاط.
   يرفض اختلاف التعلق أو القيمة أو القواعد المولدة. يستخدم الحساب نوع
   `Rat` الموجود، وتستخدم الشجرة بانيات الجبر العودي الموجود.
10. المخرج الخارجي هو إيصال البوابة فقط، مع إعادة تشغيل الطلب المستقل.
    غياب الفاحص أو نفاد الموارد لا يمنح نتيجة موجبة.

## ما كشفه فحص الشيفرة

`text_reader` يقرأ بالفعل الوقائع الموقعة وقواعد الشرط و`كل مفهوم هو مفهوم`.
الأخيرة قاعدة Horn موجبة؛ لا تمثل نفي الكم أو وجود مثال مضاد. عقد
`SourceSemantics.Formula` يحوي الذرة والاقتران والشرط دون رابط كم.
`MeaningPreservation` يحفظ قراءات مقدمة وقوة القول، لكنه ليس قارئ حساب.
لذلك يضاف قارئ محدود ومترجم نطاق، مع إبقاء الإثبات على المالكين الحاليين.

الامتداد الأصلي الجديد فاحص تنفيذي، وليس إعلانًا عن مبرهنة عامة لصحة
المحلل أو تنقيح Python إلى Lean. لا يتغير `formal/theorems.json` ولا تنشأ
سلطة مبرهنات أخرى. مراجع العائلات تخص القدرات المعاد استعمالها فقط.

## أمثلة الإبطال المطلوبة

| المقابلة | المطلوب |
|---|---|
| `2+3*4` / `(2+3)*4` | 14 / 20 وشجرتان مختلفتان |
| `8/4*2` / `8/(4*2)` | 4 / 1؛ لا تقديم للضرب على القسمة |
| `(2+3)*4` / `2*4+3*4` | قيمة واحدة مع اختلاف بنية الحساب |
| `1/(3-3)` | منع القسمة، مع إبقاء شجرة المقام |
| طالب مجتهد وآخر ثبت نفي اجتهاده | `ليس كل` مؤيد و`كل… ليس` معارض |
| سحب المثال المضاد | يعود النفي الكلي غير محسوم، ولا يصير الجميع مجتهدين |
| الشرط بلا شاهد مقدمته | لا تثبت نتيجته |
| السؤال ضمن مصادر الوقائع | لا يتحول إلى خبر مثبت |

مرجع الاصطلاح الحسابي: [OpenStax، لغة الجبر](https://openstax.org/books/elementary-algebra-2e/pages/1-2-use-the-language-of-algebra).
يبقى اختيار نطاق المصدر، ومحاذاة العربية، وصدق السجل الخارجي التزامات
مستقلة عن نجاح إعادة الفحص. لا يضاف تدريب عصبي في هذه الشريحة.

## العقد التنفيذي

الملفات `composition_arithmetic.py` و`composition_quantifier.py` تقترح
الإسقاط، و`ScopedCompositionProbe` يعيد قراءة النص الأصلي وحساب الإسقاط
كاملًا. الحقول `projection` تشخيص للمقترح؛ لا يقبل المخرج إلا مع نجاح
`native_check` واكتمال `chain_complete` وإعادة فحص إيصال البوابة.
نتيجة `BLOCKED` هنا فحص مكتمل لمانع حسابي، وليست قيمة عددية. تبقى
`OUTSIDE_SCOPE` و`RESOURCE_LIMIT` و`VERIFICATION_FAILED` حالات مستقلة.

الحساب يقبل أرقام ASCII بلا أصفار بادئة، في 2048 بايت و63 رمزًا، وارتفاع
شجرة لا يزيد على 12. البسط والمقام لا يتجاوزان `2^53-1` بالقيمة المطلقة؛
لا يستخدم الحساب فاصلة عائمة. الاقتران الضمني `2(3+4)` والأعداد العشرية
المكتوبة والمتغيرات خارج الإصدار. يُرجع `sort=quantity` قيمة كسرية دون
حقل صدق مثبت؛ ويرجع `sort=proposition` للمساواة صدقًا صوريًا دون تحويله
إلى شاهد عدّ خارجي. بانيات `RecursiveLicensedAlgebra.Tree` تحمل أرقام
عمليات الجدول `operator_registry` الخاص بهذا القانون؛ لا تعني شهادة
نحو عربي ولا ترقيم معنى كوني. لا نحسب عدد كانتور المتضخم للشجرة.

صيغ الكم الإنتاجية هي `كل G هو P.` و`ليس كل G هو P.` و`كل G ليس هو P.`،
وتحفظ صيغة السؤال عند إضافة `هل ` و`؟`. يقبل الإصدار أيضًا محاذاتين
حرفيتين معلنتين: «ليس كل طالب مجتهدًا» و«كل طالب غير مجتهد». تتغير
الأسماء والأوصاف في الصيغ الإنتاجية دون تدريب؛ ولا تنشأ محاذاة صرفية
حرة. قوائم الأفراد غير الفارغة تحدد **مجال الاختبار** فقط. يحتاج حكم
الشمول إلى شاهد الانتماء والصفة لكل فرد، ويحتاج المثال المضاد إلى شاهد
انتمائه ووصفه المضاد. كل ذلك مصدرّي وقابل للسحب والتعارض.

يحتوي `sources` شواهد الوقائع فقط، و`initial_active` المصادر المتبناة،
ومنها `scope_policy` لتبني قانون الكم المحدود. سحب هذه السياسة يوقف
الاستدلال بها. لا يستطيع العميل استبدالها أو إدخال نتيجة النطاق كمقدمة.
مصادر الاستفهام وقواعد العميل لا تقبل كشواهد واقعة. يظل `owner_result`
كاملًا: مواضع المصدر، المقدمات الموقعة، الشواهد البديلة والتعارض،
وسجل المراجعة الأصلي. حدود المالك القائمة تنطبق أيضًا: 8 مصادر إجمالًا،
16 حدث مراجعة، و6 أوصاف أحادية في مسار وصل المعرفة.

مسار `conditional` يستقبل `connection` بالعقد القائم
`nabt.acquired-knowledge.request.v1` مباشرة؛ يحتفظ بالقراءة النحوية
والاستدلال الأصليين، ولا يستدعي الفاحص الحسابي لتوثيق معنى الشرط.
التحقق من شروط نقل الصندوق وهوية الحدث وزمانه ومكانه باقٍ في
`application.case`؛ لا يستبدله هذا المسار ولا يجعل العدد مفهومًا مستقلًا
عن موضوع العد. مصدر المعرفة الأنطولوجية باقٍ في `relations.analyze`.

## التشغيل وإعادة الفحص

```sh
make scoped-composition LAKE=/path/to/lean-4.34.1-linux/bin/lake
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/composition_arithmetic.json --output artifacts/local/arithmetic.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/composition_arithmetic.json --receipt artifacts/local/arithmetic.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/composition_quantifier.json --output artifacts/local/quantifier.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/composition_quantifier.json --receipt artifacts/local/quantifier.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway run --request examples/io_gateway/composition_conditional.json --output artifacts/local/conditional.json
PYTHONPATH=src:. python -m tools.grammar_catalog gateway verify --request examples/io_gateway/composition_conditional.json --receipt artifacts/local/conditional.json
```

مثال الكم يحافظ على الحكم عند سحب اللون، ويعلقه عند سحب المثال المضاد،
ثم يعيده عند استرجاعه. مثال الشرط يسير `UNKNOWN → SUPPORTED → UNKNOWN`.
تعني `PRESERVED` ثبات حالة الحكم؛ لا تدّعي تطابق سنديه قبل التحديث وبعده.

أضيفت مراجع تشغيل واختبار إلى عائلات `recursive-source` و`signed-inference`
و`evidence-lifecycle` القائمة. أعيد توليد فهرس البرهان وروابطه السبعة
إلى `evidence/scoped_composition_v1/integration` لأن الفهرس يربط كل ملفات
Lean، مع بقاء سجلات المبرهنات الـ1654 نفسها دون تعديل. لا تتحول هذه
الملاحة إلى إثبات لصحة مترجم الكم أو المحلل الحسابي في عموم المدخلات.
