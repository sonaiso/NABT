# خطة التوسعة وبوابات قبولها

الإصدار الأول أساس قابل للتشغيل، ولا يعادل اكتمال مشروع فهم العربية. ترتيب العمل التالي مبني على منع ترقية طبقة قبل وجود مدخلاتها المبررة.

| المرحلة | الناتج المطلوب | بوابة القبول القابلة للقياس |
|---|---|---|
| R0: النواة الحالية | ترميز، قانون صيغ، أثر، عد وترقيم وشهادة | بناء جميع وحدات Lean؛ لا ثغرات برهان؛ مطابقة 11,252 انتقالًا؛ نجاح فحوص العبث؛ قياس زمن وذاكرة مسجل |
| R1: تقوية المطابقة | ربط خوارزمية الترقيم السريعة بالمواصفة المرجعية المبرهنة | براهين الانعكاس للمواصفة موجودة؛ المطلوب برهان تنقيح لخوارزمية الفروع المحسوبة، ثم مطابقة التنفيذ مع تعريفها على مجموعة محجوبة مولدة مستقلًا |
| R2: جسر الرسم والصوت | تمثيل يحفظ النص، ويخرج تحليلات مرخصة للشدة والتنوين والهمزة والمد | كل تحويل له موضع ومصدر وقاعدة؛ الأمثلة الملتبسة تحفظ بدائلها؛ لا تطبيع مفقود الأثر؛ اختبارات عكسية لكل تحويل |
| R3: السماع والجذر | سجل شواهد مستقل، وجذر ثلاثي أو رباعي مربوط بمادة ودليل | لا يرتقي أي مولد إلى مستعمل بلا شاهد صالح؛ نقل شاهد من مادة أو مصدر آخر يُرفض؛ قياس استخراج الجذور على مرجع محجوب |
| R4: الصرف والنحو | قواعد وشروط وموانع ذات هوية، وقارئ يملأ التزاماتها | كل حكم يحمل سلسلة انتقالات مرخصة؛ النقص يرجع بأسماء التزامات؛ الغياب لا يتحول إلى نفي بلا استنفاد |
| R5: الدلالة والحكم | قضية مقيدة بالمصدر والقراءة والسياق، وربط بالدليل | لا يرخّص دليل قضية قضية أخرى؛ التصحيح يعيد فحص المعتمدات؛ فصل صحة الاشتقاق عن صدق المقدمة |
| R6: تعلم الإجراءات | مقترح يتعلم اختيار الانتقال أو طلب الدليل؛ النواة تفحصه | مسائل وقواعد جديدة محجوبة، نقل إلى مسألة أخرى، تغير مؤثر وتصحيح، مقارنة بالنواة وحدها وبخط أساس معلن |

## عقد التعلم المقترح

يكون هدف التدريب لاحقًا اختيار عملية مرخصة أو التزام الإثبات التالي، مع تعليل القرار بمسار تقبله النواة. لا تعلَّم الشبكة أن تسجل لنفسها شاهدًا أو تستبدل القانون المثبت. تقسيم التدريب والاختبار يكون بحسب عائلات القواعد والمصادر، ولا يكفي اختلاف صياغة النص لإثبات عدم التسرب.

يقاس النظام على أربعة محاور منفصلة: صحة الجواب، صحة سنده، جودة التعليق عند النقص، والموارد. لا يعوض نجاح الفاحص انخفاض القدرة على بناء معنى النص. لا يوضع موعد لمنافسة نموذج عام قبل وجود مهمة ومرجع وحدود أداء مشتركة.

## ما يسبق كل توسعة

1. تعريف المجال والمدخل والمخرج والهوية التي يحفظها التحويل.
2. تحديد معلومة المصدر وأثر الخطأ والمانع وأسباب التعليق.
3. بناء البرهان الممكن في Lean وتسمية ما بقي خارج البرهان.
4. توليد الأثر العددي من التعريف نفسه، ومقارنته بالتنفيذ.
5. اختبار مستقل يتضمن نقضًا وحالات حدود، ثم قياس مسجل قبل وصف الإنجاز.

كل مرحلة تقبل بذاتها. لا تحتاج النواة إلى تعديل المشاريع السابقة لتنفيذ هذه الخارطة.
