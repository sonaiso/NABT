# إصلاح مراجعة الأدلة وتدريب ترتيب الشهادات

تعالج هذه الإضافة الملاحظات الخمس على طلب الدمج 36 بعد دمجه، دون تعديل
النواة أو قانون قبول العربية. أُعيد إنتاج الأعطال باختبارات مستقلة قبل
الإصلاح: 8 إخفاقات ضمن 56 اختبارًا مركزًا. أضيفت لاحقًا حدود العدد الطويل
وإيصال الخطأ المبكر واتساق الحالة والبيانات الغائبة.

| الملاحظة | السلوك بعد الإصلاح |
| --- | --- |
| فقدان الدقة العددية | مقارنة عشرية قبل تعريض العدد لفحوص الأعداد الصحيحة؛ منع التقريب إلى عدد آخر |
| إخفاق benchmark بلا payload | قبول إيصال التعذر وعرض السبب دون إنشاء قياس أو مقام |
| `verified=false` المتناقض | فحص الأعلام والسلطة والحالة في الاتجاهين؛ الغياب غير محسوم |
| تركيز الطبقات | تحديث الاختيار في الزر الحالي دون استبداله |
| تركيز الادعاءات | تحديث الزر والتفصيل دون إعادة بناء القائمة |

أضيف أيضًا كشف الحالة غير المعروفة واختلاف حالة الغلاف عن النتيجة.
يتطلب مسار النقل الحي بيانات العقد كاملة؛ أما استيراد ملف ناقص فيعرض
النقص للمراجعة ولا يمنحه سلطة. حُددت ملفات `web/*.js` و`web/*.css` كملفات
مؤلفة للمراجعة في `.gitattributes`؛ لا يعني هذا أن مراجعة GitHub الآلية
أُعيدت. روجعت تغييرات `evidence-ui.js` وعلاقتها بـ`app.js` وأنماط التركيز
في `style.css`؛ الملفان الأخيران لم يحتاجا تعديل شفرة.

## التحقق

- 120 اختبار Node للواجهة والمدقق والنقل، بلا فشل أو تخطٍّ.
- 10 اختبارات ترتيب جديدة و15 اختبار تدريب سابق، بلا فشل أو تخطٍّ.
- 29 اختبار Python لمسار مختبر البرهان، بلا فشل أو تخطٍّ.
- بناء Worker والتحقق من `default.fetch` نجحا.
- متصفح فعلي: Enter على طبقة المدلول وSpace على ادعاء `walad` أبقيا
  التركيز على الزر المحدد، وحدثت حالة `aria-pressed` والتفصيل.
- قُبل إيصال `RESOURCE_EXHAUSTED` بلا حمولة benchmark، ورُفض العدد الذي
  يتغير بالتقريب، وأُخفي التقرير السابق عند الرفض.

تُحفظ السجلات والبصمات في `evidence/proof_lab_review_v3/` منفصلة عن الأدلة
السابقة. هذه فحوص موجهة للتغيير، وليست إعادة تنفيذ كامل `make check` أو
برهانًا على العربية كلها. المعاينة الداخلية HTTP لا توفر WebCrypto؛
يبقى هذا معلنًا، ولا يُستبدل ببصمة يصرح بها الملف.

## التدريب

نُفذت تجربة CPU فعلية على 98 مقترحًا تدريبيًا و32 للتحقق، مع 130 فحصًا
أصليًا و32 إعادة فحص Lean. تحسنت رتبة الشهادة المقبولة من 4 إلى 1 في
المجموعات الأربع. المقارن الحتمي غير المدرّب حقق النتيجة نفسها؛ لا تُدعى
أفضلية التعلم عليه. التفاصيل والأوزان والحدود في
[تقرير التدريب](TRAINING_REVIEW_V2_AR.md). لم تُنشر الأوزان في مسار القبول.

```bash
node --test integrations/proof_lab/site/tests/*.test.mjs
PYTHONPATH=src:. python -m unittest discover -s tests -p test_certificate_ranker_v2.py -v
PYTHONPATH=src:. python -m unittest discover -s tests -p test_training_readiness.py -v
PYTHONPATH=src:. python -m unittest discover -s tests -p test_proof_lab.py -v
```

لم يُنشأ مفتاح نقل جديد ولم يُفعّل تنفيذ Lean الحي في الصفحة. مرصد الأدلة
المحلي مستقل عنه، ويظل إعداد المفتاح المشترك خطوة منفصلة تحتاج التفويض
الصريح الذي طلبته مراجعة الموافقة السابقة.
