# المعجم كشهادة منقولة: مسار حي في مختبر NABT

أضيف مسار `testimony` إلى النقل المشفر القائم، وقسم **04 شهادات المعجم**
إلى الصفحة. يستقبل فهرس مدخل معجمي ومكونات هدف، ويشغّل الفاحص التنفيذي
`lexicalDenotation` المبني من Lean المثبت. يحتفظ بجميع قراءات المدخل في
السجل؛ لا يختار معنى باستعمال التشابه أو ترتيب النتائج.

## جهات التحقق المستقلة

| الجهة | ما يسجله التنفيذ | ما لا يترتب عليه |
|---|---|---|
| هوية النقل | المؤلف، الكتاب، النسخة، بصمة المصدر، موضع البايتات، الاقتباس | صحة الرواية تاريخيًا أو تواترها |
| مقابلة النسخة | `source_file_replayed` عند إعادة قراءة الملف المحفوظ فعلًا | مقابلة طبعات أو إثبات تاريخ الوضع |
| الدلالة | نتائج المطابقة والتضمن والالتزام لكل تفسير مثبت في Lean | تعيين مراد المتكلم في نص حر |
| اللزوم | سجل مستقل مربوط بالقراءة ومصدر القاعدة وتفسير الربط | علة حكم شرعي أو وجود فرد في الواقع |

ليس هناك علم واحد `is_verified_by_app` يجمع هذه الجهات. تظل
`transmission_type=UNASSESSED`، و`historical_authenticity_established=false`.
لم تُولّد أوزان موثوقية أو درجات تواتر من عدد المصادر أو أسماء المؤلفين.
هذا لا ينفي تصنيف المصدر لبعض النقل؛ إنما لا يدّعي أن التطبيق حقق ذلك
التصنيف لكل مدخل في سجله.

مقتطفات الشخصية المحفوظة تفرق بين النقل ومعرفة الوضع، وبين اللزوم الذهني
والوجود الخارجي. راجع [مصدر النظرية](../evidence/linguistic_truth_v1/sources/shakhsiyya3_linguistic_truth_selected.txt)
و[تفصيل الدلالات](LEXICAL_DENOTATION.md). الالتزام في التنفيذ شرط لدلالة
معينة في نموذج ذهني، وليس قاعدة عامة لاستنتاج سبب أو حكم من لفظ مفرد.

## إعادة استخدام البرهان

لا مبرهنات مكررة ولا تغيير في اللغة المقبولة للنواة. يستعمل المسار:

- `LexicalDenotation.check_exact`: قبول الفحص يكافئ تعريف الدلالة الممثلة.
- `indication_sound`: سلامة النتيجة **إذا** صدق تفسير المكونات وقواعد اللزوم.
- `no_necessity_without_ledger`: لا التزام بلا قاعدة مودعة.
- `necessity_preserves_sense`: قاعدة اللزوم مرتبطة بالقراءة كاملة.
- `definition_does_not_assert_world`: التعريف لا يثبت الوجود الخارجي.

هذه أسماء مختصرة داخل `Nabt`. يسجل التقرير أسماءها الكاملة، وبصمة الملف
التنفيذي، والطلب والنتيجة الأصلية. يطابق المحوّل تصدير Lean بكامل السجل
المثبت، ثم يفحص كل قراءة ونتيجتها، مع تمييز الأعداد والقيم المنطقية بدقة.
تحقق Python هذا حد للنقل؛ مصدر الحكم الدلالي هو تشغيل Lean.

## المصادر وحدود الفحص

السجل القائم يحتوي 18 قراءة مؤلفة وقاعدتي لزوم؛ ليس معجم العربية كله.
تُعاد قراءة ملفات المقاييس ومقتطف الشخصية المحفوظة ومقارنة بصماتها
ومواضع الاقتباسات. ملف لسان العرب الكامل ليس ضمن الحزمة التشغيلية؛
لذلك يظهر له `RETAINED_QUOTATION_ONLY`، ولا يعلن المسار إعادة فحص أصله.
تطابق مقتطف مع السجل المترجم لا يثبت صحة نسبة الرواية خارج الحزمة.
التحليل إلى مكونات دلالية والربط بين المصادر تفسيران مؤلفان غير محكّمين
استقلالًا، ويبقيهما التقرير ظاهرين.

لم تُدرج أمثلة «سماء/أرض/شمس» من المقترح كتعريفات معتمدة؛ تحتاج مواضع
مصدر وتحليلًا مراجعًا. ولا يعد مجرد ذكر الشمس إثباتًا لنهار عند مخاطب
معين، أو يجعل جميع خصائص الشيء أجزاءً من مدلول الاسم.

## البيانات والواجهة

لم تُنشأ جداول موازية للمعجم. تبقى `sources/passages/lexemes/concepts/senses`
في `integrations/inference_db/schema.sql` مخزن الهوية والسياق، وتظل
`observations` مستقلة. `testimony` إسقاط تنفيذي موثق فوق السجل المثبت،
وليس ترحيلًا تلقائيًا أو سجل أحكام تواتر جديدًا. فهرس المتجهات أداة استرجاع
ولا يُستعمل لترخيص شهادة أو ملء حقول الدلالات الثلاث.

الواجهة تعرض النقل والتفسير والنتيجة المشروطة منفصلة، وتتيح تنزيل JSON.
ترفض حدود النقل إعلان واقع أو تاريخ محقق، حذف قراءة، أرقام مواضع
كسرية أو غير آمنة، وتناقض علم التحقق مع النتيجة. تحفظ أيضًا إيصالات
الفشل الصحيحة دون اختلاق نتيجة Lean.

## إعادة التشغيل

```bash
lake --dir formal build lexicalDenotation licensedInference
PYTHONPATH=src:. python -m tools.lexical_testimony --entry بيت --target المأوى
PYTHONPATH=src:. python -m tools.lexical_testimony --entry فرس --target 'واحد الخيل'
PYTHONPATH=src:. python -m tools.lexical_testimony --entry عمي --target البصر
PYTHONPATH=src:. python -m unittest discover -s tests -p test_lexical_testimony.py -v
PYTHONPATH=src:. python -m unittest discover -s tests -p test_proof_lab.py -v
node --test integrations/proof_lab/site/tests/*.test.mjs
```

محليًا استُعمل مشغّل Lake الموثق سابقًا في
[تفاصيل البيئة](../evidence/arabic_completion_v5/local_toolchain/README.md)
بسبب تعذر اكتشاف إعداد التوزيعة تلقائيًا؛ نجح البناء عبره في 51 مهمة.
تستخدم GitHub Actions التوزيعة المثبتة مباشرة وتبني الفاحصين من المصدر.
أدلة هذه الإضافة في `evidence/lexical_testimony_v1/`.
