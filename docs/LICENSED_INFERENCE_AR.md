# من النص المرخّص إلى الاستدلال المفحوص

تصل هذه الإضافة القراءة النصية المحدودة ببرنامج الاستدلال القائم في NABT.
المقترح في Python لا يمنح نفسه سلطة: يعيد مدقق Lean قراءة المصدر والسؤال،
ويفحص مطابقة القراءة المقترحة، وشهادتي الإغلاق الموقع والإغلاق الخالي من
الاعتماد المتعارض. النتيجة تخص نظرية المصدر وفي مقامها المعلن؛ لا تثبت
وقوع الخبر في الخارج، أو اكتساب جميع قراءات العربية.

## المجال ومعيار الاكتمال

القانون `nabt.licensed-inference.v1` يعرّف جزءًا محدودًا: الاسمان زيد
وعمرو، والسير ومعرفة الحق، والإخبار المثبت أو المنفي بـ«لم»، والشرط
المتقدم أو المتأخر بفاعل صريح. تحتفظ القراءة بظرف «أمامك» و«خلف الدار»
أو اجتماعهما داخل وصف الحدث؛ لا تستخرج منهما مسافة أو علة أو وجودًا
فيزيائيًا. لا تُمحى الحركات اعتباطًا: الصيغ المضبوطة المقبولة محددة،
كي لا تتحول «عُرِفَ» أو «عَرَّفَ» إلى «عَرَفَ».
غلاف السؤال «هل …؟» والنقطة الفاصلة بين الجمل اصطلاحان لهذه الواجهة؛
لا يمثلان صياغة كاملة لأحكام الاستفهام أو الوقف في المصادر.

معيار اكتمال هذه الطبقة هو مطابقة القراءة لمواصفة هذا الجزء، ثم استنفاد
اشتقاقاته الأرضية ذات الإشارة. أما شمول المواصفة للعربية المستعملة وصحة
تفسير المصادر فالتزامان مستقلان. لا يُعرّف المجال المرجعي بأنه كل ما
نجح فيه Python، ولا يعد عدد الاختبارات الناجحة برهانًا على شمول الكتب.

في العبارة «سار زيد أمامك خلف الدار إن عرف الحق» يبقى فاعل «عرف»
غير معيّن في هذه الطبقة. يُظهر المحرك البنية الشرطية ويعلّق الاستدلال
بدل افتراض مرجعه. إضافة «زيد» صراحة إلى جملة الشرط تزيل هذا النقص
المحدد؛ لا تحسم بنفسها مرجع المخاطب والدار أو معنى «الحق» في كل مقام.

هوية النص ونسخته ومقامه جزء من الشهادة. المقام يحدد نظرية رمزية ثابتة،
ولا يثبت أن تقريرين في العالم يتحدثان عن الحدث نفسه أو الزمن نفسه.
التاريخ الفعلي والمرجع الخارجي يحتاجان دليل ربط مستقلًا.

## كل مرحلة ودليلها

| المرحلة | ما يلزم | ما لا ينشأ منها |
|---|---|---|
| استعادة المصدر | البايتات كاملة وهوية النص والنسخة والمقام | صدق الخبر أو صحة نسبة كل كتاب |
| القراءة | مواصفة الجمل المحدودة وفحص Lean المستقل | اكتمال جميع قراءات العربية |
| خفض الشرط | مقدمة وجواب لهما إطار محدد | إثبات أحد طرفيه أو عكسه |
| استنفاد الاستدلال | شهادة إغلاق مفحوصة لكل قراءة | استخراج مقدمات غير موجودة |
| الجمع بين القراءات | دعم محتمل ودعم مشترك مع شرط عدم فراغ القراءات | اختيار المقصود بأعلى درجة تشابه |
| الحكم على الواقع | صدق المقدمات وصحة جسور الربط في نموذج خارجي | تصديق تلقائي من علم Boolean أو من SQL |

يعاد استعمال `VerifiedReading.checked_closure_exact` و
`SemanticInference`؛ لا ينسخ البرهان الأساسي أو يتحول نص اسم المبرهنة
إلى سلطة. تربط إيصالات الأدلة الجديدة التصريحات المترجمة بالمصادر
وبحدودها، وتحفظ إيصالات المراحل السابقة كما كانت.

| العقد في Lean | نطاقه المحدد |
|---|---|
| `atom_read_exact` و`statement_read_exact` | تطابق قارئ الأشكال مع تركيبها المولد المحدود |
| `statements_read_exact` و`source_read_exact` | الانتقال بالاستقراء من الجملة إلى قائمة الجمل كاملة |
| `query_read_exact` و`reading_exact` | مطابقة السؤال والقراءة لمواصفة الجزء المعلن |
| `verified_execution` | اتصال بايتات المصدر والسؤال بالقراءة المقبولة وشهاداتها |
| `changed_source_rejected` و`changed_query_rejected` | منع إعادة استعمال الشهادة مع مصدر أو سؤال مختلف |
| `checked_row_exact` | تكافؤ الدعم المحسوب والاشتقاق، لكل إشارة وللنظرية النظيفة |
| `compositional_answers_exact` | تركيب حصر القراءات والإغلاق وصحة تفسير المعنى، مع إعلان المقدمات المستقلة |
| `skeptical_positive_exact` و`empty_readings_not_skeptical` | الدعم المشترك يحتاج مجموعة قراءات غير فارغة |
| `execution_entails` | انتقال النتيجة إلى تفسير يحقق معنى المقدمات؛ لا يثبت تحقق هذا الشرط خارجيًا |

## المنطوق والمفهوم والطريقة العقلية

«إن عرف زيد الحق سار زيد» يضيف علاقة شرطية داخل النظرية، ولا يضيف
واقعة معرفة أو سير. ورود دليل على المقدمة في المقام الرمزي نفسه يسمح
بتطبيق القاعدة. غياب الدليل على المقدمة لا يساوي إثبات نقيضها، وإثبات
نقيضها لا يجيز نفي الجواب من الاستلزام الأمامي وحده.

يتبنى المصدر الأصولي المراجع مفهوم الشرط بشروطه وموانعه. لذلك لا يُختزل
مذهبه إلى جدول صدق `P → Q`، ولا تُفعّل قاعدة المخالفة بمجرد ظهور «إن».
تبقى شروط تطبيقها واكتسابها من الموضع العربي مجالًا لاحقًا. انظر
[مراجعة المصادر](LICENSED_INFERENCE_SOURCES_AR.md).

الأدوار ON وFOR وFROM تنظيم للعمل: الاستقراء البنيوي يحتاج بُنى وحالات
أساس وخطوات؛ والاستقراء على الاشتقاق يثبت حفظ الحكم أثناء التنفيذ؛
والاستدلال من النتيجة إلى السبب يحتاج علاقة عكسية مستقلة. لا تتكون
مبرهنة استقراء من أسماء هذه الأدوار وحدها.

يفصل المخرج الدعم الموجب والسالب والدعم النظيف. تعارض القراءات المحتملة
مختلف عن احتواء قراءة واحدة على دعم الطرفين. ولا يُقبل إجماع مجموعة
قراءات فارغة. يحفظ حد الموارد بوصفه تعذر استنفاد، لا بوصفه نفيًا لغويًا.

## الاسترجاع والواقع

لم تُضف قاعدة بيانات موازية أو بيتًا منسوبًا بلا توثيق. يحافظ مسار
الاسترجاع الموجود على دوره في اقتراح هويات المقاطع وإعادة قراءتها من
المصدر. لا يعتمد ترخيص القاعدة على المتجه أو ترتيب النتائج أو حد العرض.
لا تحمل النتيجة `world_truth_established=true`؛ يلزم لذلك جسر مستقل
بين المقدمات والملاحظات الخارجية وبروتوكول فحصها.

هذه خطوة تنفيذية نحو اكتمال مركب قابل للقياس: قراءة محددة، ومقدمات
مكتسبة ضمنها، وإغلاق مفحوص. لا تغلق التزامات الضمائر الحرة والعلل
والقياس والمجاز والزمن واستنفاد الكتب أو العربية كلها.

## التشغيل وإعادة التحقق

```bash
cd formal
lake build licensedInference
cd ..
PYTHONPATH=src:. python -m tools.licensed_inference \
  examples/licensed_inference_source.txt examples/licensed_inference_query.txt \
  --source-id example --revision v1 --scope discourse --time episode1
PYTHONPATH=src:. python -m tools.licensed_inference \
  examples/licensed_inference_unresolved.txt examples/licensed_inference_query.txt
make -f Makefile -f integrations/grammar_catalog.mk \
  -f integrations/mantuq_inference.mk -f integrations/linguistic_truth.mk \
  -f integrations/licensed_inference.mk formal check LAKE=/path/to/lake
```

تحتاج الواجهة إلى المدقق المبني محليًا. غيابه أو رفض الشهادة لا يعاد
تسميته امتناعًا لغويًا ناجحًا. الجرد المصدرى يفحص المقاطع المحتفظ بها
افتراضيًا؛ إعادة فحص الأصل الكامل اختيار منفصل يظهر نطاقه في الإيصال.
تفاصيل مجموعة التقييم المثبتة في
[بروتوكول القياس](LICENSED_INFERENCE_BENCHMARK_AR.md).
