# شمول توليفات القراءات وربطها بالدلالة

تبدأ هذه الإضافة من دمج PR #18، الرأس
`2ee6525dedd921aacd30ce556d9fa92665463ce5`. تثبت شمول **تركيب مجموعات
البدائل المدخلة**، وتربطه بفاحص الاستنتاج السابق. لا تفترض أن عدد البدائل
اللغوية الذي اكتشفه Python كامل، ولا تعرض هذه المقدمة كأنها نتيجة مبرهنة.

## الحد الذي أُغلق

في `Nabt.ReadingEnumeration` تعرّف العلاقة التصريحية `Selects` القراءة المركبة
بأنها اختيار بديل واحد من كل مجموعة مرتبة. تنفذ `enumerate` حاصل الضرب الكامل.
تثبت `enumeration_exact` الاتجاهين: كل ناتج اختيار مرخص في هذه العلاقة، وكل
اختيار مرخص حاضر في التعداد. وتثبت `enumeration_count` أن العدد حاصل ضرب
أحجام المجموعات. لا تختزل البدائل بمجرد تشابه أسمائها أو هوياتها النصية.

لا يرسل Python قائمة التوليفات إلى الفاحص بوصفها القائمة الكاملة. يرسل مجموعات
البدائل وشهادات الاستنتاج، وتعيد Lean التوليف من هذه المجموعات. يلزم عدد شهادات
يساوي عدد التوليفات، وتفحص كل شهادة على مقدمات توليفتها. يرفض الفاحص الشهادة
الناقصة أو الزائدة أو الباطلة، وأي اختلاف في البايتات أو هوية المصدر أو النطاق
أو السياق أو الدليل المعجمي داخل الربط. يفتح المحول التنفيذي ملف الهدف مستقلًا
ويقارنه ببايتات الربط وهويته قبل الفحص.

تثبت `every_selection_entails` أنه إذا نجح الفحص، فإن النتيجة لازمة في **كل**
اختيار مرخص، وفي كل نموذج تتحقق فيه مقدمات ذلك الاختيار. يأتي الشمول هنا من
`enumeration_exact`، وليس من فرض `covers` يقدمه المستدعي. تستعمل المبرهنة
`MantuqMafhum.infer_sound`؛ وتظل صحة المقدمات في النموذج مقدمة صريحة.
لا تثبت هذه المبرهنة اكتمال البحث عن جميع النتائج المنطقية الممكنة.

تبقى القراءة الناقصة `none` داخل التعداد وتمنع قبول نتيجة كلية؛ لا تعادل
المجموعة الفارغة من المقدمات. وتمنع الوثيقة الفارغة أو مجموعة بدائل فارغة
قبولًا فراغيًا. يحفظ تجميع المقدمات ترتيبها، وتبقى المراجع والزمن والمكان
والقيود والنفي وقوة الخطاب ضمن صيغة القضية الكاملة.

## التنفيذ في القارئ الحر

أصبح مخطط تقرير `audit_discourse` هو `nabt.mantuq-mafhum-free-audit.v2`، وأضاف
حقل `document` إلى نتائج الجمل. يعيد التقرير القراءة من النص والسياق والتدريب؛
أي تقرير خارجي حذف بديلًا يرفض قبل التوليف. يقترح المحول النتائج الموجودة بين
القضايا، ثم تفحص Lean كل توليفة. يدعم فاحص Lean أيضًا شهادات اقتران واستلزام
بين مقدمات مجموعات مختلفة؛ اقتراح Python الآلي الحالي يختار القضايا الموجودة
ولا يدعي بحثًا استدلاليًا كاملًا.

حاصل الضرب توسع محافظ: قد يضم اختيارات لا تجيزها تبعيات الإحالة بين الجمل.
النجاح على هذه المجموعة الأوسع لا يسقط بديلًا مدخلًا، لكنه قد يحجب نتائج صحيحة
لا بد من إثبات التبعيات لاستعادتها. ولا يعالج ذلك احتمال أن يكون القارئ نفسه
قد فقد تحليلًا أو ربطًا إحاليًا قبل تكوين المجموعات.

الحدود التنفيذية: 64 مجموعة، و128 بديلًا في المجموعة، و128 مقدمة للبديل،
و4096 توليفة، و262144 مقدمة بعد التوسيع. عمق الصيغ والشهادات 32، وحد JSONL
الموروث 1 MiB. يفحص حد التوليفات **قبل** تخصيص حاصل الضرب. تثبت
`resource_exhaustion_no_verdict` أن تجاوز حد التعداد يعيد `none`، ولا يفحص
بادئة على أنها المجموعة الكاملة. يعرض المحول ذلك `UNMEASURED` مع
`reason=RESOURCE_LIMIT`، لا نجاحًا ولا إخفاقًا لغويًا.
وتثبت `zero_count_blocks` رفض حاصل الضرب الصفري قبل التعداد، بما فيه
مجموعة فارغة تأتي بعد مجموعات ضخمة؛ فحد الناتج وحده لا يحد كلفة هذا المسار.

كشف اختبار سلبي أن واجهة الفحص الدلالي كانت تطوي مفاتيح JSON المكررة قبل
فحص المخطط. أضيف حارس خام قبل `Json.parse` في هذه الواجهة، مقتبس من الحارس
المراجع في `RecursiveBridgeProbe`. يقارن المفاتيح بعد فك تهريبات JSON ويمنع
التكرار الحرفي أو المموه بـUnicode، مع إبقاء النصوص القيمية كما هي واستعادة
معالجة السطر التالي. لا يغير ذلك ناقل البرامج المجمدة الأخرى.

| الالتزام | الحالة بعد الإضافة |
|---|---|
| تعداد كل توليفة من المجموعات المعطاة | مبرهن في Lean |
| فحص نتيجة واحدة على جميع تلك التوليفات | مبرهن ومنفذ، دون فرض شمول إضافي |
| حفظ الربط والقراءة الناقصة وعدد الشهادات | مبرهن، مع اختبارات تبديل وحذف وحدود |
| شمول مجموعات Python لكل قراءة لغوية مرخصة | غير مثبت |
| مطابقة إسقاط Python للقضية العربية ومعناها | غير مثبتة عمومًا |
| اكتساب شروط دلالات الكتب لكل استعمال | غير مثبت |
| صدق المقدمات في العالم وصحة الرواية | يحتاج دليلًا مستقلًا؛ ليس نتيجة التعداد |
| اكتمال العربية | غير مثبت |

لا تتغير قيم `reader_enumeration_proved` أو `pool_completeness_proved` أو
`python_projection_proved` أو `world_truth_established` إلى true. الاسم الإيجابي
المحدد هو `supplied_pool_composition_proved`. ليس هذا قياسًا جديدًا للاكتساب،
ولا تعديلًا لنتائج الخطاب والتركيب أو حالات التقييم غير المقيسة.

## التحقق وإعادة التشغيل

```sh
make mantuq-mafhum-conformance
PYTHONPATH=src NABT_CLASSICAL_SEMANTIC_PROBE="$PWD/formal/.lake/build/bin/classicalSemanticProbe" \
  python -B -m unittest discover -s tests -p test_reading_enumeration.py -v
```

تشمل الاختبارات مرجعًا جبريًا مستقلًا لـ64 حالة، واشتقاقًا عبر الجمل، وحذف
شهادة التوليفة الأخيرة، وتكرار هوية البديل، وتغيير المصدر، وحفظ قيود القضية،
وتوليفات 4096 و8192، وقراءة فعلية لسابق غير مؤكد. هذه اختبارات هندسية مؤلفة،
وليست عينة عربية محجوبة. سجل التشغيل وبصمات المدخلات في
`evidence/reading_enumeration/VALIDATION.json`.

عند تعثر Lake المحلي، يعيد `tools/build_semantic_audit.py` بناء الوحدات وتدقيق
المسلمات وتوليد البرنامجين بالمكتبة الرسمية المثبتة، باستخدام مشغل التضمين
الموثق في `evidence/verified_reading/environment/main.c`. هذا مسار تحقق مباشر
ولا يسمى نجاحًا لـLake. تفحص GitHub Actions البناء العادي على رأس التغيير المنشور.
