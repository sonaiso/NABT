# عقد وكيل تركيب الوحدات قبل التنفيذ

الأصل: `7c86e16c217010c0af09c67886522e6e6f991fa4`، بعد دمج PR 81.

المطلوب غير الموصول حاليًا: تنسيق مولد C/V الأصلي، وأزواج المقاطع الستة،
ومركبات A116 وأثرها، والقراء والقوالب المصدرية، تحت وكيل استرجاع وتنفيذ
واحد. المولدات والقوانين موجودة؛ لا تنشأ لها نسخة Python بديلة.

## المجالات والمالكون

| العمل | المالك | حد الشهادة |
|---|---|---|
| حصص 0..4 من C وV، عدا الفراغ | `ProgressiveUnitProbe.quota` | جميع الترتيبات في الحصتين، لا الكلمات العربية |
| حاصل ضرب C وV والمقاطع الستة | `compose_shapes` | ترتيب الأجزاء كامل؛ 64 زوجًا، منها 36 زوج مقطع |
| أشجار التجميع | `forest` | كل التجميعات الثنائية المرتبة حتى ثماني ذرات |
| هوية المركب وأثره | `UnitCarrier`، `Machine.effect/compose_effects` | حفظ الخلايا وجميع حالات الدخول الـ97 |
| القراءة والكمية | `phonological_modes.realize` ثم `quantity/shape` | إسقاط مصدري مشروط، بلا قياس صوتي جديد |
| الجذر والوزن | `derivation.generate_derivation/read_derivation` | القوالب المثبتة، لا السماع ولا تعيين المعنى |
| السطح المعتل | `derivation_surface_bridge` | النطاق الحالي لشهادة الإعلال محفوظ |
| الأدوات والضمائر والمبنيات | قارئ الكلمات والفهرس المصدرّي و`AffixFunctions` | جميع البدائل والنواقص تبقى ظاهرة |

## التزامات القبول

1. `C+V` و`V+C` مختلفان؛ ومساواة الحصص لا تمحو الترتيب.
2. `CV+CVV` و`CVC+VV` قد يتساويان سطحًا؛ تبقى هوية القطع والتجميع مختلفة.
3. استنفاد 2C و2V يعطي ستة أشكال؛ أما CCCC وVVVV فلهما شكل واحد لكل حصة.
4. يستدعي الوكيل executable الأصلي. غيابه يعطي DEFER؛ لا تنتحل محاكاة Python
   صفة تنفيذ Lean. نفاد الميزانية RESOURCE_LIMIT وليس رفضًا لغويًا.
5. لا تجمع خلايا كلمتين مفصولتين في وحدة لفظية واحدة. تحفظ حدود كل جزء وكل
   كلمة، وتفحص الأثر المركب مقابل المالك الأصلي في كل الحالات.
6. قبول الشكل لا يختار العامل أو المرجع أو الجنس أو معنى الوزن.
7. لا يُستنتج جذر مشهود أو اسم جنس من مجرد ملء قالب.
8. الزمن الصرفي والقراءة الزمنية والتصرف والتمام/النقص محاور منفصلة.
9. «الأمر للمجهول» يوجّه إلى لام الأمر مع المضارع المبني للمجهول؛ لا يضاف
   قالب أمر مجهول إلى السجل. «المتمكن» الاسمي لا يخلط بتصرف الفعل.
10. التحقق يعيد التشغيل من الطلب المستقل ويقابل التقرير كاملًا، مع مراجع
    النسخ والمالكين. لا يقبل أعلام إتقان أو اكتمال مقدمة من صاحب الطلب.
