## دورة حياة الدعوى عند كل أمر

وحدة النقل العملية هي **الأمر أو العملية**. قد يجمع CLI واحد فهرسةً بلا
سلطة، وتشخيصًا، وتحكمًا مشروطًا، وفحصًا أصليًا. لا تكفي شهادة أحدها لترقية
الأوامر الباقية. يراجع السجل
`src/nabt/data/transport_command_contracts.json` كل أمر على حدة، مع حفظ
العقد القديم صراحةً عند توفير غلاف نقل جديد.

تنتقل الدعوى عبر: جرد المدخل، ثم تحصيل المقدمات، ثم قانون النواة، ثم مطابقة
التنفيذ للجواب الكامل، ثم المرجع المستقل، ثم النقل، ثم بوابة الإصدار.
يجب أن تحدد كل وصلة النص والحدود والمقام ومجال الأعداد وما اكتسبته فعليًا
وما بقي مقدمةً. غياب المشغّل وتحريف الإيصال ونفاد الموارد حالات مستقلة؛
لا تصبح أي منها رفضًا لغويًا أو برهانًا على الدعوى المقابلة.

يجوز عرض «برهان» مع الدعوى المحددة التي اجتازت فاحصها المثبت، لا مع
الجواب كله بسبب وجود `native_checked`. يبقى الغلاف المثبت مستقلًا عن
تفسير المتن، وتبقى مطابقة الشهادة المعجمية مستقلة عن مراد جديد أو تواتر.
القائمة الناتجة من مخطط الترحيل لا تمنح سلطة برهانية لأي مدخل.

## الوصلات المنفذة وحدودها

يمكن استدعاء الوصلتين مباشرة بعد بناء المشغلات المثبتة:

```python
from tools.linguistic_truth.discourse_boundary import acquire_discourse_boundary
from tools.transport_adapters import certify_inference

boundary = acquire_discourse_boundary(
    "لم أشاهد البحر؛ وأقصد بالأسد الحيوان المفترس.",
    context="مقام معلن للاختبار", profile_id=None,
)
inference = certify_inference(
    "إن عرف زيد الحق سار زيد. عرف زيد الحق.",
    "هل سار زيد؟", scope="مقام معلن للاختبار",
)
```

الأول يفحص حدود الغلاف، والثاني نتيجة استدلال بالنسبة إلى مقدمات المصدر.
يبقى `profile_id=None` غير محسوم، ولا تصير مقدمات المصدر مشاهدات للواقع.
تضيف الواجهة المحدثة العمليتين إلى «09 المسار المرخّص»؛ يثبت توفرهما حيًا بعد النشر وإعادة الفحص. وللاستدعاء من
ملفين في CLI: `python -m tools.licensed_inference --response-contract
scoped-v1 source.txt query.txt --scope "مقام الاختبار"`، مع إبقاء الخيار قبل
الأمر أو وسيطي الملفات. لا يُستورد هذا الغلاف بوصفه تنفيذًا حيًا جديدًا.

أضيفت وصلة `DiscourseBoundaryCueBridge` بإحدى عشرة مبرهنة عامة وستة عشر
ضابطًا محدودًا في النواة. تثبت الوصلة التحصيل الدقيق لغلاف نفي يتبعه حدّ
معلن وقرينة لاحقة، وحفظ الواو ومقاطع المصدر ومجال العلامات وترقيم القرينة
بالأساس المثبت. لا تثبت صحة خبر النفي في الخارج أو مراد المتن؛ تفسير القرينة
اللاحق تشخيص مستقل يحفظ جميع المرشحين والمستبعدين والمختارين وبصمة الإيصال
التشخيصي الكامل. لا يصبح هذا التشخيص مبرهنًا بوجود برهان حدود الغلاف.

أضيف غلاف `--response-contract scoped-v1` اختياريًا إلى خمسة مداخل CLI،
مع ربط طلب الأمر وجواب الطفل والدعاوى المسماة ومصادرها. يحفظ الوضع الافتراضي
عقد CLI السابق. مصفوفة النقل تضم 97 صف أمر/وضع عبر سبعة سطوح: 83 صف CLI،
وسبع عمليات بوابة، وسبعة أوضاع مختبر؛ تكرار المسار عبر أكثر من سطح لا يزيد
عدد الجسور اللغوية المبرهنة. منها 54 أمرًا في CLI المركزي ما زالت التزاماته
معلقة، و14 مجالًا عدديًا مصنفًا، و12 صفًا يصل لطفل أصلي محدود، وتسعة تشخيصية،
وستة عقود مختبر سابقة محفوظة، واثنان للمنطوق بشروط معلقة. هذا جرد سلطة
الأمر، لا نسبة اكتمال العربية أو نسبة اكتمال ترحيل جميع الواجهات.

يميز النقل بين سلامة البايتات وسلطة الفاحص المثبت. استيراد غلاف ذي بصمات
متطابقة يثبت سلامة الربط فقط، ولا يعيد منح دعاواه سلطة التنفيذ الحي.
تحفظ إيصالات غياب المشغّل وإخفاق التنفيذ ونفاد الموارد حالة الإخفاق؛ لا
تحتاج حمولة benchmark مصطنعة، ولا تحمل دعاوى لغوية موجبة.

أنشئ تجميد runtime جديد في `evidence/legacy_migration_v2/code_freeze_v1.json`:
104 ملفات؛ داخل هذا الجرد المجمد تقتصر التغييرات على CLI والجرد وإضافة مساعد النقل ومصفوفة الأوامر. وتشمل الحزمة أيضًا براهين Lean وتحديثات الواجهة المثبتة في هوية runner.
بقيت عتبات المقيمين وموادهم وأجوبتهم المرجعية كما كانت. هوية runner الجديدة
تأتي بعد قياسات التطوير المعلنة؛ ليست عينة عمياء ولا إعادة ختم لنجاح v5.
بوابة `legacy-migration-conformance` تبني المشغلات وتفرض
`NABT_REQUIRE_NATIVE_TRANSPORT=1`، ولذلك غياب Lean فيها إخفاق لا تخطٍّ.
في وظائف اختبار Python المحمولة، يتخطى الاختبار الذي يحتاج المشغّل وحده
عند غيابه، وتبقى اختبارات سلامة النقل والأخطاء والموارد فعالة.
