# قراءة النسبة عند نقص الضبط

بدأت هذه الشريحة من حالات أحجم عنها قارئ NABT في الالتزام 683697e. أضيفت إلى شبكة الترخيص نفسها قراءة تربط النص المكتوب بأوجه صرفية ونحوية متوافقة داخل عائلة فتح الباب والصندوق والنافذة والبوابة. يمكن تجربتها من مدخل القارئ المعتاد.

```sh
export PYTHONPATH=src:.
python -m tools.grammar_catalog gateway read --text 'افتح النافذة بعد الظهر.'
python -m tools.grammar_catalog gateway read --text 'يا أهل القرية، افتحوا الباب'
```

## ماذا يقرأ المحرك؟

| الصياغة | الشاهد والنتيجة |
|---|---|
| هل فتحَ البابَ الحارسُ؟ | «هل» أداة السؤال. يُبحث عن الحارس في موضعي الفاعل المحتملين وعن الباب في موضعي المتأثر، مع فحص الحركات المدونة وقيد المعنى المختبَر. |
| يا أهل القرية، افتحوا الباب | للنداء والطلب نطاقان. يعيد القارئ بطاقتين بالترتيب. سحب «يا» من شبكة الاعتماد يوقف ترخيص النداء، ويظل طلب فتح الباب مرخصًا. |
| افتح النافذة بعد الظهر | يسند الطلب إلى مخاطَب مفرد، ويربط النافذة بالفعل و«بعد الظهر» بالزمن النسبي. هوية الشخص والتوقيت العددي والوقوع تحتاج إلى شواهد أخرى. |
| ليت باب المدرسة مفتوح | «المدرسة» مضاف إليه، و«مفتوح» خبر في مضمون التمني. جنس رأس المركب «باب» هو الذي يضبط اتفاق الصفة. |
| لم يُفتَح صندوق البيت أمس | يبقى الفاعل غير معيّن، ويُذكر الرسم المنافس «لِمَ» عندما تسمح به الحركات المشاهدة. يصل النفي إلى الحدث في قراءة «لَمْ». |
| لم يفتح باب المدرسة أمس | يغيب الشاهد الذي يميّز صوت الفعل في هذه الشريحة، فيظهر الدين المعرفي وتبقى القراءة مفتوحة. |

كل قراءة جديدة مشروطة بالقاموس التركيبي المعلن. تحفظ لكل موضع الصيغة المشاهدة، والمدى الأصلي ببايتات UTF-8، والوجه المقترح، والحركات غير المكتوبة منفصلة. لم تُستبدل بايتات النص بعبارة مصحّحة. شواهد «قطر الندى» وشواهد النفي والنائب عن الفاعل والمعنى من المصادر المودعة تعاد مطابقتها عبر القراء الموجودين. اختيار ألفاظ الحامل والفاعل والوقت مؤلَّف لهذه التجربة. يحتاج تعميم القابلية الفيزيائية أو تفسير المجاز أو تعيين مقصد «لعل» في كل مقام إلى دليل مستقل.

يتاح الرسم الكامل باختيار `licensed_speech` في مساري `text.read` و`relations.analyze`. يعرض `decoded` القراءات، ويعرض `owners` تفاصيل اللفظ وشواهد القاعدة. يحدد `revision` ما توقف وما بقي عند السحب. في الحالات المفتوحة يعرض `partial_speech.missing` سبب توقف هذا المسار. ويحفظ قارئ النص بوابة فشل فحص المصدر كما هي.

## إعادة القياس والتدريب

ثُبّتت ثماني عبارات من التجربة السابقة، واثنتا عشرة عبارة جديدة، وست عشرة حالة ضابطة قبل التنفيذ. تتشارك حالات النقل مع التدريب مجال الفتح وبعض البنى، وأُنشئت يدويًا. أعيدت الطلبات نفسها على نسخة البداية ونسخة النهاية، مع تحقق مستقل من كل إيصال. تحسب النتيجة تطابق ترتيب أفعال الكلام، وتعرض أخطاء الرأس العصبي منفصلة عن حكم القارئ. يختبر جناح الانحدار أيضًا الحامل والموقع والشاهد والسحب والتعارض.

أعيد استخدام GRU بأوزانها المثبتة. دُرّب الرأس الخطي على ٣٩ جملة من بيانات التدريب القديمة بعد حجز أي جملة تطابق رسم إحدى جمل الاختبار عند حذف التشكيل. استُبعدت بذلك عائلة جملة «هل فتح الحارس الباب؟» من التدريب الجديد. أنتج التدريب ١١٧ صورة كتابية أصلية أو مخففة الضبط. خضع الرأس السابق، المدرَّب على أربعين جملة، للقياس على النصوص نفسها. يمكن إعادة التدريب باستخدام NumPy، ويحتاج فك الترميز إلى مكتبة Python القياسية. لا يستخدم الفاحص تصنيف الشبكة لترخيص قراءة لغوية.

```sh
python -m unittest -v tests.test_partial_speech tests.test_licensed_speech
python -m tools.evaluate_partial_speech --workers 2 --output /tmp/paired-speech.json
python -m tools.evaluate_licensed_speech --workers 2 --output /tmp/previous-speech.json
OPENBLAS_NUM_THREADS=1 python -m tools.lexical_training.speech_force --output /tmp/refit-speech.json
cmp /tmp/refit-speech.json tools/lexical_training/data/speech_force_v2.json
```

المصدر المحلي المطلوب للقياس هو NABT مع تنفيذيات Lean المشار إليها في دليل البوابة. يقارن مدخل التقييم الأزواج مع نسخته المجمدة في evidence/partial_speech_v1. تختبر عينات الضبط وجوب الإرجاء **ضمن المجال المؤلف**. يمكن أن تكون الجملة المفتوحة قابلةً لتفسير آخر في الاستعمال العام.
