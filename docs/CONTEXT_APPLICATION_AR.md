# وصل الإعراب بالأثر والمقام والزمن

هذه شريحة تنفيذ من الخطة المرفقة: دمج مسار #82 مع أساس #81 ووحدات #83،
ثم تسجيل التطبيق بين القارئين القائمين والخلايا والأثر والقرائن الزمنية.
لا تتغير سلطة قبول العوامل أو شروط `CertifiedBridge` بجمع التقارير.

## التشغيل وإعادة الفحص

```sh
lake --dir formal build unitDiscoveryProbe progressiveUnitProbe temporalContextProbe
PYTHONPATH=src:. python -m tools.grammar_catalog application analyze \
  --request examples/context_application/application.json --output /tmp/application.json
PYTHONPATH=src:. python -m tools.grammar_catalog application analyze \
  --request examples/context_application/application.json --verify /tmp/application.json
PYTHONPATH=src:. python -m tools.grammar_catalog application temporal \
  --request examples/context_application/quotation.json
PYTHONPATH=src:. python -m tools.lexical_training.teaching \
  --request examples/context_application/withdrawn_lesson.json
make -f Makefile -f integrations/grammar_catalog.mk context-application
```

`application proofs` يستعيد التصريح وتوقيع المبرهنة وتبعياتها من الفهرس
المترجم الحالي؛ لا ينشئ فهرسًا ثانيًا. تبقى إحالات مصادر الإعراب الـ22 غير
المسندة لمبرهنات صريحة مفتوحة. العقود التسعة المرتبطة بالعمليات إحالات إلى
نطاقات معروفة، وليست برهانًا أن كل تطبيق Python يحقق مقدماتها.

## سجل التطبيق

لكل صف من القارئ النحوي أو قارئ الإعراب: هوية المصدر وبصمته وحدوده بالبايت،
هوية القارئ والإطار والقراءة ورقم الصف، المقاطع الدنيا المتقاطعة معه، الشواهد،
نطاق القول، والعقد الزمنية ذات الصلة. تُحفظ التقارير الأصلية كاملة؛ نتائج
البحث المحدودة بـ`limit` لا تحذف صفوف القارئين. العد هنا لوقائع الصفوف التي
أخرجها القارئ، وليس لعدد القراءات العربية الصحيحة أو لعدد معاني الجملة.

`units run` يدعم `op: source` باستخدام ماسح الكلمات الحالي. لا تعبر خلايا
كلمة إلى أخرى، وتحفظ المسافات والترقيم. الاقتباس يبقى قطعة غير محللة في
هذا الماسح، ويصرح التقرير بذلك. يطبق وضع النهاية المطلوب على كل كلمة
منفردة؛ ليس هذا إثبات النطق المتصل للجملة كلها.

`shape_count` يعيد استعمال `Machine.count/rank/unrank` عند الوزن 0 إلى 2.
مجاله أشكال كلمات A116 المرخصة بالقانون المثبت. لا يساوي عدّ صفوف الإعراب
أو الشواهد أو الأيام، ولا يولد شهادة صحة كلمة معجمية.

المثال `application.json` يربط إطار «لَمْ يَكْتُبْ» المدعوم بقرينة زمنية
سياقية معطاة. المثال المنفصل `application_with_adverb.json` يحتفظ بالجملة
«لَمْ يَكْتُبْ أَمْسِ.»: يفحص الزمن المشروط، لكن القارئ الحالي لا يخرج صفوفًا
إعرابية لهذا الإطار الأطول، فتكون نتيجة التطبيق `DEFER`. لا تُضاف قراءة
بواسطة الاختبار، ولا يحول نجاح الفاحص الزمني هذا النقص إلى نجاح نحوي.

## عقد المقام والزمن

واجهة التطبيق تقبل المقام القديم، أو غلاف
`nabt.discourse-context.v2` الذي يحتوي `reference` للقارئ القديم و`temporal`
للعقد `nabt.temporal-context.v1`. لا تتغير واجهة `read_context` القديمة.

| السجل | ما يصرح به |
|---|---|
| scope | الأب وحدود النص، قوة القول، القطبية |
| evidence | شاهد نصي مطابق للبايتات أو مقدمة سياقية، وحالة نشاطه |
| node | دور S للقول أو R للمرجع أو E للحدث، ونطاقه ومراسيه البديلة |
| relation | طرفان في النطاق نفسه، نوع العلاقة، وشواهد تفسيرها |

العلاقات الأصلية: `before/after/equals/intersects/contains/within` على فترات
مغلقة بالأيام الغريغورية. `offset_days` اشتقاق موجه من مرساة معلومة؛ يحفظ
سلسلة شواهده ولا يسمح بدورة تبرر نفسها. لكل نطاق عقدة S واحدة بمراسي بديلة؛
لا يستعير الاقتباس زمن القول الخارجي، ولا يستعمل تاريخ النظام لملء المجهول.
ترجمة القرينة العربية إلى العلاقة **مقدمة معطاة**، وليست اكتسابًا آليًا مثبتًا.

المراسي في القائمة بدائل، لا ادعاء أنها حقائق متزامنة. تُفحص جميع أزواج
البدائل للقيود الثنائية، وتظهر النتيجة المختلطة `AMBIGUOUS`. الشبكات الرمزية
غير المؤرخة تبقى `UNKNOWN`؛ لا يدعي هذا الإصدار حل اتساقها العام. إذا حُذف
شاهد سقطت مشتقاته، مع بقاء ما يستند إلى شاهد مستقل.

الأوامر والنفي والشرط والاقتباس محفوظة في النطاق. تحقق الحساب لا يثبت وقوع
الحدث أو صدق الخبر أو السببية. ليست علاقة `before` بديلًا لعلة أو سبب.
الأيام هنا مستوى الدقة الوحيد؛ لا ساعات أو مناطق زمنية أو ضبط تقويمي قبل
السنة 1 وبعد 9999. من مراجع التصميم العامة [OWL-Time](https://www.w3.org/TR/owl-time/)،
وليس هذا تنفيذًا لجميع علاقاته أو ادعاء توافق معياري كامل.

## البرهان والتعلم

أضاف `Nabt.TemporalContext` تسع مبرهنات: تكافؤ قبول المقارنة مع صحة الفترتين
وتحقق العلاقة، حفظ المجهول عند غياب أحد الطرفين، لاإنعكاسية «قبل» وتعديها
بشرط صحة الفترة الوسطى، حفظ صحة الفترة وعرضها عند الإزاحة، وحفظ سجل الإطار
وعدم منح صدق العالم. مبرهنتا السجل تصفان `record` في Lean؛ ربط نطاقات
Python بالمصدر مفحوص باختبارات، ولم يُبرهن تنقيحه العام.

أُضيف التخصص `context.time` إلى المنهاج القائم تحت وكيل الواقع والقياس.
يأتي بعد تفسير الفعل والأداة في التركيب وقبل اعتماد العوامل. هذا ترتيب
تعليمي للقدرات، وليس اشتراط تاريخ معلوم لكل جملة نحوية. دخلت مصفوفة الزمن
ومنّفذ `temporal_context` إلى وكيل التعليم القائم. الدروس تستعمل الفاحص
وتختار الالتزام التالي من النتيجة؛ لا تدرب هذه الدروس نموذجًا زمنيًا عصبيًا.

أعيد تدريب مسترجع العوامل القائم بعد تغيير بصمة الفهرس، دون تعديل البروتوكول
أو محو سجل `run_01`. سجل `context_application_v1/awamil_retrain` يحتوي
210 تحديثات وتحركًا فعليًا في الأوزان، ويغطي بطاقات الجرجاني المئة وجدول
NABT المئة و12 علاقة. النتيجة على 424 سؤال اختبار مؤلف معاد التشغيل:
38.21% لأعلى اختيار عصبي، مقابل 95.52% للاسترجاع اللفظي. لذلك بقي الترتيب
العصبي محجوبًا ببوابة التطوير. هذا قياس إعادة إنتاج على تقسيم معروف، وليس
تعميمًا جديدًا على جذور أو جمل حرة. أوزان السجل القديم تُرفض عند الفهرس الجديد.

المرجع العددي الحالي: 34 تخصصًا، 116 موضوعًا مطلوبًا، 19 مصفوفة تعليمية.
عدد الموضوعات 116 ليس الخلايا 116؛ المجالان منفصلان. الفهرس الحالي يحوي
1617 تصريحًا بعد إضافة التسعة، دون تغيير أعداد الأدلة التاريخية.
