# تحليل المقترح ومنهج الترميز وفحص المقترحات

تطبيق تجريبي بتاريخ 25 أكتوبر 2026 بتوقيت عمّان. نقطة الانطلاق هي
`c0b60d4`، وتشمل تصحيحات #22 فوق `main` عند `b539221`.
يُراجع وضع الدمج في طلب التغيير؛ وجود الملفات هنا لا يثبت دمج الفرع.

## الحكم على المقترح

الصفحة الخامسة المرفقة تضع أساسًا مناسبًا: النموذج يقترح، والفاحص يمنح
القبول، والترميز قابل للعكس، والمقارنة مقترنة، والتدريب مشروط بعائق مقاس.
الملفات المتاحة صورة تجميعية صغيرة ونسخ أوضح من الغلاف والفهرس والصفحة
الخامسة. اعتمد هذا التطبيق على البنود المقروءة وعلى الشيفرة الحالية؛
لم تُنسخ تفاصيل الجداول الصغيرة غير الواضحة ولم تُعامل أرقامها كقياسات جديدة.

| القرار | التحسين المنهجي | التنفيذ الحالي |
|---|---|---|
| encoder ليس بالضرورة شبكة عصبية | فصل هوية النص عن tokenizer النموذج وعن تمثيله المتعلم | غلاف UTF-8 قابل للاستعادة؛ لا تطبيع خفي |
| الرقم هوية | تثبيت الأبجدية وترتيب الحالات ومجال الرقم؛ المسافة بين رقمين ليست تشابهًا دلاليًا | سجل A116 وبصمته، وترميز موضعي وإطار 7 بت |
| تقييد التوليد | صلاحية JSON أو قواعد النحو لا تثبت مطابقة معنى النص؛ يبقى الفحص الدلالي مستقلًا | فحص شهادات خارجية مكتملة بالنواة؛ لم يُنفذ قناع logits |
| المقترح غير موثوق | لا ينفذ تعليمات ولا يحدد مسار الفاحص ولا يحذف المحاولات الفاشلة | ملفات شهادات محدودة الحجم، سجل لكل خانة من ميزانية k |
| حفظ التعدد | مقترحات متعددة لا تثبت استنفاد قراءات العربية | حفظ نتيجة كل مقترح، وعدم إعلان اكتمال مجموعة القراءات |
| تفسير الجواب | يُبنى من الدليل المقبول، مع فصل ذلك عن سبب اختيار الشبكة العصبية | شهادة التحليل الموجودة وإعادة تحقق مستقلة من المصدر |
| اختيار التدريب | قرار على تحقق مستقل وتكلفة معلنة، ثم اختبار محجوب واحد | بروتوكول مقارنة قابل للتشغيل؛ أوزان النموذج وكلفة GPU غير مقاستين |

تقييد المخرجات بقواعد تدريجية له سابقة تنفيذية في
[PICARD، EMNLP 2021](https://aclanthology.org/2021.emnlp-main.779/)؛
الدراسة تختبر SQL ولا تثبت صلاحية إسقاط العربية على قانون NABT.
وتبين [دراسة أمانة التفسير](https://www.anthropic.com/research/reasoning-models-dont-say-think)
أن الشرح الذي يولده نموذج ليس بذاته سجلًا أمينًا لأسباب قراره.
لذلك يُصدر التطبيق شرحًا مرتبطًا بالشهادة، ويترك السببية الداخلية غير مقاسة.
وتبقى قاعدة الثقة للتنفيذ الأصلي شاملة المترجم وبيئة التنفيذ، وفق
[توثيق Lean](https://lean-lang.org/faq/#what-is-the-trusted-code-base-of-lean).

## العقود وحدود السلطة

1. **غلاف المصدر `nabt.source-envelope.v1`:** البايتات الأصلية في hex معياري
   صغير الأحرف، طولها وبصمتها وهوية المصدر ونسخته ومجاله. يحفظ BOM وCRLF
   والتشكيل والمحارف كما جاءت؛ لا NFC ولا حذف للتطويل أو الشدة. نجاح فك
   الغلاف يثبت اتساقه فقط. `verify_source` يقارنه ببايتات وهوية مستقلتين.
2. **عرض الكلمة `nabt.a116-word-view.v1`:** كلمة واحدة تحت القارئ الحالي.
   ترتيب الحالات المثبت هو فتح، ضم، كسر، سكون؛ لا إعادة ترقيم صامتة.
   الخلية `a` ضمن 0..115، وترميز القائمة يحقق `n' = 116*n + a + 1` من
   `n=0`. `number_hex` تمثيل للعدد نفسه، ويتجنب حد التحويل العشري في Python
   للكلمات الطويلة. لا يساوي هذا الرقم رتبة الكلمة في لغة مرخصة ولا معناها.
   تبقى الألفاظ بلا تشكيل وصور الإملاء غير المدعومة معلقة بأسباب القارئ
   القائم؛ الترميز الناجح وحده لا يثبت قانون الصوت أو الصرف أو الدلالة.
3. **فحص المقترحات `nabt.bounded-decoding.v1`:** كل مدخل شهادة JSON بوصفها
   بايتات، ضمن `nabt.verified-ground-reading.v1`. لا يختار المقترح الفاحص
   أو المصدر أو المرجع أو حالة الجواب. يُرفض `null` كي لا يشغّل مقترحًا
   بديلًا ضمنيًا. تفحص النواة كل شهادة، ثم يبنى العرض من النتيجة المقبولة.
4. **إعادة تحقق الجواب المختار:** المصدر والسؤال وملفات المقترحات تأتي
   مستقلة من المستدعي. يعاد فحص الجواب بالنواة، وتطابق شهادته المقترح
   المحدد. هذا لا يصادق سجل الزمن أو ترتيب الاختيار أو سجلات الرفض؛
   أعلام `audit_log_authenticated` و`selection_order_authenticated` كاذبة.

هذه إضافات Python فوق العقود القائمة. **لا مبرهنة Lean جديدة ولا برهان
تنقيح شامل لهذا الغلاف**. لا تُحوّل القراءة المضبوطة الحالية إلى قراءة
عربية حرة، ولا يُعلن مسار كامل من 116 إلى دلالة كل مصدر؛
`a116_chain_established=false`. المسار الخاص بالكلمة ومسار استلزام القضايا
لهما بوابتان ونطاقان مختلفان. الوصل الشامل بينهما التزام مستقل.

حدود التشغيل: مصدر 64 KiB، سؤال 8 KiB، شهادة 1 MiB، و`1 ≤ k ≤ 16`.
الميزانية الزمنية مشتركة للتحقق، بحد أقصى 60 ثانية، وتُمرر بقية الوقت
إلى الفاحص. إنها مهلة تعاونية مع مهلة للعملية الفرعية وليست حجزًا آنيًا
للآلة أو حدًا لزمن خدمة LLM. توليد المقترحات خارج هذا القياس، وعند قياس
المسار المحلي المقترن يحسب المقيّم زمن إنشاء المقترح الجديد في كلا الطرفين.
الخانات المفقودة أو التي تعذر تنفيذها تبقى في السجل. لا يتحول غياب مقترح
مقبول إلى `UNKNOWN`: هذه الأخيرة نتيجة دلالية لا تصدر إلا عن إغلاق مفحوص.

يختار العرض أول مقترح مقبول بالترتيب المقدم، ويحفظ نتائج البقية. لا يعني
ذلك أن أول مقترح هو أفضل قراءة للعربية الحرة. إذا أعطت شهادتان مقبولتان
حالتين متباينتين لنفس المدخل في هذا القانون الحتمي، يحجب الاختيار ويعلن
`INCONSISTENT_VERIFIED_RESULTS`. يجب حفظ ملفات المقترحات الأصلية لإعادة
تشغيل التجربة؛ بصماتها وحدها لا تعوضها.

## التشغيل

```bash
lake --dir formal build verifiedReading
python tools/licensed_decoding.py encode examples/verified_reading/source.txt
python tools/verified_reading.py examples/verified_reading/source.txt examples/verified_reading/query.txt --output artifacts/local/proposal.json
python tools/licensed_decoding.py run examples/verified_reading/source.txt examples/verified_reading/query.txt --candidate artifacts/local/proposal.json --k 1 --output artifacts/local/decoding.json
python tools/licensed_decoding.py verify examples/verified_reading/source.txt examples/verified_reading/query.txt artifacts/local/decoding.json --candidate artifacts/local/proposal.json
make licensed-decoding
```

للمقترح العصبي المستقبلي: يكتب نفس ملف الشهادة ويُمرر عبر `--candidate`؛
لا يلزم منح النموذج تنفيذ shell أو تعديل القانون. يقبل الأمر عدة ملفات
مع `--k` مناسب. لا يحمل هذا الإصدار عميلاً لخدمة نموذج أو أوزانًا مدربة.
`encode --word` يفحص كلمة واحدة. الخروج 0 لعملية ناجحة، و1 لعدم وجود
جواب متحقق أو لتعليق/رفض عرض الكلمة، و2 لفشل واجهة أو مدخل. ملفات نتائج
الأداة تكتب حصريًا ولا تستبدل نتيجة موجودة. تقرير التشغيل يقبل أزمنة
كسرية؛ شهادة المقترح لا تقبل إلا الأعداد الصحيحة غير السالبة المعيارية.

## القياس وقرار الانتقال

[البروتوكول](../evidence/licensed_decoding/protocol.json) يفصل ثلاثة محاور:

| المحور | المقياس | شرط النجاح الحالي |
|---|---|---|
| الهوية | استعادة البايتات والتحقق من ربطها مستقلًا؛ هويات A116 الـ116 | 100% على المدخلات المختبرة؛ لا محو لفارق Unicode |
| المقارنة المقترنة | نفس الحالات الأربع عشرة، k=1، المقترح الحالي في المسارين، 3 تكرارات وتناوب ترتيب التشغيل | 14/14 تطابق حالات وإعادة تحقق واستعادة مصدر |
| حقن العطل | شهادة صحيحة الشكل بسؤال محرّف أولًا، ثم الشهادة الأصلية؛ k=2 | رفض الأولى في 14/14 واسترداد الجواب الصحيح في 14/14 |

`pass_at_1` يقيس نجاح أول مقترح فعلي. `pass_within_k` نجاح واحد على الأقل
ضمن أول k خانات مرتبة. هذا قياس مباشر لقائمة ثابتة، **ليس** مقدر pass@k
غير المنحاز لعينات عصبية مستقلة. تجربة المقترح المحرّف اختبار متانة
مصطنع معلن؛ لا تقدم دليلاً على تحسن التعلم أو اللغة. الحالات الأربع عشرة
هي مجموعة التطوير السابقة، لا اختبارًا محجوبًا جديدًا. تبقى كل حالة في
المقام إذا فشل المقترح، وتسجل المقاييس غير المقاسة `null`.

قياسات الزمن محلية، مع جميع العينات وعددها وP95 بطريقة الرتبة الأقرب.
لا تمنح هذه العينات SLA أو تفوقًا على GPT-5. مقارنة النموذج المرجعي تتطلب
اسم الإصدار وإعداداته ونفس المصادر والأسئلة وميزانيات الرموز والمحاولات
والوقت، مع فصل تقييم الطلاقة البشرية عن قبول البرهان ومطابقة المعنى.

تستمر [الأهداف السابقة](../evidence/explainable_pilot/goals.json): دقة
انتقائية ≥99% عند تغطية ≥80%، ودقة حالات محجوبة ≥90%، ومراجعة تفسير
مستقلة ≥98%، وصفر قبول غير مسند على ≥3000 سلبية مستقلة. شرط التكبير:
زيادة تغطية ≥2 نقطتين مئويتين عند دقة ≥99% وحد أدنى موجب لفاصل ثقة 95%
للفارق المقترن، مع ميزانية وتكلفة محددتين. هذه أهداف قرار وليست نتائج اليوم.

## برنامج الأسابيع الاثني عشر

تبدأ المدة بعد توفير الفريق والبيانات والعتاد، دون إعادة عدّ زمن التطوير
الحالي على أنه أسابيع منجزة.

| الأسابيع | العمل وشرط الانتقال |
|---|---|
| 1–2 | اعتماد العقود وخط الأساس؛ تجميد بروتوكول المقارنة. تقسيم البيانات بحسب المصدر والوثيقة والعائلة والقالب، وفحص التسرب قبل التدريب. يتولى مراجع مستقل الاختبار المحجوب. |
| 3–4 | ربط نموذج موجود بمنفذ المقترحات؛ تسجيل هوية النموذج وإعداداته وجميع المحاولات والتكلفة. اختبار إضافات الاسترجاع وتقييد البنية بصورة منفصلة. |
| 5–8 | معالجة أكبر سبب فشل مقاس؛ مقارنة الاسترجاع والتوليد المقيد والتدريب الخفيف على نفس التحقق. لا تعديل للمعايير بعد رؤية نتائج الاختبار المحجوب. |
| 9–12 | تشغيل محجوب وفق البروتوكول، وفواصل ثقة مع احترام ترابط المصدر، ومراجعة مستقلة لإسقاط النص على المنطق وأمانة التفسير. قرار استمرار أو إيقاف موثق. |

البيانات اللغوية الجديدة تكون فصحى معيارية مضبوطة ومصرحًا باستعمالها؛
يبقى الرسم القرآني مسارًا منفصلًا. أمثلة القضايا التقنية الحالية تقيس
عقد البرنامج، ولا تتحول بهذا إلى عينة تغطية لغوية أو مجموعة تدريب جديدة.
يفصل سجل الإخفاقات بين النقل، والإملاء/التشكيل، والتحليل، والإسناد للمصدر،
والاشتقاق، والموارد والعرض. لكل فئة مالك إصلاح ومقياس قبل/بعد، وتمنع أي
ترقية إلى المرحلة التالية عند انقطاع شهادة سابقة لازمة للدعوى المحددة.

الفريق المطلوب يغطي هندسة اللغة/البيانات، والتحقق بـLean، والنموذج والقياس،
ومراجعًا مستقلاً لا يختار النماذج على مجموعة الاختبار التي يحجبها.
