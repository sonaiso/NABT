# وكيل العوامل والإسناد — الإصدار الأول

يمتد هذا العمل من `grammar-catalog awamil` ويستعمل الاسترجاع الموجود، ونموذج
`tools.lexical_training.model.Retriever`، وقارئ الخطاب وشهادات الإسناد الموجودة.
يرتبط بالهدف `lang.awamil` في منهاج التعلم الحالي. لا ينشئ نحوا أو محرك إسناد موازيا.

## ما ينفذ

- فهرس مستقل لهويات الجرجاني المئة، بإحالات صفحات الجرد وبصمة النسخة، وتقسيم ٩١/٧/٢.
- فهرس مستقل لصفوف جدول NABT المئة، مع البدائل الإعرابية وروابط العلامات وصاحب الفحص.
- ١٢ بطاقة مصدرية للعلاقات والتراكيب؛ تسترجع نصوص الشواهد من فهرس الكتب الموجود.
- جواب عربي مستند إلى البطاقات، مع هوية كل إحالة والعمل المشروط حيث يقدمه الجدول.
- مصفوفة تنفيذية تحفظ كل تحليل مستقل ومواضع أطرافه ونطاق دعواه ونواقصه.
- مسار `analyze` يجمع الشواهد المسترجعة وتطبيق القارئ وجوابا بأطراف الإسناد؛
  لا يقلص حد العرض في الاسترجاع فضاء تحليلات القارئ.
- منهاج يولده الوكيل من ١٠٠ وحدة مرقمة، ويقدم وحدات الخطأ المقاسة في مجموعة التطوير.
- تدريب فعلي على ترتيب بطاقات القائمتين والعلاقات، وحفظ الأوزان والنتائج لكل هوية.

رقم العامل لا يطابق رقم صف الجدول تلقائيا: `jurjani:001` هو الباء، و`nabt:001`
هو إنّ. المطابقة اللفظية في `crosswalk` مرشحات تحتاج مراجعة الاستعمال؛ تحفظ
الهويات المتشابهة، والصفوف التي لم تطابق، وتبقى `equivalence_established=false`.
شاهد تعداد العامل لا يستوفي جميع شروط عمله أو يثبت التعرف عليه في نص حر.

## مصفوفة العلاقات

رأس الإسناد هنا **مرساة المحمول في التحليل المختار**. العامل وحاضن التعلق حقول
مستقلة. هذا تعريف لواجهة العرض، وليس حكما بأن جميع المدارس تتبنى رأس شجرة واحدا.
التضمين في هذه المصفوفة احتواء تركيب داخل نطاق تركيب آخر؛ لا يتحول إلى دلالة
التضمن الأصولية أو إلى استلزام منطقي. تحفظ تلك العقود في أصحابها الحاليين.

| التركيب | المسند إليه | المسند والرأس | العلاقة وما يجب حفظه |
|---|---|---|---|
| الجملة الاسمية | المبتدأ | الخبر | إسناد، مع ربط الأطراف بمواضعها |
| الجملة الفعلية | الفاعل أو نائب الفاعل | الفعل | إسناد؛ المبني للمجهول لا يعاد تأويله فاعلا |
| كان وأخواتها | الاسم | الخبر، والناسخ مستقل | الإعراب والزمن والنفي |
| إن وأخواتها | الاسم | الخبر، والناسخ مستقل | شروط التفعيل وموانعه |
| ظن وأخواتها | المفعول الأول في القضية المضمنة | المفعول الثاني داخل النطاق | لا يستخرج مضمون الظن حقيقة مستقلة |
| الصلة | مرجع العائد | محمول الصلة داخلها | لا يحل محل خبر الجملة الخارجية |
| شبه الجملة | ما يحدده الإسناد الحاضن | المركب الذي عينه القارئ | التعلق والمحل؛ لا يختلق فعل محذوف |
| النعت | المنعوت | الصفة التابعة | التقييد والمطابقة؛ لا يصير خبرا مستقلا |
| الإضافة | المضاف | المضاف إليه تابع، والرأس هو المضاف | التقييد؛ لا تفترض الملكية |
| الحال | صاحب الحال | الحال مرتبط بالحدث | نطاق الحدث وصاحب الحال |
| التمييز | المميز | تابع يرفع الإبهام | نوع النسبة أو المقدار |
| المقاربة | الاسم | جملة الخبر المضمنة | يبقى الحدث تحت المقاربة |

يعرض كل صف `analysis_id` و`frame` و`force` والأطراف و`claim_path` عند وجوده،
ويحفظ `claims` و`assignments` و`relations` و`obligations` كاملة. إذا لم يقدم
القارئ ربطا للرأس يبقى `NO_PREDICATION_BINDING`. لا تختار درجة النموذج تحليلا
لغويا مقبولا من بين البدائل. إعادة الفحص تعيد القارئ على **مدخلات مستقلة** وتطابق
المصفوفة كاملة؛ تعديل الرأس أو النص أو سحب المعجم يفشل المطابقة.

## التدريب والقياس

البيانات مؤلفة ومعلنة، وليست امتحانا لغويا مستقلا. لكل بطاقة أربعة أسئلة تدريب
وسؤالا تطوير وسؤالا اختبار من قوالب مختلفة: ٨٤٨/٤٢٤/٤٢٤. لا تظهر معرفات الإجابة
في السؤال. عند تطابق نص بطاقتين في القائمتين يعامل التدريب كلتيهما إجابة صحيحة،
بدلا من جعل إحداهما مثالا سلبيا زائفا. لا يدخل مفتاح الاختبار في اختيار الأوزان.
اختيرت الدورة الثالثة بخسارة التطوير من ٣٠ دورة و٢١٠ تحديثات للمحسن؛ تغيرت
الأوزان بالفعل بمقدار L2 نحو ٧٫٠٩٤.

النتيجة الأولى المحفوظة في `evidence/awamil_agent_v1/run_01/report.json`:

| القياس على ٤٢٤ سؤال اختبار | البحث BM25 | النموذج المتعلم وحده |
|---|---:|---:|
| إصابة المرتبة الأولى | ٩٥٫٥٢٪ | ٣٨٫٢١٪ |
| وجود جواب صحيح ضمن خمسة | ١٠٠٪ | ٦٩٫١٠٪ |

هذه أرقام **استرجاع بطاقات بقوالب أسئلة جديدة**، ولا تقيس النقل إلى جذور غير
مرئية أو إعراب نصوص حرة أو تطبيق جميع شروط العوامل. سجل كل هوية محفوظ، بما فيه
الإخفاق. يظل `application_mastered=false` لكل وحدة حتى قياس تطبيقها بشاهد مستقل.

تعيد أداة تحميل النموذج حساب بوابة التطوير ولا تثق بعلم نجاح مكتوب في ملف الأوزان.
لأن النموذج أضعف في التطوير، لا يدخل ترتيبه في البحث الهجين الحالي؛ يبقى البحث
النصي والحرفي عاملا، وتفيد أخطاء النموذج في ترتيب المنهاج. تمرير `--model` يعرض
هويته ونتيجة بوابة الاعتماد. النتائج أعلاه للمقارنة التجريبية BM25/النموذج منفردين،
وليست قياسا شاملا لكل سؤال قد يرد إلى واجهة RAG.

الأوزان أعداد JSON محدودة الحجم، دون pickle أو تحميل شيفرة نموذج خارجية. يرتبط
تحميلها بهوية الفهرس والبيانات وأبعاد النموذج. التوليد عربي مقيد بالبطاقات؛
التنفيذ محصور في أصحاب الوظائف، وليس في تعليمات مسترجعة من النصوص.

## التشغيل

من جذر المستودع، مع `PYTHONPATH=src:.`:

```bash
python -m tools.grammar_catalog awamil catalog --output /tmp/awamil-catalog.json
python -m tools.grammar_catalog awamil answer 'ما عمل إنّ وأخواتها' --collection nabt
python -m tools.grammar_catalog awamil answer 'الجملة الفعلية الفعل والفاعل' --collection relations
python -m tools.grammar_catalog awamil curriculum --output /tmp/awamil-curriculum.json
python -m tools.grammar_catalog awamil check --request examples/awamil_agent/case.json
python -m tools.grammar_catalog awamil analyze --request examples/awamil_agent/nominal.json
python -m tools.grammar_catalog awamil matrix --request examples/awamil_agent/nominal.json --output /tmp/awamil-matrix.json
python -m tools.grammar_catalog awamil matrix --request examples/awamil_agent/nominal.json --verify /tmp/awamil-matrix.json
```

التدريب اختياري الاعتماد على PyTorch، ولا يضيف تبعية إلى نواة NABT:

```bash
python -m pip install numpy==2.3.5
python -m pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
python -m tools.grammar_catalog awamil train --run-dir artifacts/local/awamil-new-run
python -m tools.grammar_catalog awamil answer 'إنّ وأخواتها' --model evidence/awamil_agent_v1/run_01/model.json
```

يرفض التدريب إعادة الكتابة على مجلد موجود. التشغيل الجديد ينتج `model.json`
و`report.json` و`curriculum.json`. المنهاج بعد التدريب يتكيف من **أخطاء التطوير**
فقط؛ لا يستعمل أسئلة الاختبار لاختيار درس المراجعة أو درجة الإتقان.

`check` يقبل `nabt:NNN` وتعيينات الأدوار الصريحة؛ نجاحه حساب مشروط فقط. لا ينسب
علامة معطاة من المستخدم إلى وقوع مشاهد. `matrix` يقبل النص، ومعجما تعليميا بصيغة
TSV وسياقا اختياريين. هذه مقدمات معلنة؛ أمثلة المستودع لا تتحول إلى معجم عام.

## إعادة الاستعمال والتحقق

- تعداد الجرجاني: `tools.mantuq_mafhum.load_awamil_inventory/audit_inventory`؛ المطابقة
  مع `Nabt.AwamilInventory` يجريها `classicalSemanticProbe` في مسار CI الأصلي.
- جدول العمل: `nabt.governors` و`Nabt.Governors`، من دون تغيير القوانين.
- الإسناد: `nabt.discourse` و`claim_bindings` وأصحاب التراكيب الحاليون.
- الاسترجاع: `SearchIndex` الحالي، وإعادة إحضار البطاقات المثبتة محليا.
- التعلم: `tools.lexical_training.model` و`features`؛ `lang.awamil` ووكيل `awamil`
  في `evidence/cognitive_curriculum_v1/learning_framework.json`.

فحوص الانحدار تغطي هوية القائمتين، المتشابهات، الحركات، المصدر المتغير، الأثر
الإعرابي المخالف والناقص، حفظ نطاق الظن والصلة، تعلق شبه الجملة، تعديل الرأس،
سحب المعجم، تحديث الأوزان فعليا، وإعادة تحميلها ورفض ترفيع النموذج الأضعف.

المراجع التقنية التي راجعت أثناء التنفيذ:
[إعادة الإنتاج في PyTorch](https://docs.pytorch.org/docs/stable/notes/randomness.html)،
[حدود تحميل الأوزان](https://docs.pytorch.org/docs/stable/notes/serialization.html)،
[بحث التفريق بين المتشابهات بالحركات](https://aclanthology.org/W19-4606/).
أرقام الشواهد اللغوية ونصوصها تأتي من الفهرس المثبت في المستودع، لا من نتائج البحث العامة.

يتصل تدريب الاسترجاع الآن بمسار مستقل يقيس العمل داخل جملة مضبوطة ويعرض شاهد المعمول في البوابة. [تدريب العوامل من وقوعها في الجملة](AWAMIL_OCCURRENCE_AR.md)
