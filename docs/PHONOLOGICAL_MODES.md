# المسار الرمزي للابتداء والوصل والوقف — الإصدار الأول

أضيف مسار مستقل يميز الرسم المحفوظ عن التحقق الرمزي، وعن التسجيل الصوتي. له بداية (`ibtida` أو `wasl`) ونهاية (`wasl` أو `waqf`) مستقلتان؛ فقد يُبتدأ بالكلمة ويوقف عليها في الحدث نفسه. النجاح هنا لا يثبت جودة نطق مسموع، ولا حصر العربية أو لهجات سيبويه.

## المنفذ وحدوده

`nabt.phonological_modes.realize` يقرأ **معرّف شاهد محللًا من جدول مثبت داخل الحزمة**، ولا يستنتج تحليل الكلمة من نص خام، ولا يقبل وسمًا خارجيًا مرخّصًا. الجدول يضم 20 تحليلًا مؤلفًا لشواهد المصدر، و20 مقطع مصدر محفوظًا ببايتاته؛ بعض المقاطع حصر بحثي لم ينفذ حكمه بعد. ضبط الشواهد وتقسيمها الرمزي تفسير لغوي معلن، وليس من النص الأصلي المشكول ولا من تسجيل صوتي.

```python
from nabt.phonological_modes import realize, realize_imperative_onset

realize("idrib", start="wasl")
# written_form = "اِضْرِبْ"; alternatives[0].segments = ["ḍ", "r", "i", "b"]

realize("yaqul_jussive", following_id="alqawm")
# ["y", "a", "q", "u", "l", "i"]؛ لا تعود الواو أو ألف مد.

realize("irmi", end="waqf", profile="sibawayhi_attested_options")
# [ʔ,i,r,m] و[ʔ,i,r,m,i,h] محفوظان بديلين مستقلين.

realize_imperative_onset("اُكْتُبُوا", lexical_model=model,
                        profile_id="2MP", start="wasl")
# يعيد الاشتقاق من model؛ onset_segments=[] والبقية كْتُبُوا محفوظة.
```

الواجهة الأخيرة قانون قابل لإعادة الاستخدام لكل صيغ المخاطب الست في مجال الأمر السالم المثبت في النظام: `2MS/2FS/2MD/2FD/2MP/2FP`. تعيد `person_candidates` ولا تثق في مرشح يرسله المستدعي. وهي **إسقاط بداية فقط**: تبقي البقية بوصفها حروفًا عربية مرصودة وتعيد `end="unprojected"`؛ فلا تحول ألف الجماعة إلى صوت ولا تزعم تحليل المقطع أو الوقف على كل لاحقة. لا يمنح المصدر القرآني المعجمي حكم قراءة قرآنية للنطق الناتج.

الملف `phonological_modes_v1.json` مثبت ببصمة في وحدة Python ويُعاد فحصه مع جميع بايتات المصدر كل استدعاء. `UNKNOWN` يعني خروج الطلب عن مجال الشاهد/العملية، و`NabtError` للمدخل المشوه أو الحدود المتناقضة؛ إخفاق إعادة المصدر هو `INSTALLED_CONTRACT_FAILED/DEFER`. هذه نتائج مختلفة عن رفض عربية الكلمة.

- `standard_core`: إسقاط مختار ضيق؛ ليس وصفًا كاملًا للفصحى المعاصرة.
- `sibawayhi_attested_options`: يضيف بديلَي الوقف على الأمر المعتل في الشواهد المحددة فقط. لا يعني جميع لهجات الكتاب.
- لا توجد سمة «مرخص سمعيًا». جميع النتائج تحمل `acoustic_validation=False` و`complete_for_arabic=False`.
- إشمام الوقف عند سيبويه حركة شفوية مرئية؛ إثباته لا يستخلص من ملف صوت وحده، ولا من Unicode.

## الأدلة الرياضية وقياس الإنجاز

`formal/Nabt/PhonologicalModes.lean` يحتوي 17 مبرهنة، منها حفظ بايتات المصدر والرسم وسجل المحذوف، أثر همزة الوصل، بقاء بديلَي هاء السكت، وأن إضافة كسرة الاتصال لا تغير الجسم السابق وتزيد عنصرًا قصيرًا واحدًا فقط. كما يثبت مثالًا صريحًا أن الوقف وحده لا يسترجع حركة الإعراب المحذوفة. هذه مبرهنات عامة على الأنواع المعرفة؛ صدق تفسير النصوص وملاءمة الرمز للنطق التزامان خارجيان، ولا تخفيهما المبرهنات.

`ExportPhonologicalModes.lean` يصدر كل مفاتيح التحكم الحالية: 8 بدايات و64 نهاية. `tools/check_phonological_modes.py` يقارنها بالتنفيذ، ويرفض حذف/تكرار الصفوف، ويفحص تركيبها في 160 حالة حدود للشواهد العشرين. هذه **مطابقة تنفيذ للنموذج** وليست 160 شاهدًا عربيًا مستقلًا. الاختبارات العشرون تتضمن أمثلة ومضادات مستقلة في صياغتها، وتغطية profiles المخاطب الست، وسحب المصدر.

مقاييس قابلة للمراجعة دون تضخيم:

| المقياس | المقام الصحيح | ماذا لا يقيس |
|---|---|---|
| مراجعة القانون | التزامات P01–P32 المثبتة في هذا الحصر | اكتمال كل قواعد سيبويه |
| سلامة المصدر | 20 مقطعًا: بصمة + بايتات + مواضع | صحة التفسير المؤلف أو استقلال النسخ |
| صحة النواة | 17 مبرهنة في المجال المعلن | قبول كل تركيب عربي |
| مطابقة التحكم | 72 مفتاح تحكم مولدًا من Lean | دقة لغوية خارج العينة |
| تركيب الشواهد | 20 × 2 بداية × 2 نهاية × 2 profile = 160 | 160 شهادة أصلية |
| اختبار لغوي خارجي | يجب إعداد مجموعة محجوبة بحسب أبواب/أسر مصدر مختلفة | لا تعوضه شواهد التطوير |
| اختبار سمعي | تسجيلات مستقلة ومحكّمون وتقطيع زمني معلن؛ غير متوفر هنا | لا يستنتج من نجاح Python أو Lean |

المقياس السمعي المستقبلي يفصل خطأ إدراج/حذف الهمزة، وخطأ نوع/طول الحركة، وخطأ حدود المقاطع، ونسبة البدائل المرخصة المسترجعة، ونسبة بدائل غير مرخصة. يُقسّم التدريب والاختبار بالمؤلف/النص/السياق والمتكلم، وتفصل القراءة القرآنية باسم القارئ/الرواية عن الفصحى المعيارية. الإشمام يحتاج قناة مرئية مستقلة. لا توجد قيمة صفرية مصطنعة للخطأ عند غياب هذا الاختبار.

أوامر الإعادة:

```bash
PYTHONPATH=src:tests python -m unittest test_phonological_modes -v
cd formal
lake build exportPhonologicalModes
cd ..
python tools/check_phonological_modes.py
```

عند تعذر Lake يمكن تشغيل النسخة المثبتة من Lean مع `LEAN_PATH` صراحة، وبناء `Nabt/PhonologicalModes.olean` ثم `lean --run ExportPhonologicalModes.lean` وتمرير JSON إلى `--lean-export`. توثق بيئة التنفيذ الفعلية في تقرير الإصدار، ولا تعد نتيجة أمر لم يُشغّل ناجحة.
