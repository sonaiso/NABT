# دفعة الشواهد المعجمية عبر NTP

يسأل درس `ntl.dictionary-deposit.v1` عن قول معجم في مجموعة ألفاظ. ترسل الدفعة مرة واحدة عبر `ntp → cognitive.lesson`، وتُحمَّل مادة كل معجم مطلوب مرة في الدفعة. يرد لكل سؤال، بترتيبه، قرار وشواهده. توسع الدفعة عدد الأسئلة التي يجيب عنها المصدران المثبتان دون توقيع بشري لكل جواب. إدخال معجم آخر يتطلب قارئ مصدر مسمّى وإصدارًا مثبّتًا يراجعه المشروع.

| المدخل | ما يقيسه المالك | حدود الحكم |
|---|---|---|
| `mukhtar` | يفحص `dictionary_reading.resources()` بصمة مختار الصحاح وجدول ٣٩ قراءة وموضع كل شرح داخل مدخل جذره. تعيد `indices_for` القراءات الموافقة للرسم والضبط، بما فيها الأوجه المختلفة للعين. | النص المقتبس قولٌ مرتبط بالموضع. ربط الضبط بالمعنى وتصنيف المحور تحليل معلن في الجدول. |
| `maqayis` | يفحص `SourceLexicon.load()` هوية النسخة الكاملة من مقاييس اللغة ويعيد `lookup_exact` جميع كتل العنوان المطابق، مع حدود UTF-8 وبصمة كل كتلة. | الكتلة شاهد نصي. استخراج تعريف مستقل أو اختيار قراءة في جملة جديدة يحتاج إلى قارئ آخر. |

يقبل الطلب من استعلام واحد إلى ٦٤. سجل `withdraw_sources` يسحب المصدر من النظر في هذه الدفعة، ويمكن تفعيل المصدر مجددًا بإعادة طلب مستقل. وسماح الطلب بحجب مصدر لا يمنحه سلطة اعتماد مصدر بديل. `NOT_INDEXED` يصف نتيجة البحث في الجرد المعين. تميّز الصفوف بين خلو الجرد والسحب وتعذر قراءة الملف وتغيّر بصمته والمدخل غير الصالح. إذا تجاوزت كتل عنوان في مقاييس اللغة ١٦٣٨٤ بايتًا مجتمعة ينتج `ROW_RESOURCE_LIMIT` لذلك الاستعلام. وتبقى الشواهد البديلة مجتمعة في كل نتيجة مقبولة.

## التشغيل

الطلب [ntl_dictionary_deposit.json](../examples/io_gateway/ntl_dictionary_deposit.json) يتضمن ٤٩ استعلامًا. يُحفظ الطلب المستقل وتُعاد البوابة عليه لفحص الإيصال قبل استهلاكه.

```sh
PYTHONPATH=src:. python -m tools.ntp run --request examples/io_gateway/ntl_dictionary_deposit.json --output /tmp/dictionary-receipt.json
PYTHONPATH=src:. python -m tools.ntp verify --request examples/io_gateway/ntl_dictionary_deposit.json --receipt /tmp/dictionary-receipt.json
PYTHONPATH=src:. python -m unittest tests.test_dictionary_deposit -v
```

يمكن للمستهلك بعد تحقق `valid=true` أن يقرأ `execution.owner_result.owner_result.rows`. داخل قراءة مختار الصحاح يُعاد بناء المنقول من بايتات الملف عند `citation.gloss_span`. وفي مقاييس اللغة يُعاد من `start_byte` إلى ما قبل `end_byte`. يحتفظ الإيصال ببصمة المصدر، وتعني `SOURCE_ATTESTED` وجود نص مطابق ضمن الطريقة المحددة. يُفحص وقوع مدلوله في العالم في مسار مستقل. تحتفظ النصوص المقتبسة بشروط بيانات OpenITI المنشورة مع المصدر.
