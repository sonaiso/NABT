# وحدة المفهوم والتعلم المشترك — التنفيذ الأول

هذه الدفعة تصل التعريف الذي يستعمله مالك الدلالة نفسه بالتصدير والتعليم
والتنبؤ العصبي. لا تنشئ مفهومًا جديدًا عند الانتقال من المعرفة إلى المنطوق
أو طرق الاستفادة، ولا تدمج معاني متباينة لمجرد اشتراك اللفظ.

## العقود والمالكون

`Nabt.ConceptContinuity` يستعمل `SourceSemantics.Formula/ConceptDefinition/Binding`،
ويصل معنى مكونات المعجم بقانون `LexicalDenotation` وبسلامة `MantuqMafhum.infer`.
البراهين الاثنا عشر مشروطة بصدق المقدمات وقواعد الانتقال المطلوبة؛ ليست
برهانًا على استخراج تلك المقدمات من العربية الحرة أو مطابقة بايثون وLean كلها.
تعريف العدد يستعمل مجال `nabt.cardinal.nonnegative-integer.v1` الموجود.
وجود تعريف «10» لا يثبت أن الموجودات المعدودة عشرة.

مالك `lexicalDenotation --concepts` يصدر التعريفات الأصلية الثمانية عشر.
المعرف هو معرف المعنى الموجود، ومعه بصمة تعريف تميز تغير المحتوى. المنظور
والمجال ليسا جزءًا من الهوية. تبقى الفروق بين معاني «قلم»، وبين تفسيرين
منسوبين إلى مصدرين، إلى أن يوجد شاهد لمحاذاتهما. التصدير OntoLex يستعمل
التعريف نفسه، ويحفظ شروط الالتزام وشواهدها كاملة في عقدة الدلالة.

`nabt.cognitive-lesson.v2` يوجه العمل باسم العملية وعقدها وشواهدها. أسماء
المصفوفات مناظير تعليمية؛ يمكن للتعلم المكتسب أن يدخل منظور `mafhum` مع
بقاء سجل التعلم والمراجعة. `policy_id` لا يتغير باسم المنظور؛ شروط القياس
والموافقة والمخالفة تبقى لدى فاحصها. الإصدار الأول محفوظ لإعادة التشغيل.
بصمة العملية تشمل كامل الحمولة والشروط، ولا تشمل اسم المجال أو المنظور.
السجل يشير إلى نتيجة المالك وتاريخ سحب الأدلة الأصليين. هذا لا يدعي أن
كل محمول يستخرجه القارئ اكتسب بالفعل محاذاة معجمية عامة.
ويتضمن الدرس v2 ملاحظات الشبكة للنصوص الأصلية في عقدي التعلم والاستدلال:
المصدر وبصمته وموضعه وتنبؤات الرؤوس كلها متصلة بالسجل نفسه. لا تعاد كتابة
المقدمات بتنبؤ النموذج، ولا يزيل سحب الشاهد المعرفة المعجمية أو تاريخ
التنبؤ؛ صلاحية الحكم الحالي تبقى عند مالك الأدلة. حد الشبكة ثمانية نصوص
و256 بايتًا لكل نص؛ تحفظ النصوص الأطول كاملة مع تعليق المرحلة العصبية.

`rag_views.inventory` يشتق 18 منظورًا متقاطعًا من سجل المالكين الحالي،
بمساراتهم وبراهينهم واختباراتهم والتزاماتهم المفتوحة. هذه المناظير ليست
18 قاعدة مفاهيم منفصلة، ولا يلغي عددها مصفوفات المنهج الـ19 الموجودة.

## شبكة فعلية واحدة

المشفر GRU يقرأ بايتات UTF-8 بترتيبها دون حذف الحركات أو تطبيع النص.
يمتلك 6,695 معاملًا وخمسة رؤوس تشترك في الحالة المخفية نفسها:
القراءة، الصرف، المفهوم، التعلّق، ونوع الشاهد المطلوب. رأس المفهوم يستعمل
معرفات وتعريفات المالك الأصلي، ويعيد جميع البدائل مرتبة.

التدريب يستعمل 94 عينة و100 خطوة تحديث مشتركة. تحصيل المعجم يعيد استخدام
`lexical_training.acquisition.dataset` وشواهده؛ الأمثلة الصرفية مؤلفة
ومعلنة المصدر. الجذور الصرفية المحجوبة «كتب، غسل» و«قمتُ/قمتَ/قمتِ» لا
تدخل تدريب الصرف. «كتب» حاضر في تعريف معجمي، لذلك لا ندعي أن كامل الجذر
غير مرئي لجميع مهام النموذج. اختبار المعنى مؤلف ومكشوف سابقًا، ويقيس
سياقات لمعانٍ معلومة؛ لا يقيس اكتساب مفاهيم جديدة أو تحكيمًا دلاليًا مستقلًا.

الأوزان النهائية محددة قبل تقييم الاختبار، ولا يوجد اختيار حقبة بحسب نتائجه.
تُحفظ بيانات التدريب والاختبار والتنبؤات ونتيجة أول قياس. لا نخفي الإخفاقات
بمتوسط مجمع:

| الرأس | المشفر قبل التدريب | الشبكة المدربة | أقرب نص بالبايتات |
|---|---:|---:|---:|
| القراءة | 2/27 | 27/27 | 26/27 |
| الصرف | 3/27 | 27/27 | 26/27 |
| التعلّق | 7/27 | 27/27 | 26/27 |
| ترتيب المعنى | 1/18 | 9/18 | 8/18 |
| الشاهد المطلوب | 9/47 | 41/47 | 44/47 |

المقاييس ترتيب أول بديل ضمن المجموعة المعلنة. التعلّق هنا أربعة أصناف
محدودة، وليس تحليل اعتماد نحوي عام. الشاهد المطلوب تصنيف للمهمة؛ لا يولد
دليلًا. رأس الشاهد أقل من المقارنة البسيطة، ونصف اختبار المعنى ما زال
يخطئ في المرتبة الأولى. لا تُستنتج معرفة عامة من هذه النتائج.

حُفظ أثر UTF-8 كاملًا مستقلًا عن الحالة العصبية. الحالة العصبية ليست
ترميزًا ثبت أنه قابل للعكس. تشغيل النموذج لا يحتاج PyTorch: أوزان JSON
بأشكال وقيم محدودة وفاحص GRU ببايثون. قورن التشغيلان على الاختبار كله؛
أكبر فرق مطلق في الدرجات نحو `2.75e-6`. لا يستقبل العميل مسار نموذج،
ولا تصبح الدرجة شهادة معنى أو حقيقة أو إعراب. تغير تعريف المالك يبطل
اتصال النموذج حتى إعادة التدريب/المحاذاة؛ لا يُصحح المعرف صامتًا.

## الاستخدام والتحقق

المدخل الخارجي الوحيد هو بوابة NABT، ثم التحقق بطلب مستقل:

```sh
python -m tools.grammar_catalog gateway run --request examples/io_gateway/shared_neural.json --output /tmp/neural.json
python -m tools.grammar_catalog gateway verify --request examples/io_gateway/shared_neural.json --receipt /tmp/neural.json
make shared-cognition LAKE=/path/to/lake
python -m tools.lexical_training.shared_training --run-dir artifacts/local/new-shared-training
```

المسارات الجديدة `concept.view` و`concept.matrix` و`neural.propose` تستخدم
الفهرس الحالي للبراهين والاختبارات. تؤخذ بصمة الأوزان مع مصادر التنفيذ
قبل التشغيل وبعده. قبول إعادة التشغيل لا يرفع رتبة الحكم الدلالي.
