# انتروبيا الشيفرة وترابط NABT

أُنجز هذا التدقيق في 2026-10-28 على أساس `a14332afb934bedd4f35bf2fb3d34c9004df52b7`
(دمج PR 53)، وتطبيق `180c198d233a6bf90f1968d6958a6771d234a7d2`.
تسبق [مواصفة القياس](CODE_ENTROPY_CONTRACT.md) التنفيذ. النتيجة العملية هي
**قياس قابل للإعادة، وحارس معماري، وسياسة تجميد موحدة، وترتيب بناء يمنع
التجميد قبل جاهزية الملفين التنفيذيين المقاسين**. لم يتغير القانون اللغوي
ولا نواة Lean، ولم يُعدّل Mashru.

## ما المقصود بالانتروبيا هنا؟

لكل وحدة Python نعد علاقات استيرادها الداخلية المختلفة، ثم نعرّف
`p(v) = outdegree(v) / E` و`H = -Σ p(v) log₂ p(v)`.
المقام `E` هو عدد الحواف الموجهة المختلفة، وليس عدد الأسطر أو الكلمات أو
المبرهنات. إذا انعدم المقام تبقى القيمة غير مقاسة. زيادة `H` أو نقصها لا
تثبت تحسنًا هندسيًا أو لغويًا؛ توزيع أكثر تساويًا للاعتماد قد يخدم تصميمًا
وقد يضر تصميمًا آخر.

الطوبولوجيا هنا طوبولوجيا **رسم اعتماد منتهٍ**: مكونات قوية، ومكونات ضعيفة،
ودرجة اعتماد، ورتبة دورات للإسقاط غير الموجه البسيط `Eᵤ − V + C`.
لا نساوي هذه الرتبة بعدد الدورات الموجهة أو بوجود دور منطقي في برهان Lean،
ولا ندّعي قياس فضاء الدلالات العربي. تحفظ الأداة حدود المجتمع والمحلل
وبصمات الملفات والمواضع والقيود داخل كل نتيجة.

## القياس الفعلي قبل التعديل وبعده

المجتمع هو ملفات Python المتتبعة تحت `src/nabt/` و`tools/` و`integrations/`،
مع استبعاد مسارات `tests`. قرأ المحلل بايتات شجرتي Git الثابتتين، ولم
يستورد الوحدات التي يحللها. استُعمل الإصدار نفسه من أداة القياس للمقارنتين.

| القياس | الأساس | التطبيق |
|---|---:|---:|
| ملفات المجتمع | 265 | 266 |
| الأسطر الفيزيائية | 62,914 | 63,290 |
| الحواف الداخلية الموجهة المختلفة | 557 | 557 |
| وحدات لها حواف خارجة | 195 | 195 |
| إنتروبيا توزيع الحواف، بت | 7.141354 | 7.141354 |
| مكونات قوية متعددة الوحدات | 3 | 3 |
| رتبة دورات الإسقاط غير الموجه البسيط | 337 | 337 |
| استيرادات النواة من الأدوات/التكامل | 0 | 0 |
| مجموعات تطابق AST الحرفي | 23 | 23 |
| وقوعات هذه المجموعات | 71 | 71 |

أضاف التدقيق أداة، ولم يزعم خفض التعقيد بعدّ الأسطر. إصلاح سياسة التجميد
يمنع اختلاف تعريف المدخلات الملزمة؛ هذا تكرار في **المسؤولية** لا يلزم أن
تلتقطه مطابقة AST الحرفية. بقي استقلال النواة قائمًا وأصبح له حارس CI
يمنع حتى الاستيراد الحرفي لأسماء أدوات لم توجد بعد في المجتمع.

المكونات الثلاث هي:

- `counting ↔ nominal`.
- `construction_complements / construction_reader / discourse_reader`.
- `arabic_reader / governor_reader / semantics`.

لا يحتوي إسقاط عبارات الاستيراد المباشرة في جسم الوحدة على دورة موجهة؛
تدخل حواف محلية أو متداخلة في المكونات أعلاه. لا يثبت ذلك سلامة كل ترتيب
تحميل: الرسم لا يشمل تهيئة الحزم الضمنية، أو الاستيراد الديناميكي، أو
العمليات الأصلية، أو اعتماد البيانات. تسجل الاستيرادات الديناميكية منفصلة
بكشف محدود معلن. ولا نجمع أطوال نسخ الدوال باعتبارها أسطرًا قابلة للحذف:
قد تتداخل المقاطع، وتوجد نسخ تاريخية ومراجع مستقلة يجب الحفاظ عليها.

## إصلاحات الترابط المنفذة

### قائمة مدخلات واحدة للتجميد والتحقق

كان المنشئ يجمد ملفات Lean والأدوات والاختبارات وسلاسل المصدر، بينما
كان المتحقق يفرض مجموعة أضيق. صار الاثنان يستخدمان سياسة واحدة داخل
تمهيد المقيم الموثوق بالفعل. تعتمد القائمة على اتحاد شجرة الالتزام
المسمى والفهرس المتتبع؛ حذف ملف من الفهرس أو إضافة ملف جديد لا يسقطه
صامتًا من متطلبات التحقق. تُقرأ روابط المصدر من سجل الالتزام بقراءة JSON
ترفض تكرار المفاتيح، وتظل بصمات البايتات والمصادر وإعادة التنفيذ الأصلية
فحوصًا مستقلة. لا يمنح اتحاد القوائم ملفًا غير ملتزم سلطة تنفيذ.

تختبر الحالات المضادة حذف ملف Lean، أو أداة، أو اختبار، أو بيانات، أو
أداة البناء، أو شاهد مصدر، وتغيير سجل المصدر وحذف ملف مرحليًا. يرفض
المقيم نقص الملفات قبل استيراد التنفيذ. هذا تحقق عضوية وهوية، وليس
عزلًا ذريًا من كاتب متزامن معادٍ.

### ترتيب البناء ثم القياس

صار هدف `aligned-acquisition-evaluation` يستدعي جاهزية Lean والملفين
الأصليين، ثم اختبارات المطابقة، ثم تكامل PR 34، ثم التجميد والتقييم.
تتحقق اختبارات أوامر بديلة من هذا الترتيب مع `make -j8` ومن منع التجميد
إذا فشل البناء. تشمل السلسلة إعادة بناء `licensedInference` في بوابته
المضمنة؛ لا تدعي منع كل كاتب خارجي أو عزل جميع الأهداف التاريخية المتوازية.
يستخدم CI هذا المدخل الواحد ويحتفظ بنتيجة التدقيق والقياس.

### حفظ تاريخ البرهان

صححت إرشادات فهرس البرهان لتفصل لقطة 1,372 تصريحًا التاريخية عن المرجع
الحالي ذي 1,504 تصريحات و1,501 مجموعة عبارات. تُولد النتائج محليًا،
ويختار ملف التكامل الحالي مراجع البرهان وروابط القواعد معًا. لم تُمحَ
اللقطات القديمة ولم تُدمج نسخ الأدلة المستقلة لتجميل مقياس التكرار.

## التحقق المنفذ

نجح الاختبار الشامل: **2,477 اختبارًا ناجحًا و63 متجاوزًا** من أصل 2,540،
مع رمز خروج صفر وخاتمة تشغيل كاملة. نجحت بوابات Lean والفهارس وروابط
المصدر والاستدلال، ومنها **683/683** لمطابقة PR 34. يحتفظ تشخيصه المكشوف
بنتيجة **37/38** وفجوة المفردة الموثقة؛ ليست كل المقاييس نجاحًا كاملًا.

أعادت المصفوفة الأصلية **72/72** من توقعات التمثيل و**37/37** من مصفوفات
الخلايا، وبقي تحصيل الأهداف الموجبة **32/47**. بقيت الأهداف اللاحقة الـ48
غير مقاسة بعقد هدف دقيق، ومنها 29 هدفًا موجبًا يمثل نقص تغطية. ونجح
انحدار التركيب في **12/12** عقدًا متوقعًا مع **5/12** سلاسل مكتملة فقط.

تجربة قائمة التجميد المستقلة أعادت **52/52** مشاهدة متوقعة: 13 حالة،
ومرحلتان، وتنفيذان مأخوذان من Git. كانت سبع فئات حذف تُقبل في الأساس
وأصبحت تُرفض. ملفاتها الأصلية اصطناعية لا تُنفذ، وبصمات المواصفة
والمرجع مضبوطة على الشاهد الاختباري؛ لا تُحسب هذه التجربة تغطية عربية.

## إعادة القياس وحدود النتيجة

توجد المقارنة وبيانات الترابط والسجلات وبصماتها في
[`evidence/strategic_entropy_v1/`](../evidence/strategic_entropy_v1/).
تحتفظ النتائج بقياسات المجتمع الأصلي والمصفوفة المكشوفة منفصلتين؛ لا
تعامل امتناعًا عن هدف صحيح مطلوب بوصفه اكتسابًا له.

```sh
python tools/code_entropy.py --ref a14332afb934bedd4f35bf2fb3d34c9004df52b7 --output artifacts/local/entropy-new/before.json
python tools/code_entropy.py --ref 180c198d233a6bf90f1968d6958a6771d234a7d2 --check --output artifacts/local/entropy-new/after.json
python evidence/strategic_entropy_v1/reproduce_traceability.py --proof-reference evidence/aligned_acquisition_v1/integration/proof_catalog.json --output artifacts/local/entropy-new/traceability.json
make test
make -f tools/aligned_acquisition.mk grammar-catalog mantuq-inference linguistic-truth aligned-acquisition-evaluation LAKE=/path/to/lean-4.34.1-linux/bin/lake EVIDENCE_DIR=artifacts/local/entropy-new/replay
```

الأوامر التي تحفظ تقارير حصرية تحتاج مسارًا جديدًا. أداة الترابط الأخيرة
تستورد واجهات الفهرسة الموثوقة وتقارن لقطة مخزنة بمصادرها؛ لا تبني Lean
ولا تستمد سلطة من رسم الاعتماد. أمر Make المنفصل يعيد الفحوص الأصلية.
يسجل ملف التحقق بيئة التشغيل والتكييف المحلي لمسار أداة Lean. هذا ليس
إصدارًا، ولا تنفيذًا كاملًا لأمر `make check` للإصدار، ولا شهادة بنسبة
فهم للعربية. يبقى هدف التطوير التالي عقدًا لغويًا جديدًا وتجربة مستقلة،
لا نقل نتيجة القياس إلى علم `grammar_certified`.
