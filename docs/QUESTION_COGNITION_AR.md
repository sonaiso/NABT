# كيف يختار نبط المقدمات بحسب السؤال؟

يقبل قارئ النص سؤالًا مستقلًا عن المصدر. يحفظ إيصال البوابة كليهما ويعيد فحص القرار على المدخل نفسه. مثال تشغيل:

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog gateway read --text 'سيفتح الحارس الباب إذا وصل المفتاح.' --question 'هل نُسب استعمال الآلة إلى الفعل؟'
```

يبقى استعمال الآلة مفتوحًا وتُسند شرطية الوصول إلى الفعل عند السؤال عنها. ضع «بالمفتاح» مكان «إذا وصل المفتاح» وأعد السؤالين. نطاق الإسناد هو الفعل المستقبلي الموصوف. إثبات حصوله خارجيًا يحتاج شاهدًا آخر.

## قانون العملية

يحكم `nabt.question-cognition.v1` واجهة الأسئلة. يتلقى الرأس المتعلّم نص السؤال وحده. ترتب أوزانه الاحتمالات بوصفها مقترحات. تقبل البوابة صيغة السؤال كاملة وتتحقق من عملية الفحص، وتحتفظ بقرار مستقل عند غياب الأوزان. يقبل مسار العلاقات الحقل الاختياري نفسه. لا يغير السؤال النص الأصلي أو يلقن النموذج الجواب أو يغيّر القراءة التي يحصل عليها العملاء السابقون.

في الملف الذي يفسّر الإسناد المشروط توجد أربعة أطر معجمية مضبوطة للفتح والكتابة والرسم والقياس. تقبل كل جملة أربعة شواهد محلية كحد أقصى. تُفهم باء الأداة واشتراط الوصول ونفيهما في موضع مقيّد. نختبر ثماني قيم مركبة لمحاور الآلة والشرط والوقوع الخارجي. لكل سؤال نحتفظ بالمحاور الداخلة في حكمه، وبالتعارضات في المحاور الأخرى. عند وجود جوابين نعرض صورتين متوافقتين على المحاور المسؤول عنها. تحفظ الصورتان جميع القيم ذات الشاهد المتسق، ومنها القيم الواقعة خارج محور السؤال. إذا تعارض محور مستقل تُعرض قيمته غير محسومة وتبقى شهادتاه محفوظتين. عند ثبوت جواب واحد أو تعارض شواهده نفحص جميع المجموعات الجزئية من الشواهد ونحتفظ بكل مجموعة دنيا بالحذف. يبين السجل نتيجة سحب كل مقدمة من تلك المجموعة. يبقى تفسير الصيغة وربط الضمائم مقدمات ثابتة معرّفة في نطاق اللغة المصغّرة. لا يستنتج سحب الشاهد نفي القضية.

## ما الذي يستطيع المستخدم سؤاله؟

| مثال للسؤال | مادة الاختبار ومصدر الحكم |
|---|---|
| هل الوصول شرط للفعل؟ هل نُسب استعمال الآلة إلى الفعل؟ هل اجتمع الشرط واستعمال الآلة؟ هل وقع الحدث في الخارج؟ | الأطر المذكورة، مع مجالات الشواهد في بايتات النص الأصلي |
| ماذا يرث هذا المعنى؟ | لفظ معجمي مفرد مثل «النمرقة» أو سؤال شبكة التعريفات الأصلي مع سحب الشاهد. يحتفظ الجواب بكل قراءة وبرهانها |
| ما المشترك والفارق بين المعنيين؟ | `«برنية» أو «ركوة»`. نقارن كل زوج من القراءات على نوع العلاقة والعقدة معًا. غياب شاهد عن أحد التعريفين يترك النفي مفتوحًا |
| ما القراءة العرفية؟ ما القراءة اللغوية؟ | مثال «أعني بالدابة ذوات الأربع». نعيد فحص الاستعمال في الاصطلاح المسؤول عنه. إثبات عادة مجتمع أو عصر يحتاج بحثًا خاصًا ومصادر مستقلة |
| ما القيمة الحسابية؟ | التعبير نفسه كما كتبه المستخدم. يحتفظ الجواب بشجرة العمليات والإسقاط وإيصال الفاحص، بما فيه حالة القسمة على صفر |
| ما التغير المرصود؟ هل ثبت السبب الفيزيائي؟ | سلسلة رصد «الطور» أو غيره بصيغة سجل نبط. يحتفظ الجواب بالسجل وتعارضاته وحدود الفحص. الترتيب وحده يترك سبب التحول مفتوحًا |

## إعادة القياس

يدرّب `tools.lexical_training.train_question_ranking` مصنف بيرسبترون متوسط الأوزان، على أسئلة عربية مؤلفة وموسومة، بسمات الكلمات وثلاثيات الحروف. المقام في دقة المقترح هو عدد الأسئلة المميزة المرخّصة في التحدي، ويستبعد السؤال الخارج عن المجال. المقام في قياس قرار البوابة عدد الطلبات المعاد فحصها بما فيها التكرار والتحويل إلى مسار العلاقات. يمكن فحص خطأ المقترح منفردًا حتى إذا صحت القراءة النهائية.

```sh
PYTHONPATH=src:. python -m tools.lexical_training.train_question_ranking --output /tmp/mental-weights.json
PYTHONPATH=src:. python -m unittest tests.test_question_cognition
PYTHONPATH=src:. python -m tools.evaluate_question_cognition --output /tmp/mental-replay.json
```

تحتاج اختبارات الفواحص الأصلية إلى بناء `make io-gateway-build`. [التحدي](../evidence/question_cognition_v1/challenge.json) و[أسئلة التدريب](../evidence/question_cognition_v1/train.tsv) منفصلان. الحدود الحالية تشمل القراءة العربية المفتوحة، واكتساب الإطار الحدثي من نص جديد، واكتشاف قانون فيزيائي من قياسات، والتحقق من انطباق المفهوم على عين خارجيّة. هذه الشريحة لا تقيس أداء فهرسة بيانات ضخمة.

## معيار توليد السؤال والجواب وتقويمهما

يضيف `nabt.question-answer-cycle.v1` دورة اختيارية فوق مسار السؤال السابق. تقرأ البوابة المصدر وحده وتولّد أسئلة مرتبطة به، ثم تفكك صيغتها وتنتج أجوبة عربية وتقرأ كل جواب مرة أخرى. يحتفظ الإيصال بنوع المطلوب، وحامل الحدث وأطرافه، ونطاق الحكم، والمقدمات الكافية أو النماذج البديلة. يحدّد فاحص الإطار أو فاحص الحساب المسندَ المستقل لتقويم جواب جديد. ولا يدخل الجواب المقدّم في تحليل المصدر أو توليد الشواهد.

```sh
PYTHONPATH=src:. python -m tools.grammar_catalog gateway read --text 'سيفتح الحارس الباب إذا وصل المفتاح.' --question-cycle
PYTHONPATH=src:. python -m tools.grammar_catalog gateway read --text 'سيفتح الحارس الباب إذا وصل المفتاح.' --question 'في العبارة «سيفتح الحارس الباب»، هل يثبت النص اشتراط وصول «المفتاح» للفعل؟' --answer 'نعم؛ الشاهد «إذا وصل المفتاح».'
```

تقبل صيغة الطلب JSON الحقل `question_cycle: true` مع النص للتوليد، أو `question` و`answer` للتقويم. تخص هذه الدورة الأطر الحدثية الأربعة والحساب المحدود في المشروع. وتقبل الأسئلة الحدثية «نعم»، «لا»، «غير محسوم»، و«تعارضت الشواهد»، مع تعليل اختياري بصيغة «؛ الشاهد «…»» أو «؛ الاحتمالان موافقان للنص.». تُقبل شواهد متعدّدة، ويُعرض لكل اقتباس كل مواضع مطابقته. الصواب في دعوى حدثية والتعليل الكافي حكمان مستقلان. وللجواب المولّد جواب مقابل يُبيّن الفاحص هل ناقض الدليل أو تجاوز ما يسنده النص. تُفحص قطبية التعليل بالنسبة إلى النتيجة المقدّمة، وقد يكون الشاهد صحيحًا في نفسه ويبرهن عكس جواب صاحبه. ففي المسألة المفتوحة يظل جواب «نعم» غير مسند، وعند تعارض الشواهد يظهر أثر التعارض، وفي وجود شاهد نفي صريح يخالفه الإثبات. إذا خرج النص أو الجواب عن نحو هذه الشريحة، يظهر تعذر القراءة مستقلًا. مصدر مضاد يقلب الشاهد يُستخدم في اختبارات المعيار.

في الحساب يُستعاد نوع الناتج وقيمته أو سبب امتناع العملية من الفاحص الأصلي. يقبل المقوّم الكسور المتكافئة في نطاق الأعداد المعتمدة، ويميّز صدق المساواة من قيمة عددية. سبب `NATIVE_REPLAY` يعني أن الفاحص أعاد الحساب؛ ولا يعني أن المستخدم قدّم برهانًا حسابيًا.
