# تركيب الدلالات المعجمية واكتمالها النسبي

هذه الإضافة تنفذ القانون `nabt.lexical-completion.v1` فوق حساب الدلالة
`nabt.lexical-denotation.v1` وتعداد القراءات `nabt.reading-enumeration.v1`.
توسّع الدليل من 18 قراءة وقاعدتي لزوم إلى **42 قراءة، منها 41 مفسرة
وقراءة واحدة غير محسومة، وثلاث قواعد لزوم ذهني**. تشمل 30 فهرس مادة.
لم يثبت اكتمال العربية كلها، ولا التواتر، ولا صحة الوقائع الخارجية.

## المنفذ والحد الفاصل

| الطبقة | النتيجة الحالية | ما لا يثبت بها |
|---|---|---|
| النقل | مقابلة اقتباسات الكتالوج كله ببايتات الملفات الثلاثة المثبتة | صحة نسبة كل نص تاريخيًا أو تواتره |
| الفهرسة | إعادة استعمال فهرس المصدر الكامل: 9882 مقطع عنوان في لسان العرب و5605 في المقاييس | أنها 15487 كلمة أو معنى محققًا؛ تشمل عناوين أقسام ومواضع تحتاج مراجعة |
| التفسير | 41 تفسيرًا مؤلفًا وواحد غير محسوم؛ لا تجزئة تلقائية لكل كلمة في الشرح | تحكيم لغوي مستقل أو استنفاد معاني كل مادة |
| الدلالة | المطابقة والتضمن واللزوم المشروط بحساب Lean القائم | علية أو حكم شرعي أو وقوع عيني |
| التركيب | جميع اختيارات القراءات لخانات معجمية مرتبة، حتى 8 خانات و512 تركيبًا في الطلب | تحليل الجملة الحرة أو إثبات المراد من السياق |
| البرهان | 15 مبرهنة عامة جديدة، منها تركيب العلاقات والاستقراء على عدد المراحل | أن مقدمات كل مرحلة قد تحققت للعربية كلها |

**الخانات هي فهارس قاموسية يحددها الطالب، وليست كلمات استخرجها محلل
نحوي.** فطلب `[ذهب، ولد]` يربط تفسيرين منقولين؛ لا يثبت بمفرده إعراب
«ذَهَبَ الْوَلَدُ»، أو لزوم الفعل، أو زمن حادثة، أو مكانها.
هوية الطلب المثبتة في الجسر هي هوية هذه الخانات وأهدافها، وليست هوية
وقوع دلالي استخرج من نص عربي. لا يُصنّع «الآن» أو «هنا» ولا إزاحة زمنية.

حُفظ الكتالوج السابق ومبرهناته دون تعديل. الإضافة تستورد قراءاته أولًا،
وتضيف 24 قراءة من لسان العرب. التفسير الجديد كله ذري: «السير والمرور»
مكوّن مصرح به واحد؛ ورود «السير» فيه لا يرخص التضمن تلقائيًا. «الشمس:
معروفة.» بقي بلا مكونات، مع `PREVIOUS_KNOWLEDGE_REQUIRED`. لا تُملأ هذه
الفجوة بادعاء النهار أو الحرارة. قاعدة السرير/الارتفاع مقيدة بقراءة
«المضطجع» وبموضع من مقتطف الشخصية الثالث؛ تعيينها لهذه القراءة تفسير
مؤلف عبر مصدرين، وليس تحقيقًا تاريخيًا مستقلاً أو برهان ارتفاع سرير عيني.

## ما يضيفه البرهان فعلًا

تعرف `Reference` القراءات المرخصة **داخل الكتالوج المحدد**. تثبت
`answers_exact` الاتجاهين بين التنفيذ وهذا المرجع. وتثبت
`accepted_indication_sound` و`alternative_premise_sound` صحة نقل الهدف إلى
صيغة الاستدلال القائمة، بشرط صدق تفسير المكونات وقواعد اللزوم في النموذج.
يبقى كل بديل في التعداد؛ لا تتحول نتيجة بحث أو أعلى درجة متجهية إلى تعيين
وحيد للمعنى. تعاد استخدام مبرهنتي `enumeration_exact` و`enumeration_count`
وحساب الصيغ من المستودع بدل كتابة تعداد أو حساب دلالة جديدين.

تثبت `compose_exact_with_domains` أن اكتمال مرحلتين ينتقل إلى تركيبهما
عندما يثبت أيضًا أن كل مخرج مرجعي للمرحلة الأولى يقع في مجال الثانية.
وتثبت `chain_exact` ذلك باستقراء بنيوي على قائمة مراحل بأي طول منتهٍ،
بشرط اكتمال **كل مرحلة**. هذا هو موضع الاستقراء؛ لا يُستبدل الشرط بوجود
جداول أو أعلام `verified=true`. وتثبت `unresolved_selection_blocks` أن
بديلًا غير محلول يمنع ترخيص جميع القراءات، و`budget_preserves_verdict`
أن تجاوز ميزانية البحث لا يصدر حكمًا إيجابيًا.

هذه المبرهنات تتصل بالنواة الموجودة، لكن اكتساب القراءات من النص الحر
وجسرها إلى هذه الخانات ما زالا التزامًا مستقلاً. لم نصل هذه المدخلات
المؤلفة آليًا بمحلل الجمل على أنها حقائق مستخرجة منه.

## نتائج قابلة لإعادة الاختبار

| الطلب | النتيجة |
|---|---|
| ذهب ← «السير والمرور»، ولد ← «ما ولد أيا كان» | تركيب معجمي واحد مرخص مشروطًا؛ كلا النصين مع مصدر وبايتات |
| عين ← «النقد» | خمس قراءات محفوظة؛ واحدة مرخصة للهدف |
| عين + قلم | 15 تركيبًا محفوظًا؛ واحد مرخص للهدفين المحددين |
| سرر ← «الارتفاع» | قراءتان؛ قاعدة اللزوم لا تنتقل من إحداهما إلى الأخرى |
| ذهب ← «السير» | لا ترخيص؛ ليست جزءًا مصرحًا به في هذا التفسير الذري |
| شمس ← «النهار» | `UNMEASURED_DEFINITION`، لا اختراع تعريف أو لازم |
| بحر ← «ماء» | `UNMEASURED_ENTRY` مع إحداثيات النص المصدر؛ لم ينفذ تفسير المادة |
| أربع خانات «عين» | 625 تركيبًا محسوبًا؛ `RESOURCE_EXHAUSTED`، لا فحص لبادئة ولا حكم Boolean |

`all_targets_licensed=false` يعني عدم اكتمال الترخيص وفق هذه المقدمات؛
لا يعني كذب الهدف في الواقع أو فساد العربية. `native_checked=true`
يعني تنفيذ الفاحص ومطابقة جوابه، ويمكن أن يصاحب نتيجة عدم ترخيص أو نقص
أو تجاوز ميزانية؛ لا يساوي `all_targets_licensed=true`.

الضوابط اليدوية المثبتة في `benchmark_cases.json` تضم 16 حالة. هي مراجعة
ذاتية مؤلفة قبل تشغيل المقيم، وليست مجموعة عمياء أو تحكيمًا لغويًا مستقلاً.
يميز التقرير النجاح في مطابقة الضابط من التغطية اللغوية: الامتناع الصحيح
عن تعريف الشمس ينجح كضابط أمان، لكنه لا يزيد عدد المعاني المفسرة.
المقارنة الحسابية في محول Python تحقق سلامة النقل من التنفيذ الأصلي،
ولا تُحسب دليلًا مستقلاً على صحة المرجع.

أعيد أيضًا تشغيل التشخيصين السابقين دون تغيير أجوبتهما المرجعية:
الاستدلال المرخص بقي عند 37/38، وتشخيص الحقيقة اللغوية عند 19 ناجحًا
و11 فاشلًا و14 غير مقاس من 44؛ حالات الاستعمال الطبيعي الست ما زالت
0/6. هذه الإضافة لا تدعي إصلاح اكتساب النص الحر بتوسيع كتالوج الخانات.
تحفظ النتائج في `preserved_scope_checks.json` ولا تدخل الحالات غير
المقاسة أو الامتناعات في بسط «اكتمال العربية».

## معيار اكتمال العربية المطلوب

لا يوجد في هذه الإضافة مقام عددي معلوم اسمه «كل العربية» يسمح باستخراج
نسبة اكتمال. نحتاج أولًا علاقة مستقلة `R(نص، قراءة، مقام)` تحدد نوع العربية،
المصادر والطبعات، الخلافات المدرسية، الابتداء والوصل والوقف، والاصطلاحات
والقرائن. ثم يلزم إثبات اتجاهين لكل طبقة: كل مخرج تنفيذي مرخص في `R`،
وكل قراءة مرخصة في `R` ينتجها التنفيذ. يجب أن تأتي `R` من مصادر وتحكيم
مستقلين، لا من إعادة تسمية المخرجات الحالية «العربية».

| التزام | حالته بعد الإضافة | دليل الإغلاق المطلوب |
|---|---|---|
| استنفاد مقاطع المصادر | فهرسة بايتات للمصدرين متاحة، وليست استنفاد قواعد | تصنيف كل مقطع مع حفظ غير القاعدي والملتبس |
| استنفاد معاني كل مادة | 42 قراءة مختارة فقط | سجل معانٍ مستقل ومراجعة الحذف والإضافة لكل مادة |
| تحقيق التفسير والنقل | 0 قراءة محكمة استقلالًا؛ التواتر غير مقيم | سند/طبعة/موضع ومراجعة تفصل الثبوت والدلالة |
| القراءات الصرفية والنحوية والصوتية | المسارات السابقة المحدودة باقية | براهين الاتجاهين لكل مسار، مع الخلافات وحدود الصوت والرسم |
| النص الحر إلى المدلول | غير منجز بهذا المسار | قارئ مرخص يحفظ كل التأويلات والقرائن وهوية النص |
| تركيب المراحل | المبرهنة العامة منجزة، شروط المراحل مستقلة | إثبات انتماء المخرجات لمجالات المدخلات التالية |
| مطابقة الواقع | ليست وظيفة الشهادة المعجمية | أدلة وقائع مستقلة عن صحة نقل اللفظ |

لذلك لا يثبت نفي النقيض بفشل اختبارات محدودة في العثور على مثال ناقض.
تعداد محدود يثبت الاستنفاد بالنسبة إلى مجاله المعلن؛ الاستقراء العام
يحتاج أساسًا وخطوة انتقال تغطيان تعريف المجال المستقل كله.

## أوامر إعادة التحقق

```bash
python tools/fetch_lisan_source.py --output artifacts/local/lisan.txt
python tools/build_lexical_completion.py --check
cd formal
lake build Nabt lexicalCompletion
cd ..
python tools/check_axioms.py --output artifacts/local/lexical-completion/axioms.json
PYTHONPATH=src:. python -m unittest discover -s tests -p test_lexical_completion.py -v
python tools/benchmark_lexical_completion.py --output artifacts/local/lexical-completion/benchmark.json
python tools/lexical_completion.py --request evidence/lexical_completion_v1/example_request.json
python tools/lexical_completion.py --inventory
```

النسخة مثبتة في `formal/lean-toolchain`. يتوقف التشغيل عند تغير الكتالوج
أو المصدر أو تصدير الفاحص. يقارن JSON المقنن الأنواع دون تحويل `true`
إلى `1` أو `5.0` إلى `5`. مسار CLI يرفض المفاتيح المكررة. مدخلات الفاحص
الأصلي تمر بمحول JSON المقيد القائم؛ لا يُدّعى هنا برهان صوري لتكرير
محلل JSON أو متحقق SHA إلى نواة Lean.

مصادر لسان العرب والمقاييس مثبتة بمعرف Git وSHA-256. مقتطف الشخصية
الثالث مصدر محفوظ من المستخدم، وليس نسخة كاملة محققة من الكتاب؛ يظل
ذلك ظاهرًا في حقل `revision`. لا تُرفع نسخة لسان العرب الكاملة؛ تستعاد
من OpenITI المثبت. ترخيص البيانات وحقوقها محفوظة كما في
[توثيق الدلالة](LEXICAL_DENOTATION.md). المقتطفات الجديدة قصيرة ومنسوبة.

حدّثت مراجع بوابات النحو والمنطوق والحقيقة اللغوية والاستدلال المرخص
إلى لقطة الفهرس الحالية وروابطها، دون تغيير براهين هذه الطبقات أو محو
لقطاتها التاريخية. يقارن `proof_catalog.py` العبارات المترجمة وبصمات
المصادر، وتعيد بوابة GitHub المتكاملة فحص الروابط الأربعة. البصمة لا
تمنح صحة دلالية؛ تمنع استخدام شهادة مرحلة قديمة مع فهرس مختلف.

التقرير التنفيذي في [دليل المرحلة](../evidence/lexical_completion_v1/)
ومراجعة المستودعات في [المسح المحدث](LEXICAL_REPOSITORY_REVIEW_AR.md).
هذه إضافة للمستودع وCLI؛ صفحة المختبر المنشورة تظل على مسار الشهادة
السابق إلى أن تنشر نسخة متوافقة معها وتفحص بإيصال حي جديد.
